# ProbabilityMeter

0–100% 막대 하나에 확률(채움), 기준 확률(점선), 매수·매도 임계값(세로 표시)을 함께 보여줘요.

- 제공: `probability`, 선택 `base`, `buyThreshold`, `sellThreshold`(모두 1–99 정수 문자열), `probabilityLabel`(기본 “확률”).
- 색은 `primary`와 중립색만 써요. 빨강·파랑은 쓰지 않아요(가격 방향과 매수·매도 버튼 전용).
- 확률은 막대 위 한 줄에 크게, 기준 확률·매수 기준·매도 기준은 막대의 세로 표시와 이름표로 보여줘요.
- 이 앱의 확률은 대부분 막대 왼쪽 절반(10–50%)에 몰려요. 이름표는 실제 글자 폭으로 겹침을 확인해서 아래 줄 → 위 줄 → 아래 둘째 줄 순서로 놓고, 막대 끝에서는 안쪽으로 붙여요. 그래서 표시가 붙어 있어도 서로 가리지 않아요.
