# PriceChange

등락 금액과 등락률을 국내 관례 색(상승 `up` 빨강, 하락 `down` 파랑, 보합 `ink-muted`)과 기호(▲ ▼ –)로 보여줘요.

- 제공: `value`(등락 금액), `rate`(등락률 %, `"2.43"`), `currency`(`KRW` 기본, `USD`). 코어가 표시 자릿수까지 반올림한 **문자열**만 넣어요.
- 방향은 받은 문자열로 정해요. 등락률이 0이 아니면 등락률을, `"0.00"`·`"-0.00"`이면 금액을 따라요. 둘 다 0이면 보합(–)이에요. `▼ −$0.01 (0.00%)`처럼 금액만 움직인 경우는 하락이에요.
- 둘 중 하나라도 잘못된 값이면 전체가 주황 `—`(“등락 값 오류”)로 바뀌고 오류가 올라가요. 0이나 보합으로 보이지 않아요.
- `pill`은 배지형(목록·랭킹), `size`는 `sm`·`md`·`lg`.
- 색만으로 방향을 전하지 않아요. 기호와 `aria-label`(“상승 +1,700원 +2.43%”)이 항상 함께 나가요.
