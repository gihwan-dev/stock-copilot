# Callout

화면 안에 머무는 알림·주의·실패 상자예요. 토스트 대신 써서 사용자가 읽고 조치할 때까지 남겨요.

- 제공: `tone`(`info` 기본, `warning`, `error`), `title`(무슨 일인지 한 문장), `children`(왜·어떻게 고치는지), 선택 `action`(Button sm). 예전 이름 `alert`는 `warning`으로 처리돼요.
- 제목 앞에 단계 단어(알림·주의·실패)가 자동으로 붙어요.
- `info`: 휴장, 동기화 완료.
- `warning`: 쏠림, 오래된 데이터, 근거가 외부 출처뿐. 테두리만 있는 `!`.
- `error`: 토스 연결 실패, 토큰 폐기, 주문 실패, 값 오류. 꽉 찬 `×`, `alert` 테두리, `role="alert"`, 조치 버튼을 꼭 넣어요.
- 내부 오류 코드(`ip-not-allowed` 같은)는 화면에 쓰지 않아요. 사용자가 알아듣는 말로 바꾸고 코드는 로그에만 남겨요.
- 둘 다 빨강이 아니라 `alert` 주황이에요. 빨강은 가격 방향 전용이에요.
