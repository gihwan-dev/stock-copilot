# 설정

기본 항목은 **토스 연결, 투자 성향, 주문 켜기** 세 개뿐이에요. 나머지는 “고급” 펼침 안에 다섯 묶음으로 있어요.

- 투자 성향: 기간(며칠 / 몇 주~몇 달 / 반년 이상, 기본 몇 주~몇 달)과 위험 성향(보수 / 중립 / 공격, 기본 중립)을 `SegmentedControl` 두 개로. 그 아래 제외(종목 유형·섹터)와 비중 상한(종목 20%, 섹터 40%)을 한 줄 요약 + “바꾸기”로.
- 고급 다섯 묶음(묶음마다 대표 항목만 그렸어요): **AI**(작업별 모델: 아침 브리핑·종목 분석·채팅마다 Claude 모델), **뉴스·데이터**, **주문**(시장가 허용, 몇 시간 단위 기간 허용), **투자 원칙**(쏠림 경고 기준), **시스템**(로그인 시 자동 시작, 계좌, 상태).
- 매수·매도 임계값은 코드가 계산하니 입력란이 없어요. “기록만 하는 기간”은 판정된 추정이 30건 쌓이면 자동으로 끝나서, 스위치 대신 시스템 > 상태에 읽기 전용 한 줄(“기록만 하는 중이에요. 30건 중 12건 판정됨”)로 보여줘요.
- 조립: `Dialog`(`dialog-width`) → 연결 줄 → `Divider` → 투자 성향 → `Divider` → `Switch` 주문 켜기 → `Disclosure` “고급”(묶음마다 `Heading` 3 + `Stack`).
- 상태: 로딩(Skeleton) · 빈(연결 안 됨: 연결하기 버튼, 주문 켜기 비활성) · 오류(저장 실패 Callout) · 정상.
- 바뀐 값은 바로 적용돼요(저장 버튼 없음).
