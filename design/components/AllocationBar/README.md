# AllocationBar

섹터·국가·통화 비중을 한 줄 막대와 범례로 보여줘요. 비중 계산, 정렬, ‘기타’ 묶기, 쏠림 판정, 반올림은 코어가 하고 이 컴포넌트는 그리기만 해요.

- 제공: `items`(`{label, weight, over?}` 배열, 큰 비중부터, **최대 6개**). `weight`는 소수 첫째 자리 문자열(`"48.0"`), `over`는 코어가 사용자의 상한과 비교한 결과예요.
- 7개 이상이 오거나 비중을 읽을 수 없으면 막대를 그리지 않고 실패 Callout(“비중을 표시할 수 없어요”)을 보여주며 오류를 올려요. 일부만 그려서 합이 100%가 안 되는 막대는 만들지 않아요.
- 선택 `limitLabel`(“상한 40%”)은 쏠림 배지에 그대로 나가요.
- 큰 비중부터 `chart-1`…`chart-6`. 진한 색과 밝은 색이 번갈아서 이웃 계열이 밝기로 구분돼요. 빨강·파랑은 계열색으로 쓰지 않아요.
