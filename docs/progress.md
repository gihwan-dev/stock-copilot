## 검사 명령

- `just base=<HEAD 또는 40자리 커밋 ID> check`: 기준은 HEAD의 조상이어야 한다. 병합 확인은 병합 전 `master` 끝을 기준으로 돈다.
- `just base=<…> check-full`: 전체 변이 테스트와 권고 DB 갱신 포함.
