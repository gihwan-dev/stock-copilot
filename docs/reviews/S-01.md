Opus는 훅이 막은 손 변형·임시 테스트를 실행하지 못했고 check-fast는 10분 제한으로 미완료였다. 차단 뒤 경로를 바꿔 다시 시도한 절차상 문제도 원문에 보고했다. Codex는 별도 체크아웃에서 C lookaside 계측·권한·스냅샷 반례를 실행했고 제품 기본 allocator 배치의 힙 덤프는 하지 않았다. Codex의 메타데이터 파일 한 건이 /tmp에 만들어진 절차상 실수는 종료 전에 제거·부재 확인했다고 보고했다. 두 리뷰어의 tracked 작업 트리는 깨끗했다. 이 결과를 세션 훅 신뢰·적용의 증거로 주장하지 않는다.

실행 로그는 target/S-01, 의존성·PRAGMA·손 변형 표와 인계는 ADR 초안에 있다. 지시문 원본과 docs/tasks.md·docs/progress.md를 직접 수정하지 않았다. A-21의 해당 문서 변경은 master 병합으로만 받았다.
