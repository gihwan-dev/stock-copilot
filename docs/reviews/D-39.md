## 검증 범위와 인계

회차 2 리뷰어는 빌드·속성·변이·전체 검사, 스펙 39필드 전수 대조, application 및 A-02·A-20 병합분을 검증하지 않았다. 구현자의 실행 증거는 ADR의 수정 회차 기록에 별도로 둔다. 실제 토스 API는 호출하지 않았다. 리뷰 후 자동 변이 미검출을 보강한 테스트는 자체 검증이며 Opus 재리뷰를 주장하지 않는다.

회차 3 최초 `cargo test -p domain`은 950개 통과·두 국내 지수 예제 실패(BenchmarkMismatch)였다. 두 함수는 생성자 호출명을 제외하면 master 원문과 바이트 단위로 같음을 확인했다. 수정 뒤 단위 952개와 통합 16개가 모두 통과했다. market_ranking·sector_composition의 D-42 영 값 예제와 virtual_exit·signal_return_review의 추가 예제는 수정 없이 통과했다. master가 실제 조상이 된 병합 뒤의 독립 test-diff 집계도 정확히 15건이다. 증가한 두 항목의 파일·테스트·전후는 ADR의 D-42 병합 호환성 표에 있다.
