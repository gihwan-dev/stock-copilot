# 리뷰 기록 A-11

## 브리프

AI-01(실행 이벤트 모델 `AiEvent`)과 A-11(`testkit` 2: 가짜 AI CLI 실행 파일) 묶음의 A-11 몫이다. `crates/testkit`의 잎 크레이트 불변식과 새 외부 패키지 금지 규칙을 유지한 채, `PATH`를 바꾸지 않고 실행 파일 경로 주입(`PreparedFakeAiCli::prepare`·`prepare_with_binary`)으로 교체되는 가짜 AI CLI 바이너리(`fake_ai_cli`)를 구현했다. 녹화 `stream-json` 재생 모드와 순수 `std` + `serde_json` 기반 두 세대(`2026-07-28`, `2025-06-18`) 대본 MCP 클라이언트 모드·내장 stdio↔UDS 브리지를 제공하며, 토큰·API 키 비노출과 사전 점검 실패 시 도구 호출 0건을 테스트로 고정했다. ADR 초안은 `docs/adr/a-11-fake-ai-cli.md`다.
