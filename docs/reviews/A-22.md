# A-22 자동 창과 일일 전체 검사 판정 리뷰

## 브리프

A-07의 명시적 창 동기화 위에 D-45의 최근 14일 자동 창, 오늘 전체 검사가 필요한지의 판정, 마지막 성공 완료 시각 저장과 역행 시각 닫힌 실패를 연결한다. 전체 시작일·분할·완결은 기존 domain 계약이 없어 정의 대기다. 별도 최소 저장 trait을 허용하며 새 domain 정책을 만들지 않는다. 가짜 테스트는 testkit-ports/tests에만 둔다. 기존 테스트·A-07 구현·tasks/progress는 수정하지 않는다. 새 ADR은 번호 없이 초안으로 유지한다. 보호 등록 생성물과 지정 Xcode R4 한 건 실패 후 나머지 모든 검사 통과 시 커밋 한정 환경 예외는 사전 승인이다.

비판자 실행: 원 통합 6개 통과, D-45 선택 4개 통과(나머지984 중980 제외), 보고서 유실 변형에서 기존6 통과·독립회귀 포함7통과1실패, 복구8통과. 미래완료는 저장시각 도달 시 CompletedToday로 회복했다. 전체 check와 실제 S-03/전체 실행은 비판자 NOT_RUN이다.

## 검사와 환경

프로젝트 신뢰·세션 훅 신뢰 적용 여부는 확인 불가다. 브리프 승인으로 계속하며 Git 훅은 설치했다. 첫 정상 훅은 새 ADR 추적 뒤 재생성이 빠진 R5와 Xcode R4의 두 건에서 실패했다. 이 시도에 환경 예외를 쓰지 않았다. 공식 설정·조각·해시 재생성 후 staged 상태에서 R5는 통과했다. pnpm PATH를 빠뜨린 단독 진단에서는 pnpm 모듈 경로 오류가 났고, 지정 PATH를 포함한 재실행10개는 모두 통과했다.

두 번째 정상 훅은 Xcode 라이선스 미동의 R4 단 한 건만 실패했다. 환경 예외 사용: 예. 후속 check-ts와 check 본문의 모든 단계를 직접 순서대로 실행해 종료0을 확인하고 20ff616 커밋 한정 LEFTHOOK=0을 사용했다. 사유는 커밋 메시지에도 있다. 전체 nextest1813개·coverage계측1070개·coverage-check·test-diff·hooks-installed 통과, 새 검사 끄기0건이다. 전체 just check 자체가 종료0이었다고 주장하지 않는다. 로그는 target/A-22/commit2.log·remaining.log다.

원 명령 just mutants-diff는 4개 중 미검출1·컴파일불가3으로 종료1이다. application만 시험해서 testkit-ports 통합 테스트가 제외됐다. 원 명령을 통과로 보고하지 않는다. A-07과 같은 H-47 선택 인계이며 통합 테스트를 포함한 보완 실행을 별도로 기록한다. 손 변형20개는 전부 실제 컴파일 성공·검출이고 원복6개 통과다(ADR 표, target/A-22/manual.json). 비판자의 별도 보고서 유실 변형은 최초 생존이었다.

## 최종 통합 범위

수신한 master는 bf9618518c8782cd5e00a5735679c34762ade84a이다. --no-ff --no-edit master 수신에서 config/hash 충돌만 발생했다. 두 작업의 lib 선언은 자동 병합되어 모두 유지했다. 충돌은 공식 생성 명령으로 재생성한다. master에서 받은 A-17 코드·테스트·tasks/progress/ADR은 보존하며 직접 편집하지 않는다. 최종 테스트·검사 결과와 merge commit SHA는 최종 보고로 정확히 구분한다. master ref 자체는 옮기지 않는다.
