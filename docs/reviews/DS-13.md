구현과 수정은 Codex `gpt-6.1-sol`(T3 스레드, 작업 사본 `ds-13`). 리뷰어는 회차 1에 새 Claude Opus 5.5 서브에이전트. 결정은 ADR 0026에 있다. D-01, D-15, D-16과 병렬로 진행했다.

**비판 단계를 생략했다.** 리뷰어가 복사본에서 실제 Tailwind 4.3.5 컴파일과 `vite build`로 재현했고 메인이 전부 판정했다.

## 메인 결정

- 대비 검사는 xtask가 아니라 Node 스크립트(`harness/ds-tokens/contrast.mjs`, `just tokens-contrast`)다. Rust 작업 공간의 `float_arithmetic = "forbid"`는 끌 수 없는 규칙이고 그대로 둔다.
- 기존 테스트 두 곳의 기대값 추가를 승인했다: `apps/desktop/tests/eslint-config.test.mjs`(CSS 두 경로), `apps/desktop/tests/knip.test.mjs`(생성 타입 파일과 CSS 진입점). `local/forbidden-file`에 정확 경로 예외 두 개(`tokens.css`, `theme.css`)를 더했다. 약해진 단언은 없다.
- 대비 미달 조합은 토큰을 고치지 않고 "확인 대기" 닫힌 목록에 둔다. 목록의 값이 바뀌거나 기준을 넘으면 실패한다.
