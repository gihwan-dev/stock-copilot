## 샌드박스 결정

원본 루트에서 샌드박스 안의 `just check`가 실패했다(실측 E4b). 원인을 고치려면 기존 테스트 여러 개를 바꿔야 해서 되돌렸다. 메인 결정: 샌드박스는 지금 켜지 않고 H-20의 잠금 설정에 넣는다. git 커밋을 샌드박스 밖에서 돌리는 방법은 쓰지 않는다(구현자의 커밋 훅이 에이전트가 쓴 코드를 샌드박스 밖에서 실행하게 된다).
