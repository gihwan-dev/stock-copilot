## 리뷰 (회차 1)

R-11 예제 8(HHI 0.2300, 유효 종목 수 4.347826, 상위 1·3·5 비중 0.35·0.75·0.95)은 모든 자릿수가 맞았고 독립 계산 900건과 일치했다. 손 변형 9개 모두 검출.

| 번호 | 등급 | 지적 | 평가 |
|---|---|---|---|
| 1 | 차단 | 현금을 분모에만 넣고 제곱합에서 빼서 유효 종목 수가 부풀려짐. 1종목 10% + 현금 90%가 100으로 나와 경고가 없음. R-11은 지표별 현금 처리를 정하지 않음 | 수정: HHI, 유효 종목 수, 상위 비중, 경고를 모두 보유 구성비(현금 제외)로 계산. 같은 입력이 1로 나오고 경고 |
| 2 | 중요 | 공개 표시 함수가 큰 값에서 panic | 수정: 유효 종목 수를 [1, 보유 수]로 검증. 정수 비율을 반올림해 표시 문자열을 만듦 |
| 3 | 중요 | 반올림하는 근사 제곱이 정확 산술 파일에 들어가고 근사 비중이 금액 타입으로 나옴(ADR 0029 위반) | 수정: 쏠림 전용 근사 계산 파일과 봉인 타입. 정확 산술 파일의 추가분은 되돌림 |
| 4 | 사소 | 큰 값에서 표시 자릿수가 참값과 다름 | 수정: 독립 유리수 대조에 1e-4~1e12 평가액 |
| 5 | 사소 | 상태·오류 타입을 외부에서 만들 수 있고 `Debug`가 전체 정밀도를 출력 | 수정: 봉인, 가림 |

## 메모

- 분모 결정(보유 구성비)은 문서에 없는 해석이다. 근거: 예제 8과 "균등 10종목이면 HHI 0.10"은 비중 합이 1일 때만 성립하고, 유효 종목 수는 "사실상 몇 종목인가"를 뜻한다. 사용자 확인 대상이다.
- ADR 0029에 쏠림 전용 근사 계산 파일에 관한 문장을 더했다.
- 경고 결과의 네 변형(경고, 경고 없음, 해당 없음, 계산 불가)은 D-12의 쏠림 입력 네 상태와 일대일로 대응한다. 연결은 D-25 작업에서 한다.
- 회차 1의 변이 검사는 30분을 넘겨 중단했다. 회차 2는 손 변형 18개가 모두 검출됨을 확인했다. 수정분은 Opus 재리뷰를 하지 않았다.
