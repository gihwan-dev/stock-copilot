## 메인 평가

- 판정: 수용. 신호 저장 포트를 통째 교체(`replace`)에서 스냅숏 읽기와 기대 상태 기반 커밋(`snapshot`·`commit`)으로 바꿔, 같은 종목의 신호 전이가 겹칠 때 뒤늦은 쓰기가 앞선 판단을 덮지 못하게 했다. A-13(`EvaluateSignals`)이 이 포트 위에서 다시 시작한다.
- 기존 테스트 변경 6건을 승인한다. 메인이 차이를 직접 읽었다: 포트 서명 문자열과 호출·준비 코드가 새 포트를 따르고, 쓰기를 버리는 구현을 거부한다는 단언은 유지되며 커밋 시도 횟수 단언이 더해졌다. 단언 삭제·약화는 없다.
- H-55의 승인 기록(`harness/test-diff/approvals.toml`)으로 기계 승인을 시도했으나(임시 복제본, 표시 유무 두 가지) 여섯 건 모두 해소되지 않았다. 판정기가 거부 사유를 알려 주지 않아 원인을 확정하지 못했고, 이 병합은 종전처럼 예외 커밋으로 넣는다. 거부 사유 출력과 이 사례의 재현은 하네스 과제로 넘긴다.
- 남은 연결: SQLite 실저장과 프로세스 간 경쟁(S-07·S-18).
