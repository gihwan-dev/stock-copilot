## 샌드박스 안 검사 실패

원인: Claude Code 샌드박스는 프로젝트 폴더 안 어느 깊이에서든 `.git/config`와 `.git/hooks/*` 쓰기를 거부한다. 하네스 테스트가 `target/harness` 아래에서 `git init`하다 실패했다. 수정: 테스트 저장소의 git 폴더를 사용자 전용 임시 폴더에 두고 링크로 가리킨다. 샌드박스 설정은 바꾸지 않았다. 샌드박스를 켠 복사본 루트에서 `just check`, 커밋, 병합이 통과했다(실측 E4c).
