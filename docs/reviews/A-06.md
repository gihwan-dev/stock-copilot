## 실행 결과와 한계

1차 대상의 정상 Git 훅 전체 검사는 전체 Rust 1596개, 커버리지 1059개 및 coverage-check를 통과했다. Opus의 check-fast 두 실행은 120초·590초 시간 제한으로 실행 미완료다. 최초 보고의 NOT_RUN 표기를 정정한다. 비판자는 좁은 독립 재현만 실행했으며 전체 검사·check-fast는 실행하지 않았다. 새 승인 증거나 domain 생성 경계를 추가하지 않아 타입 우회 실험은 해당 없음이다. 금액 계산 코드가 없어 독립 수치 계산도 해당 없음이다.

최초 just mutants-diff는 application 패키지만 검사해 testkit-ports 통합 테스트가 실행되지 않았다. 16개 선택 중 미검출4·컴파일불가12였으며 이를 통과로 세지 않는다. 네 결함의 컴파일 가능한 동등 변형은 기존 통합 테스트에서 전부 검출됐다. application에는 가짜나 개발 의존성을 추가하지 않고 현금 변환과 순수 결과 판정 테스트만 추가했다. 포트 가짜 테스트는 testkit-ports/tests에 유지한다.

보호 파일 변경은 새 ADR 등록에 필요한 .codex/config.toml와 harness/claude-hooks/hashes.json 생성물뿐이며 공식 쓰기 스크립트로 재생성했다. 규칙 완화·소스 주석·검사 끄기·기존 테스트 수정·master 이동·push·PR·홈 설정 변경·자격 증명 접근·실제 계좌/키/API 사용은 없다.

2차 Opus는 기준선 15개와 raw-types/source-check를 통과했으나, 손 변형은 하네스의 dynamic-target/dynamic-command/chmod 및 main-docs-only 거부로 실행하지 못했다. 생존 주장은 추론으로만 보고했고 거부를 우회하지 않았다. test-diff는 사본의 frontendDist 부재로 실행 미완료다. 새 Codex 비판자는 4개 유효 변형 각각의 컴파일 성공·기존15개 통과·독립 증인 검출을 확인했다. 최초 구독자 변형2개는 컴파일 불가여서 집계에서 제외했다. 원본17개 및 원복17개 증인 대조군과 증인 제거 후15개가 통과했다.

수정1의 정상 훅은 전체1601개·커버리지1061개·coverage-check·arch-check·test-diff를 통과했다. 표준 변경분 자동 변이 재실행은18개 선택 중2개 컴파일 후 검출·16개 컴파일 불가·미검출0·시간초과0이며 위반 없음이다. 컴파일 불가를 검출로 세지 않는다. 수정2는 통합15개와 순수2개 테스트가 통과했으며 세부 손 변형은 ADR의 최종 표와 target/A-06/hand-results.json에 남긴다.

## 3차 비판과 최종 수정 범위

140145ab045037b965a4e6a3a08e9cc8ce29303b → b66d40a4439d0658159c8b2ddb661e0cab8403c8 범위에는 testkit-ports의 테스트 세 개 추가만 있다. 새 제품 코드·domain·의존성·기존 master 테스트 변경은 없다. 원 사용자 지시의 최대3회차 규칙에 따라 이 수정에 대한4차 독립 리뷰를 시작하지 않았다. 메인이 평가할 수 있도록 실제 컴파일된 손 변형36개의 검출 테스트와 원복 대조군 결과를 ADR 끝 표에 보존했다.

3차 Opus는 M1 비종합매매 허용 변형의 컴파일 성공·통합15/순수2 통과·생존을 확인했고, 원복 통합15개도 통과했다. 이후 실험은 dynamic-target 거부로 실행하지 않았으며 나머지 생존 주장은 추론으로 구분했다. 새 Codex 비판자는 M1~M6 모두 재컴파일 성공·기존15+2 통과·독립 증인 검출을 확인했다. M7 AccessDenied 일반 실패 변경은 기존 테스트가 검출했다. 원본·원복 통합15/순수2/독립증인3개가 통과했고, 임시 소스·테스트를 원복했다. 현재 제품 결함은 확인하지 못했으며 조립 오류 원인 미반환을 현재 계약 위반으로 보는 판정은 기각했다.

세 번의 리뷰와 세 번의 비판 모두 대상 추적 파일·인덱스·HEAD·브랜치 참조의 위임 전후 스냅숏이 일치했다. 프로젝트/훅 신뢰 및 전체 런타임 적용은 확인 불가이고, Claude 리뷰에서 일부 PreToolUse 거부가 실제로 작동한 사실만 별도로 확인했다. 실험 거부를 우회하지 않았다.

최종 회귀 보강 커밋의 정상 훅은 전체1606개 및 커버리지1061개, coverage-check·arch-check·test-diff를 통과했다. 최종 master 통합과 표준 변경분 변이의 실제 결과·최종 SHA는 최종 보고에 남긴다.

## 메인 평가 (3차 뒤 수정)

3차 뒤 수정은 회귀 테스트 추가(비종합매매 계좌, 조립 실패, 계좌 오류 네 종류)와 등급 표기 통일이며 제품 동작을 넓히지 않는다. 병합 커밋의 정상 전체 검사가 통과했고 승인된 test-diff는 0건이다. 추가 리뷰 없이 병합한다.
