구현과 수정은 Codex `gpt-6.1-sol`(T3 스레드, 작업 사본 `h-41-codex`). 리뷰어는 회차 1과 2에 각각 새 Claude Opus 5.5 서브에이전트. 결정과 실측은 ADR 0021에 있다. 병합 커밋은 1551544다. 사용자가 2026-11-13에 배분을 바꿨다: 구현·수정·조사·비판은 Codex, 적대적 리뷰는 Claude Opus.

**비판 단계를 생략했다.** 두 리뷰 모두 차단 지적을 Codex 0.168.0에서 재현했고, 메인이 전부 수정으로 판정했다.

## 메모

- 회차 3 수정분은 재리뷰하지 않았다.
- T3가 `full-access`로 띄운 Codex 세션에 프로젝트 훅과 권한 프로필이 적용되는지는 확인되지 않았다. ADR 0021의 "병합 뒤 메인의 1분 적용 확인"으로 본다.
- 사용자가 `just codex-setup` 출력을 Codex 사용자 설정에 반영하고 프로필을 선택해야 샌드박스가 적용된다.
- Codex에는 설정 변경 이벤트가 없고, 훅 시작 실패와 시간 초과는 닫을 수 없다. 알려진 빈틈으로 등록했다.
- Codex 셸에서는 `/usr/local/bin`의 오래된 corepack이 먼저 잡혀 pnpm 12를 실행하지 못했다. `just check-pnpm`을 더했다.
