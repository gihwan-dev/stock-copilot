## 메인 평가

- 판정: 부분 수용. 섹터 목록·상세·구성·ETF 조회와 전체 종목 조회의 초당 1회 제한기(가짜 시계 검증)는 들어왔다. **전체 종목 마스터(`BrokerRead::instruments`)는 구현되지 않았다**: 토스 응답에 안정적인 내부 `InstrumentId`가 없고 발급·영속 대응 규칙이 정의돼 있지 않다. 구현자가 규칙을 임의로 만들지 않은 것은 지시에 맞다.

- 후속 등록: D-52(내부 ID 발급과 영속 대응 계약), T-21(전체 종목 마스터 공급과 오류 분류). T-09 행의 "전체 종목 조회의 초당 1회 한도 준수"는 제한기 수준에서만 충족됐고 실제 조회 경로 연결은 T-21이다.
