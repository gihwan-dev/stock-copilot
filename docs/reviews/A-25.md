## 브리프

A-25 행과 ADR 0117에 따라 FullInspectionPlan으로 구간별 기존 창 동기화 경로를 호출하고 FullInspectionProgress에 완전 수신·대조·저장 성공만 보고한다. completion_at 성공값의 completed_at을 그대로 저장한다. 실패·날짜 변경·중복·외부 보고는 완료를 만들지 않으며 다음 실행은 전체를 재시도한다. 개설일 포트가 없으면 None 정책, 비용과 요청 간격은 T-06 후속이다. A-07·A-22의 기존 동작과 테스트를 유지하고 새 domain/포트 메서드를 만들지 않는다. 푸시·PR·master 이동·실제 키/계좌/API 사용 없음.

## 2차 비판과 수정 근거

새 Opus 리뷰의 A-25/A-22 통합19개가 통과했다. 새 Codex 비판은 같은19개와 격리 target 실험2개, broker-toss의 창 밖 미결제 회귀1개를 실행했다. 접근차단 합성 실험은 broker_calls=2028·saves=2028·completed=0, 구독자 실패 실험은 subscriber_failures=2·saves=2인데 반환은 Completion(Incomplete)뿐이었다.
