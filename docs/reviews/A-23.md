Opus의 역할 훅 거부 문구는 `[role-without-edits] adversarial-reviewer는 파일을 편집하지 않는다 (docs/workflow.md 1장)`였다. 이 역할의 편집을 우회하거나 훅을 변경하지 않았다. 별도 Codex 비판자가 자기 허용 범위의 target 임시 사본에서 독립 실험을 수행했다. Opus가 직접 실행한 것으로 합산하지 않는다.

2차 비판은 격리 원문 손상·혼합 정규화 짝 교환·clean 상한 꼬리 원문 손실을 실제 컴파일했다. 보강 전 신규3개는 각각 통과했고 별도 실험 회귀는 각 손상을 검출했다. 구현자는 보강안의 독립 기대값을 확인한 뒤 자기 임시 사본에서 같은 세 경계를 다시 변형해 각각 검출하고 원복 대조3개 통과를 확인했다.

## 독립성과 실행 한계

3차 Opus의 diff 필터가 추가 줄의 접두 기호를 처리하지 못해 ADR의 첫 검증 절 이후 리뷰·손 변형 보고 일부가 출력됐다. 리뷰어는 이를 근거로 쓰지 않았다고 고지했지만 보고서 비노출 요건을 완전히 충족했다고 주장하지 않는다. 별도 새 Codex 비판3은 그 구간을 읽지 않고 계약·제품·테스트에서 독립적으로 판단했고 위험 변형3개와 비공개 필드 실험으로 재검증했다. Opus가 손 변형을 실행한 것으로 합산하지 않는다.

최종 비판의 제품 파일 원복은 HEAD blob과 바이트 일치로 확인됐다. SQLite 원자 저장·복원·영속성, 실서비스 API 및 중간403/429와 RetryDelay의 결합 표현은 이 작업의 검증 범위가 아니다. JSON 객체의 중복 키 수용 정책도 고정하지 않았으며 T-06 후속·S-03에 확인 항목으로 남긴다. Source 원문 전달이라는 S-03 선행 계약의 막힘은 해소됐다.

마지막 병합 작업에는 새 master의 수신, 위 사소한 명명·직접 단언 보강과 이 리뷰 기록을 함께 포함한다. A-23 제품 연결 자체는 9a60994a 이후 변경하지 않았다. docs/tasks.md와 docs/progress.md의 변경은 수신한 master의 내용이며 구현자가 직접 편집하지 않았다. 푸시·PR·master ref 이동은 하지 않는다.
