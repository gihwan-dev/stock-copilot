회차 1 리뷰어는 관련 기존 테스트를 실행했으나 손 변형과 capabilities 조회가 세션 훅에 막혀 실행하지 못했다. 비판자는 읽기 전용 재현과 메모리 변형을 실행하여 다섯 지적을 확정했다. 실제 Terra 실행과 최종 적용 강도 관찰은 NOT_RUN이며 capabilities의 Terra 기본 low·상속 high 및 가드 입력 재현으로 판정했다.

회차 2 리뷰는 차단·중요 0건, 경미 5건, 참고 3건이다. 새 sol 비판도 신규 차단·중요가 없고 모델·역할 40개 및 기존 경계 17개를 독립 확인했다. 다만 비판자는 전달한 경미 지적 목록이 없었다고 보고하며 항목별 판정표를 제공하지 않았으므로, 경미 다섯 항목을 모두 비판자가 확정했다고 계산하지 않는다. 구현자가 문서·진단을 정리하고 생존 두 변형을 직접 재현·검출했다. d5276ec8 뒤의 판정기 변경은 거부 문구 두 문자열뿐이며 허용·거부 로직은 동일하다. 이 경미 정리분의 추가 독립 리뷰는 수행하지 않았고 관련 123개 회귀·29개 손 변형과 최종 병합 커밋 훅으로 확인한다.

참고 사항: 중복 판정은 기존 방어로 남겼고 동등 변형을 검출 건수에 넣지 않았다. ADR은 사용자 지시대로 번호 없는 초안이며 메인이 확정한다. 보호 파일·해시 변경은 H-50 작업 지시가 승인했다. 구현 커밋은 서명 옵션 없이 만들었으며 서명·master 병합·푸시는 메인에게 인계한다.

첫 훅 테스트 실행은 지정 pnpm PATH 누락과 재생성 전 해시 때문에 실패했고, PATH 지정·해시 재생성 뒤 239개가 통과했다. 최초 커밋 시도는 수동 검사와 동시 실행되어 테스트의 일시 fixture를 commit-guard가 거부했다. 검사 종료 후 정상 훅으로 재시도하여 구현 커밋을 만들었다. 검사 비활성화는 없다.

최초 최종 병합 검사에서는 워크스페이스 1992개와 계측 1114개 및 coverage가 통과했지만, 실행 중 master가 7b74fc84에서 997389db로 전진해 마지막 test-diff의 정확한 incoming-default 조건이 무효가 됐다. 하네스를 수정하지 않고 자체 수정 패치를 보존한 뒤 진행 중 병합만 취소하고 최신 master로 다시 병합했다. source·문서 패치는 모두 깨끗하게 적용됐다.

두 번째 최종 검사에서는 기존 workspace_layout_tests::lint_file_does_not_run_command_substitution_in_path가 SIGKILL로 종료되어 nextest가 2019 통과·1 실패·3 미실행으로 끝났다. 중단을 시도한 시점에는 커밋 프로세스가 이미 없어 종료한 PID는 없다. 이 사이 master에 H-49(0e10f05f)가 반영되어 해당 끝으로 다시 병합했다. H-49 변이 검사 세 파일은 master와 바이트 차이가 없다. 기존 테스트와 검사 규칙을 수정하지 않고 좁은 재현 후 정상 훅으로 재검증한다.

SIGKILL 대상의 좁은 재실행은 같은 코드로 1/1 통과했다(nextest 기본 프로필, 다른 335개 미선택). 종료 원인은 확인하지 못했으며 자원 압박이나 하네스 결함으로 단정하지 않는다. 테스트·실행 제한을 완화하지 않고 최종 전체 검사로 다시 검증한다.

최종 정상 커밋 훅은 CARGO_BUILD_JOBS=2로 빌드 동시성만 제한하여 실행한다. 테스트 선택·횟수·nextest 병렬 설정·커버리지 기준·검사 규칙은 바꾸지 않는다. 이 실행 설정이 SIGKILL의 원인을 해결했다는 증거로 해석하지 않는다.
