새 Opus는 기존 통합 시험10개를 통과했지만 재현 크레이트 및 inline-code 실행은 해당 세션 훅이 거부해 우회하지 않았다. 새 Codex는 원 지시문과 기존 계약을 직접 읽고 독립 복사본에서 B1·I1을 실행으로 재현했다. M2 오류 값/분류도 직접 확인했다. 원본의 HEAD·추적 파일·인덱스는 리뷰 전후 동일했다.

독립 비판은 B1·I1·M2 일부를 채택하고 B2·I2·M1을 기각했다. 부모도 근거를 확인해 같은 평가를 적용했다. 새 회귀3개는 컴파일 후 0/3으로 실패했으며 제품 수정 후 3/3으로 통과했다. 다음 새 Opus와 Codex 재검토는 수정 커밋 후 실행한다. 이 기록은 최종 완료 판정이 아니다.
