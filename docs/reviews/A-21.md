# A-21 읽기 포트 3 리뷰 기록

## 브리프

A-21은 D-41의 투자자별 랭킹·섹터 목록/상세/랭킹·관련 ETF 조회를 MarketInfo에 추가한다. D-37/D-41 봉인 타입과 A-01/A-20의 Send Future·오류·capability 관례를 유지한다. 프로그램·공매도·신용·대차 수급은 정의 대기다. domain 계산/타입·testkit·tasks·progress는 변경하지 않는다. 기존 FakeBroker에 필수 메서드를 더하는 기계적 impl 변경만 사전 승인됐다. ADR은 무번호 초안이다. 실제 API·키·계좌 사용, push·PR·master 이동은 금지다.

## 비판과 실험 근거

- Opus는 application 테스트 79개 통과 및 OpenAPI 대조를 실행했다. 별도 target·복사 실험은 해당 세션 하네스의 environment/dynamic-target/git-alias 거절로 실행하지 못했다. 이를 우회하지 않았고 손 변형/타입 우회 검증 완료로 주장하지 않았다.
- Codex 비판은 별도 복사본에서 ADR 행 삭제와 입력 변경이 계약 테스트를 통과함을 확인한 뒤, 현재 29행과 실제 trait 29개 입출력이 일치함도 별도 대조했다. 직접 ADR을 읽어야 한다는 주장은 규칙에 반하므로 기각했다.
- SectorId는 ../accounts, 쿼리/fragment 문자, 41·64바이트 문자열을 실제로 허용했다. HTTP 구현은 이번 diff에 없어 경로 조작 발생은 확정하지 않았다.
- 기존 SectorRankingItem::sector, SectorCatalog::sectors, SectorMetadata::id/depth로 계층을 결합하는 외부 호출자 코드를 컴파일했다. 새 domain 타입은 필요하지 않았다.
- query 구조체 리터럴은 E0451, Default는 E0599, 필드 직접 변경은 E0616으로 거부됐고 정상 생성자는 컴파일됐다.
- 가짜 상세 시장 KR 고정은 기존 A-21 예제를 통과했다. query 시장 KR 고정은 두 테스트에서 실패했고 Unknown 종류 허용도 조합 테스트에서 실패했다. 원본 복구 후 통과했다.
- 비판자도 application 79개 통과를 확인했고 원본 HEAD/status를 보존했다. 실험 복사본은 제거했다. 전체 just check와 실제 API는 비판 범위에서 실행하지 않았다.

## 구현 검사와 승인된 변경

- 시작 기준 master는 735ea38189edbf15d34238dd14ac49bb02c9e94f다. pnpm frozen/ignore-scripts 설치와 lefthook install을 실행했다. 프로젝트 파일 hooks=true는 확인했으나 프로젝트 신뢰·세션 훅 실제 적용은 별도 확인 불가다. 홈 설정/자격 증명은 읽거나 변경하지 않았다.
- 첫 정상 훅은 matches! 금지를 발견했다. 규칙을 끄지 않고 소진 match로 고쳤다. 좁은 Clippy도 통과했다.
- 구현 커밋의 정상 훅은 전체 검사로 승격되어 workspace 1396개와 coverage 1047개를 통과했고 coverage-check 위반은 없었다. 이후 test-diff가 승인된 FakeBroker MarketInfo impl 추가 한 건만 지적했다. 후속 disable-report, 새 끄기 0, hooks-installed도 별도로 통과했다. 사용자 지시에 따라 이 커밋만 LEFTHOOK=0으로 만들고 사유를 메시지에 기록했다. 전체 just check 명령 자체의 종료는 해당 승인 항목으로 비정상이며 무조건 통과라고 보고하지 않는다.
- 승인 test-diff: crates/application/tests/ports.rs의 FakeBroker MarketInfo impl에 필수 5개 메서드 추가. 기존 master 테스트 함수 16개 본문 및 단언은 동일하다. 이번 브랜치의 새 테스트는 보강할 수 있다.
- 보호 생성물: .codex/config.toml은 새 ADR 읽기 전용 경로 등록, harness/claude-hooks/hashes.json은 해당 생성 설정 해시 갱신이다. 저장소 스크립트로 생성했다. 규칙/범위를 느슨하게 하지 않았다. 외부 의존성 추가와 검사 끄기는 없다.
- just mutants-diff를 기준 SHA로 한 번 실행했다. 선행 test-diff의 동일 승인 1건으로 종료되어 자동 변이는 NOT_RUN이다. 0개 검출이나 변이 통과로 세지 않는다.
- 최종 소스의 손 변형은 별도 빌드 디렉터리와 임시 복사본에서 27개 모두 실제 컴파일 성공 후 검출했다. 매 로그의 재컴파일, 원본 clean/recompile 기준 통과와 임시 소스 제거를 확인했다. 앞선 공유 빌드 디렉터리 실험은 최종 집계에서 제외한다. 변형별 표는 ADR 끝에 있다. 증거는 작업 사본 target/A-21/final-hand-NN.log, final-hand-results.json, isolated-baseline.log다.

## 사소 지적 반영 검증

application Clippy와 nextest 80개를 통과했다. 새 두 시장·두 ID 테스트로 sector/sector_etfs의 시장 KR 고정과 ID 고정 네 변형을 별도 소스 복사본과 빌드 디렉터리에서 실제 실행하여 모두 컴파일 후 검출했다. 원본 복구 뒤 같은 테스트도 통과했다. 증거는 target/A-21/fake-probe-1.log부터 fake-probe-4.log, fake-probe-baseline.log와 fake-probe-results.json이다. 원본 제품 소스는 첫 리뷰 이후 동일하며 수정은 ADR 인계·새 테스트 보강·리뷰 기록에 한정한다.
