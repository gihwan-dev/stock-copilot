구현과 수정은 사용자의 2026-11-17 결정에 따라 `gpt-6.1-terra` max가 직접 수행했다. 새 Claude Opus 5.5가 첫 구현을 적대적으로 리뷰했고, 별도 새 Codex에 `gpt-6.1-sol`로 비판을 요청했다. 첫 비판 스레드의 실제 실행 모델 메타데이터는 제공되지 않았다. 프로젝트 신뢰 설정과 세션 훅의 신뢰·적용 상태는 각각 확인하지 못했다. 첫 커밋에는 일반 Git 훅이 적용돼 통과했다. 수정 커밋의 첫 훅은 검사 목록 등록 누락과 Tailwind 클래스 후보 혼입을 발견해 실패했으며, 각각 정확한 등록과 새 테스트 전용 파일의 소스 검색 제외로 수정했다.

1차 리뷰는 고정 Chromium에서 예제와 이야기 실행, WKWebView 예제, 보호 등록, 누락 검사 등을 확인했다. 리뷰어 역할의 훅이 합성 파일 작성과 인라인 코드·동적 셸 명령을 막아 손 변형·타입 실험은 실행하지 못했고 우회하지 않았다. 1차 비판자는 의존성이 설치되지 않은 별도 사본에서 소스와 문서를 대조했으며 브라우저·타입·변이 실행 검증은 하지 못했다.
