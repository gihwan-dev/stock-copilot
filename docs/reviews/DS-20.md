1차 리뷰는 고정 Chromium에서 예제와 이야기 실행, WKWebView 예제, 보호 등록, 누락 검사 등을 확인했다. 리뷰어 역할의 훅이 합성 파일 작성과 인라인 코드·동적 셸 명령을 막아 손 변형·타입 실험은 실행하지 못했고 우회하지 않았다. 1차 비판자는 의존성이 설치되지 않은 별도 사본에서 소스와 문서를 대조했으며 브라우저·타입·변이 실행 검증은 하지 못했다.

2차 적대적 리뷰는 새 Claude Opus 5.5가, 비판은 별도 새 Codex에 `gpt-6.1-sol`을 요청해 수행했다. 비판 스레드의 실제 실행 모델 메타데이터는 제공되지 않았다. 두 작업 사본에는 의존성이 없었고, 홈 접근 금지와 역할 훅을 지켜 설치·브라우저 실행을 우회하지 않았다. 이 회차의 브라우저 실험과 변이 검사는 구현 작업 사본에서 별도로 수행한 결과다.

3차 적대적 리뷰는 새 Claude Opus 5.5가 수행했다. 비판은 별도 새 Codex에 `gpt-6.1-sol`을 요청했으나 실제 실행 모델 메타데이터는 제공되지 않았다. 리뷰어는 설치·스크립트 실험을 역할 훅과 홈 접근 제한 때문에 실행하지 못했다. 비판자는 의존성 누락으로 Node 테스트가 로드 단계에서 실패했고, 출력 잘림 때문에 전체 문서와 diff를 확인하지 못해 비판을 미완료라고 보고했다. 이 제한을 승인으로 취급하지 않고 구현자가 아래 반례를 별도로 실행해 평가했다. 추가 적대적 리뷰는 실행하지 않았다.

같은 3차 리뷰를 보완하는 새 `gpt-6.1-sol` 비판도 전체 문서·diff와 실행을 확인하지 못해 미완료였다. 이후 같은 리뷰의 지적을 계약·통합, 기하·엔진, 자료·방어 세 범위로 나눠 각각 새 Codex `gpt-6.1-sol`에 비판을 요청했다. 실제 실행 모델 메타데이터는 제공되지 않았다. 세 비판은 배정된 13개 지적에 대한 정적 판정을 제공했지만 브라우저와 변형 실험은 실행하지 않았다. 자료·방어 비판자는 관련 diff의 잘린 부분을 모두 재조회하지 못했다고 밝혔다. 따라서 이들의 정적 반론과 구현자가 별도로 실행한 증거를 구별한다.

자료·방어 비판자는 보유 종목이 전부 빠지면 기존 차트 테스트가 검출하므로 그 반론 범위에서 3-6을 일부 기각하고 사소로 평가했다. 구현자는 다른 반례인 마지막 한 행만 거부하는 컴파일 가능한 파서 변형과 Markdown 파싱 실패 변형이 당시 일반 카탈로그 검사를 통과함을 실행으로 확인했다. 이 실제 검출 공백 때문에 3-6을 중요로 평가하고 수정했다. 계약 비판자가 중요로 평가한 3-7은 이 작업 범위 밖의 기존 Text 계약 불일치여서 DS-11에 인계한다.

3차에서 실행으로 재현한 중요 지적 3-3·3-6의 수정 범위는 위 4행이다. 고정 Chromium 예제 79개, 일곱 확인 독립 실험, 컴파일 가능한 검사 함수 변형 53개와 파서 변형 2개를 수정 범위에 대해 실행했다. 전체 카탈로그 1,034개 이야기의 네 조건을 재측정했고 WKWebView 합성 예제 24개를 확인했다.

## 메인 평가

- 판정: 수용(남은 판정은 후속으로 분리). harness 4.4의 일곱 넘침 확인을 하는 검사 함수와 보호된 부하 자료, 공개 컴포넌트 30개의 부하 이야기가 들어왔다. 확인마다 독립 실패 예제가 있고, 확인 하나를 빼면 해당 예제만 영향을 받는다. 구현 모델은 `gpt-6.1-terra`(max), 리뷰 3회차(등급은 브리프에 없었고 메인이 3으로 지정).
- 메인 결정: Vitest 브라우저 모드 제공자 `@vitest/browser-playwright` 5.1.0을 이 패키지 하나에 한해 승인했다(브라우저 바이너리는 DS-15의 것을 재사용).
- 사실대로 적어 둘 것: 넘침 실행기를 전체 부하 이야기에 돌리면 174개 이야기·544조건에서 판정이 남아 종료 1이다. 이 실행기는 아직 `just check`의 문이 아니다. 남은 판정에는 검사가 지나치게 잡는 것(숨긴 접근성 표, 1px 글꼴 지표, 입력 내부 스크롤)이 섞여 있어 결함 수로 읽지 않는다. 해소와 문 편입은 DS-22로 등록했고 DS-12는 DS-22 뒤에 한다.
- 검증의 한계: 비판자들의 브라우저·변이 실행은 이루어지지 않았고(구현자가 반례를 따로 실행), 실제 Tauri 창·WKWebView의 hit-test는 실행되지 않았다. 첫 훅에서 기존 Rust 훅 회귀 테스트 한 건이 실패했다가 재시도에서 통과했다(원인 미확정, 다른 작업들에서도 같은 계열 관찰).
