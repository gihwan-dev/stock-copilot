구현·수정은 2026-11-17 사용자 결정에 따라 Codex `gpt-6.1-terra` max가 직접 한다. 1차 적대적 리뷰는 새 Claude Opus 5.5, 비판은 별도 Codex `gpt-6.1-sol`이 수행했다. 프로젝트 신뢰와 세션 훅 정의 신뢰는 각각 확인하지 못했고, 확인용 Git 명령은 거부되지 않았다. Git 훅과 별개로 세션 훅이 강제됐다고 주장하지 않는다.

1차 수정의 정상 커밋 훅은 전체 Rust 테스트 2,034개와 커버리지 테스트 1,115개가 통과한 뒤, 이미 승인된 기존 테스트 기대값 4건을 최초 분기점 기준으로 다시 감지해 커밋을 거부했다. 이후 사용자는 전체 정리를 workspace 정리로 되돌리고 관련 기존 테스트 기대값도 복원하기로 결정했다. 후속 커밋에서도 최초 분기점 기준의 승인된 테스트 변경만 남을 때는 다른 검사가 모두 통과한 뒤 사유를 적어 예외를 쓸 수 있다고 명시했다. 반복 측정 결과 씨앗을 제거한 뒤 정상 훅으로 축소 변경을 커밋했다.

2차 적대적 리뷰는 새 Claude Opus 5.5, 비판은 별도 Codex `gpt-6.1-sol` high가 수행했으며 차단·중요 지적은 없었다. 리뷰어는 하네스의 `role-without-writes`·`misplaced-config` 차단으로 변형을 직접 실행하지 못했고 `cwd-unknown` 차단으로 리뷰어 사본의 작은 임시 폴더도 지우지 못했다. 비판자는 자기 사본의 무시되는 임시 영역에서 별도로 20개 변형과 종료 훅 반례를 실행한 뒤 정리했다. 구현자는 각 리뷰 뒤 대상 HEAD와 작업 사본이 변하지 않았음을 확인했다.
