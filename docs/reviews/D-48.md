# D-48 평가 누락일 계획과 가격 증거 리뷰

## 브리프

D-48: 마지막 스냅샷과 KST 오늘 사이 누락 평가일의 순수 계획, 모든 계획일의 채움/채우지 못함 사유, 종가·장중·휴장 이월 가격 증거와0 판정. 기존 domain 타입을 재사용하고 application은 변경하지 않는다. 주말·연휴·연말·KST 자정·마지막 날짜 경계 예제 및 중복/누락/날짜별 결과 속성을 검증한다. 작업 사본만 사용하며 master 이동·푸시·PR·실제 키·계좌·API·홈 설정 접근은 금지다.

사용자는 필요한 새 파일의 보호 등록과 공식 생성물·해시 변경, 번호 없는 ADR 초안을 명시 승인했다. 검사 규칙 약화·기존 테스트 약화는 승인하지 않았다. 테스트 변경 승인(a~d)은 이번 작업에서 사용하지 않았다. 최초 테스트는 구현 뒤 실행했으므로 구현 전 red 증거는 없다.

## 독립 재현과 한계

1차 Opus는 기존 D-48 테스트9개 통과. 저장소 실험 파일 쓰기가 role-without-writes에 거부돼 우회하지 않았으며1~3·6번은 추정이었다. 1차 Codex 비판은 target의 독립 소비자에서 공개 API를 경로 의존성으로 실행했고 추적 파일·인덱스·HEAD·참조는 변경하지 않았다.

- R1: `dates=[1970-01-03] success=true kr_basis=AwaitingSession price_date=1970-01-02`. 빈 계좌 실험이므로 비0 보유 손익 고착까지 증명하지 않음.
- R2: `missing_middle=Err(CalendarMismatch)`. 완전 입력의 누락을 거부하는 규칙은 유지하며, 별도 unavailable 입력으로 날짜별 획득 실패를 표현하도록 수정.
- R3: 오래된 미국 달력과 행 사이 역행 수용. 미국 현지 날짜·최신성 공급 계약의 위험으로 기록.
- R6: `foreign_calendar_success=true usd_date=1970-01-02`. 수정 회귀는 같은 결제일의 다른 미국 날짜와 양 통화 각각의 가격 기준 불일치를 거부.

비판의 전체 check-fast는 미완주로 통과 근거에서 제외했다. 1차 리뷰 전후 원본 HEAD·브랜치·인덱스·추적 파일·작업 트리가 동일했음을 스냅숏으로 확인했다. 비판자는 별도 사본의 시작·종료 clean을 보고했다.

## 검사

초기 정상 커밋 시도는 glob-import로, 다음은 커버리지 미실행 분기·테스트 파일 배치로 실패했다. 규칙을 바꾸지 않고 명시 import, 도달 불가능 경로 제거, 오류 경로 테스트, cfg(test) 모듈 배치로 수정했다. 62213bcc의 정상 훅은 전체 just check·커버리지·test-diff·hooks-installed 통과, 새 검사 끄기0건이었다.

수정 회귀12개와 Clippy 통과. 집중 커버리지에서 두 생산 파일의 미실행 줄·영역0개. 손 변형28개 중26개 컴파일 후 검출,2개 컴파일 불가 제외,생존0개. 사본의 마지막 변형을 원본에서 재구성한 값과 대조하고 원복 소스의 SHA-256을 확인했고 valuation_ 필터 대조군55개가 통과했다. R6 회귀는 수정 전62213bcc에서 실패하고 수정 소스에서 통과했다(수정 후 기준 판 대조). 수정 후 just mutants-diff(기준994c25a)는18개 중10개 검출·8개 컴파일불가·생존0·시간초과0으로 통과했다. 최종 전체 검사 결과는 완료 뒤 추가한다. 프로젝트 신뢰·세션 훅 신뢰 적용은 확인 불가이고 Git lefthook 설치와 실제 정상 커밋 검사만 확인했다. 환경 예외·LEFTHOOK=0 사용 없음. 외부 의존성·주석·검사 끄기 추가 없음. 보호 변경은 새 ADR 등록용 공식 config/hash 생성물이다.
