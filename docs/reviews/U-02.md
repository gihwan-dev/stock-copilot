메인 수정 afc9a3f9841832585bcc48fe122e4f36cd27b367을 정상 --no-ff 병합으로 수신했다(674d0a8f277d83afe81db3859b4c440268b5a0e9). 20개 파일의 스테이징 패치를 보관·복원하고 동일성을 확인했다. fixture 테스트는 직접 수정하지 않았다. 앞의 막힘·미실행 표는 최초 시도의 이력이다. 독립 리뷰와 최종 검사 결과를 이어서 기록한다.

## 입력 DTO와 명령 검사 보완

재개 후 정상 훅은 disable-check에서 기존 AppHandle 명령의 needless_pass_by_value 예외를 거부했다. 입력 DTO가 추가되어 모든 인자가 주입 타입이어야 한다는 좁은 예외 조건을 벗어났기 때문이다. 예외 정책을 넓히지 않고 app_version을 async fn으로 전환했다. 기존 두 expect를 제거한 상태로 Clippy all-targets가 통과했고 TS 재생성 내용은 동일하다. 응답 테스트는 block_on 호출로 기계적으로 갱신했다.
