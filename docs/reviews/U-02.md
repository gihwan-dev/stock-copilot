Opus는 하네스의 읽기 전용 역할 제약으로 컴파일 우회·손 변형·실제 invoke/emit 실험 파일을 쓰지 못했다. Codex 비판자는 실험 파일을 만들었지만 당시 Xcode 환경 오류로 Rust 실행을 완료하지 못했다. 이 두 한계를 실행 성공으로 간주하지 않았다. 이후 메인이 승인한 환경에서 구현 담당이 수정본과 mount 제거 변형을 실제 실행했다.
