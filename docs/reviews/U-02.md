최종 수동 test-diff의 첫 호출은 병합 중 수신 커밋이 아직 HEAD의 조상이 아니므로 기준 종류 검사에서 멈췄다. 정상 훅과 같은 commit 기준 모드로 다시 실행해 수신 master를 비교 기준으로 확인했고, 원 지시문이 승인한 진단 5개만 남았다. 마지막 disable-report·기준 이후 새 끄기 0·hooks-installed도 통과했다.

정상 훅의 전체 검사 종료 코드는 R4 환경 실패로 1이다. 나머지 검사는 위의 사전 승인 test-diff 5개를 제외하고 모두 통과했으며, 알려진 환경 실패 외의 미해결 실패는 없다. 최종 병합 커밋에 한해 환경 안내 2와 원 지시문의 test-diff 예외로 LEFTHOOK=0을 적용하고 사유를 커밋 메시지에 남긴다. 환경 테스트·훅·0099 fixture를 고치지 않았다.

최종 근거는 target/U-02/final-merge-commit.log, final-remaining.log, final-remaining-after-registration.log, final-test-diff.log, final-post-test-diff.log다. 마지막 기록·설정·해시 검증은 결과 기재 뒤 다시 실행한다. 실제 WebView 전달·ACL과 실제 토스 API 검증은 이번 결과에 포함하지 않는다.
