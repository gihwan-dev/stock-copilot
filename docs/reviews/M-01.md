## 리뷰 (회차 1)

| 번호 | 등급 | 지적 | 평가 |
|---|---|---|---|
| 1 | 차단 | `mcp-server` 변경분 변이 미검출 30건·시간 초과 1건(`signal_shutdown`) | 확정. `socket.rs` 메타데이터 검증을 순수 검사 함수(`check_ancestor_dir_ownership`·`check_run_dir_metadata`·`check_socket_metadata`)로 분리해 경계 단위 테스트를 추가하고, `Debug` 구조·가림 표식 단언, 유한 시간 `shutdown()` 대기와 반환 이벤트 확인, 중복 `||` 제거 및 `verify_run_dir_0700` 무조건 `0o700` 적용으로 보강. ADR 0173 절차에 따라 자동 변이 재실행·2차 리뷰는 생략 |
| 2 | 중요 | 기대 부모 PID를 `start()` 시점에 고정해 `architecture.md` 2.3 순서와 맞지 않음 | 확정. `PeerProcessTarget::pending_parent`를 신설해 결합 전 연결을 `ParentPidUnbound`로 닫힌 실패 거부하고, CLI 기동 직후 `McpServerHandle::bind_expected_parent_pid`로 1회 한정 결합하도록 수정(재결합 시 `ParentPidAlreadyBound`) |
| 3 | 중요 | 토큰 만료 뒤에도 초기화 전·`discover` 뒤 `ping`이 성공 응답하고 유휴 세션이 동시 연결 슬롯을 점유 | 확정(비판자 실행 재현). `ExpiryGuardedReader`·`ExpiryGuardedWriter` 전송 경계에서 매 `poll_read`/`poll_write`마다 `ensure_active()`를 강제하고 `wait_for_expiry` 유휴 감시와 `watch::Sender<SessionStopSignal>`로 즉시 연결 종료·슬롯 반환하도록 수정. 기본 `ServerHandler` 알림·미구현 요청(비판자 추가-2)도 전송 경계에서 함께 차단 |
| 4 | 중요 | 기반 폴더 소유자·권한 미검사 및 상위 경로 심볼릭 링크 허용 | 확정(비판자 실행 재현). `collect_ancestor_prefixes`로 `/`부터 `base_dir`까지 모든 조상 경로의 심볼릭 링크 거부, sticky 없는 그룹·타인 쓰기(`0o022`) 거부, 본인·루트 외 소유자 거부를 추가하고 회귀 테스트로 검증 |
| 5 | 사소 | TTL 30분을 유휴 시간이 아닌 발급 기준 절대 수명으로 적용 | 확정. M-01 단독 완료 기준 위반은 아니며 `McpServerConfig::try_new`로 최대 24시간까지 조정 가능. ADR M-01 정의 대기 표에서 R-04:70이 유휴 타임아웃임을 정정하고 AI-02·C-09에서 결정하도록 인계 |
| 6 | 사소 | 공개 API(`authenticate_and_serve_stream`·`McpSkeletonHandler::new`)로 피어·인증 검증 없이 MCP 제공 가능 | 확정(비판자 추가-1 포함 실행 재현). `McpSkeletonHandler`·`authenticate_and_serve_stream`·`StreamAuthParams`·`RunAuthBinding`·`verify_peer`·`BoundRunSocket` 등을 `pub(crate)`로 닫아 `McpServerHandle::start` 단일 진입점만 공개 |
| 7 | 사소 | `listener.accept()` 오류를 버리고 백오프 없이 즉시 재시도 | 확정. `ConnectionEvent::AcceptFailed`를 기록하고 `classify_accept_error`로 치명 오류는 루프 종료, 일시 오류는 종료 신호와 경주하는 50ms 백오프 적용 |
| 8 | 사소 | `ConnectionEventLog`가 상한 없이 무한 증가 | 확정. `VecDeque` 기반 256건 상한 순환 버퍼(`ConnectionEventLog::with_capacity_limit`)로 제한하고 단위 테스트 추가 |
| 9 | 사소 | TCP·chrono·pastey·unsafe 금지 소스 검사가 하위 폴더를 순회하지 않음 | 확정(비판자 실행 재현). `collect_rust_sources_recursive` 재귀 순회로 수정 |
| 10 | 사소 | 동기 `McpServerHandle::start`가 Tokio 런타임 밖에서 패닉 | 확정(비판자 실행 재현). `tokio::runtime::Handle::try_current()`로 선확인해 폴더·토큰 생성 전 `McpServerError::RuntimeUnavailable` 반환하도록 수정 |
