## 1차 수정 검사

정상 커밋 훅의 전체 검사는 Rust 테스트에서 기존 Git 훅 회귀2건으로 중단됐다. 한 건은 commit-guard 하위 프로세스 signal9, 다른 한 건은 정상 fixture 커밋 거부였다. 소스 변경 없는 좁은 재실행은2/2 통과했다. 원인을 확정하지 않는다. 같은 소스에서 속성 횟수4096을 유지하고 동시 실행 수4로 전체를 다시 실행해1669/1669·건너뛰기0을 확인했다. 전체 검사의 다른 정적·프런트·정책 단계는 정상 훅에서 통과했다.

커버리지 단독 실행에 전체 검사의 속성 환경 전달을 누락한 시도는 기존 domain 미도달12건으로 실패했다.4096 환경을 명시한 최종 재실행은1059/1059, coverage-check 위반 없음이다. test-diff는 계속 사전 승인된16건만 보고한다. 해당 커밋에만 사용자 명시 예외를 적용한다. 검사 정책·기존 단언은 바꾸지 않았다.

수정된 소스를 mktemp 사본에서 다시 손 변형해 유효21개를 검출했다(당시22개 집계는 아래 정정 참조). 컴파일불가1개는 제외했다. 전후 대조군은 각각 신규11개 통과다. 원본에 변형을 적용하지 않았다. 실제 자동변이 실행을 대신한 통과 주장으로 쓰지 않는다.
