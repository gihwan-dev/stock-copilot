## 메인 평가

- 판정: 수용. 승인 행이 있어도 해소되지 않는 지적마다 왜 거부됐는지(해시 불일치, 누락, 구조 보존 규칙의 어느 조건)를 출력한다. 판정 자체는 바꾸지 않았다. 조사 결과 A-27·S-06/S-07의 승인이 해소되지 않은 것은 해시가 아니라 ADR 0141의 구조 보존 규칙 때문이었다. 실측으로 확인한 운영 지침: 단언 인자의 고정 목록에 항목을 더한 변경(A-14형)은 승인 행에 `assertion_change = true`를 주면 해소된다. `match`·`if let`·`matches!`·`let … else` 안의 타입 이름 변경은 해소되지 않으며 정식 예외 절차가 문서에 없다 → H-62로 등록해 정한다(그때까지는 병합 커밋을 따로 전체 검사해 승인된 건수만 남는지 확인하는 절차를 쓴다).
- 등급 2·2회차. 1차 지적 4건(차단 1, 중요 2, 사소 1)은 모두 재현 뒤 고쳤고 2차는 사소 지적만 남아 보완했다. 구현은 Codex 한도 초과로 Antigravity(gemini-4-neon)가 이어받았고 실행 기기도 옮겼다.
