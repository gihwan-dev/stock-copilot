2차도 새 Opus 5.5와 새 Codex gpt-6.1-sol을 각각 T3 격리로 실행했다. 두 결과에서 재현된 차단·중요는 0건이다. 구현 보고서를 제공하지 않았으며 전후 원본 스냅숏 차이는 각각 0건이었다.

Opus는 역할 훅이 막은 손 변형을 실행했다고 주장하지 않았다. Codex 비판자는 파일 변경 없이 메모리 실행으로 글꼴과 서버 오류를 재현했다. RV-17의 직접 적용과 실제 macOS 앱의 특정 글꼴이라는 원문 주장은 범위를 줄였으며, 확정 근거는 원래 Storybook과 촬영 경로의 차이 및 harness 6.6이다. 최초 기준 이미지와 필요한 보호 파일 등록은 작업 지시문의 구체적 사전 승인 범위다.

통합 실측에서 clock.install 직후 같은 목표 시각으로 pauseAt할 때 이미 시간이 지나 과거로 이동 오류가 나는 경합을 추가 재현했다. 설치와 정지 사이 1ms 경과 회귀의 red를 확인한 뒤 빈 페이지에서 epoch 설치 → 목표 시각 정지 → 이야기 탐색 순서로 수정했다. Node 22개 green, 실제 컨테이너 8쌍 바이트 일치를 확인했다. 목표 시각·PNG·글꼴 기준은 동일하다. 마지막 독립 리뷰 대상에 이 변경도 포함한다.
