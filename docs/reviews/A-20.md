## 독립 검증과 한계

Opus가 실험 테스트 파일을 작성하려 하자 main-docs-only 훅이 거부했다. 다른 경로로 우회하지 않았으며 지원 조합 독립 계산·외부 타입 우회·손 변형은 해당 리뷰에서 미검증이다. 기존 application45개 테스트 통과 및 문서·소스 대조만 수행했다. 이 제한을 비판자에게 전달했다.

ADR0068에서 독립 작성한 랭킹 지원 표448조합은 수락320·거부128로 일치했다. 비공개 RankingQuery 조립, BrokerRead의 rankings 접근, 주문 식별 quotes 입력, 미지 시장 calendar 입력은 각각 E0451/E0599/E0308/E0308로 거부됐다. 컴파일 가능한 손 변형6개(limit고정2, 미지/실시간검증2, capability1, Order분류1)는 모두 테스트가 검출했다. 비판자 작업 사본은 복구 후 깨끗했다. 실제 키·계좌·API는 사용하지 않았다.

Rust 소스·테스트는 자동 병합됐으며 수동 코드 수정은 없었다. 병합 후 application75/75(오류 분류7개 포함)가 통과했다. 새 master0739990 기준 정상 커밋 훅은 check-fast를 선택하고 전체 검사로 승격했다. 전체1323/1323·coverage975/975, 커버리지 위반0을 확인했고 그 외 선행 검사도 통과했다. test-diff는 정확히15건만 보고했다: support-modified8건(Order 소진 도우미1·호출/자료 도우미5·필수 impl2), import 재편에 따른 support-removed2건·shadowing2건, 승인된 서명·타입 이관의 modified3건이다. 기존 단언의 삭제·완화는 없다. 중단 뒤 disable-report·disable-report-since·hooks-installed도 통과했고 새 검사 끄기는0건이다.
