# 리뷰 기록 A-16

## 브리프

- 기준 커밋: 16b4c54080d976006659bd1d6954c9b0a7f11dda, 브랜치 a-16.
- 작업: TakeValuationSnapshot과 빠진 날 재계산. 일별 평가를 저장한 뒤 계좌 키 이벤트를 한 번 낸다(I-09, ADR0065).
- Clock과 기존 domain 계산만 사용한다. 필요한 domain 함수·타입·포트가 없으면 새로 만들지 않고 정의 대기와 작업 ID별 인계를 남긴다.
- 가짜 테스트는 testkit-ports/tests. 기존 테스트 약화·주석·실제 키/계좌/API·새 외부 패키지·push·PR 금지.
- 구현·수정은 이 T3 gpt-6.1-sol 사본에서 직접 수행한다. 새 Opus5.5 리뷰와 새 Codex 비판, 최대3회차, 실제 손 변형20개 이상, 변경분 변이, 최신 master 수신을 요구한다.

## 독립 검증과 한계

매번 새 Opus5.5와 새 Codex gpt-6.1-sol을 T3 격리 사본으로 실행했다. 구현 보고서는 주지 않았다. Opus는 executedModel을 확인했고 Codex는 선택 모델이 gpt-6.1-sol이며 T3의 별도 executedModel은 반환되지 않았다. 원본 추적 파일 SHA256·인덱스·HEAD·ref·상태를 회차 전후 비교해 동일함을 확인했다(target/A-16/before-review*.json, after-review*.json).

Opus 세 회차는 기존 테스트와 소스 대조를 수행했으나 role-without-edits/cwd-unknown/dynamic-target/git-alias 하네스 거부로 새 반례·손 변형을 실행하지 못했다. 이를 실행 확정으로 세지 않았다. 새 Codex 비판자는 각 자기 사본 target 아래에서 반박·반례를 실행했다. 1차는 과거/마감 전 및 FX 변형, 2차는 실제 KR세션14:00 현재가의 직전 가격일 저장, 3차는 KR09~15:30KST/US14:30~21UTC 및 휴장·16:00 입력을 재현했다. 최초 KR fixture의 SymbolMismatch/MissingTradingStatus는 결함 재현으로 세지 않았다.

타입 경계 실험은 private 생성자 E0624와 ValuationSnapshot.source 직접 변경 E0616으로 거부됐다. 컴파일 거부를 변이 검출로 세지 않는다. 비판자의 제품 손 변형이 금지돼 입력 조합만 바꾼 회차는 제품 변형 NOT_RUN으로 구분한다.

## 3차 지적 수정

정확한 원 지시의 최대3회차 예외에 따라 이번 확정 지적을 수정하고 4차 독립 리뷰는 하지 않는다. 최종 수정의 평가는 메인에게 인계한다.

통화별로 보유가 있거나 보고 valuation의 해당 통화 값이 Some일 때만 가격 증거를 요구한다. 두 자료가 모두 없으면 기존 domain이 만드는 정확한 0을 사용하며, 보유 없는 USD의 AwaitingSession/HolidayCarry를 이유로 안전한 기록을 막지 않는다. 보고 USD null도 이 구조에 해당한다. 금액 0 판정을 application에서 계산하지 않는다. Some인 0 보고·0수량 보유의 추가 생략은 D-31의 전용 계약으로 남긴다.

올바른 KR fixture와 새 수용 기준을 d686d1d1의 별도 복사본에서 실제 실행해 15개 중4개 실패(빈16시·국내전용16시·USD null 보고16시·휴장 빈 계좌),11개 통과를 확인했다(target/A-16/final-regression-red.log). 초기 잘못된 Symbol fixture 실패는 제외했다. 수정 후 통합16개·가짜 없는 순수5개·clippy가 통과했다(target/A-16/final-narrow.log, final-clippy.log). 비0 장중·미국 휴장 관측은 여전히 저장·이벤트0회다. 달력 날짜를 바꿔 성공시키지 않는다.

## 검사와 환경 예외

정상 Git 훅은 지정된 session-r1 R4 Xcode 라이선스 한 건만 실패했을 때에만 남은 check-ts와 check 본문을 순서대로 직접 실행한 뒤 해당 커밋에 승인 LEFTHOOK=0 예외를 적용한다. 첫 후속 검사에서 발견한 새 테스트 glob-import는 고친 뒤 정상 훅을 재실행했고 그 상태에서 나머지 검사 통과를 확인했다.

초기 커밋 근거는 commit2.log/environment-check.log/remaining-check.log(전체1810·커버리지1070),1차 수정은 fix-commit.log/fix-environment-check.log(1815·1071),2차 수정은 review2-commit.log/review2-environment-check.log(1819·1073)다. 모두 target/A-16 아래에 있다. 검사 전용 복사본의 기준 실패는 결과를 세지 않고 새 독립 빌드 출력에서 재검증한다.

프로젝트·훅 정의 신뢰 및 세션 적용은 확인 불가, Git lefthook 설치는 확인했다. 보호 변경은 사용자 지시가 승인한 새 ADR 경로의 .codex/config.toml 및 공식 생성 harness/claude-hooks/hashes.json뿐이다. 기존 master 테스트 변경0건, 새 의존성0개, 새 포트0개, 새 가짜 메서드0개, 새 검사 끄기0개다. 최신 master에서 받은 변경은 구현자가 직접 바꾼 테스트로 세지 않는다.

## 최종 수정 변이

최종 소스의 자동 변이는12개 중9개 검출·3개 컴파일불가·생존0·시간초과0이다(target/A-16/final-mutants.log). 손 변형은 새 고유 출력의 기준 통과 뒤35개 전부 컴파일·검출했고 원복 대조군도 통과했다. 변형마다 application 순수 테스트와 testkit-ports 통합 테스트를 함께 실행했다. ADR 끝에 각각의 증인을 기록했다. 공유 출력에서 기준이 불일치한 실행과 초기 컴파일 불가 변형은 집계하지 않았다.

3차 지적의 최종 수정 정상 훅은 지정된 R4 라이선스 한 건만 실패했다(final-fix-commit.log). 남은 check-ts와 check 본문을 직접 순차 실행하여 전체1828개·커버리지1075개·test-diff·모든 후속 검사가 통과했다(final-fix-environment-check.log). 해당 수정 커밋 한정 환경 예외를 적용한다. 그 뒤 최신 master를 작업 브랜치로 병합하고 통합 검사를 다시 수행한다.

## 최신 master 통합

a8d20344ebdcf8d1044189a97cce531b8b41c0af을 --no-ff로 받는다. lib.rs 충돌은 A-16과 A-17/A-22 등록을 모두 보존했다. 설정·해시 충돌은 한쪽 생성물을 출발점으로 선택하고 공식 쓰기 명령으로 통합 경로를 재생성했다. tasks/progress와 A-17/A-22 소스·테스트·ADR·리뷰 기록은 master에서 받은 그대로다. A-16 소스와 테스트의 SHA256은 손 변형35개를 실행한 hand-source-proof.json과 일치한다. 3차 지적 수정 범위는 위 표의 d686d1d1 → 2b45073f이며 4차 독립 리뷰는 없다.

## 최종 통합 검증

병합 정상 훅은 지정된 session-r1 R4 Xcode 라이선스 테스트 한 건만 실패했다(final-merge-commit.log). 실제 incoming 기준은 a8d20344ebdcf8d1044189a97cce531b8b41c0af이다. 남은 check-ts·check를 순차 실행해 전체1851개·커버리지1080개 및 coverage-check가 통과했다(final-merge-environment-check.log).

최초 수동 test-diff와 변이 명령은 병합 전 incoming을 일반 조상으로 검사해 선택/검사 전에 중단됐다. 실행·검출로 세지 않는다. 정상 커밋 훅과 동일한 STOCK_COPILOT_BASE_USE=commit 문맥으로 정확한 incoming 기준을 다시 검증했다. test-diff·disable-report·disable-report-since·hooks-installed가 모두 통과했다(final-merge-remaining.log). 최종 자동 변이는12개 중9개 검출·3개 컴파일불가·생존0·시간초과0이다(merged-mutants-final.log). 하네스·기준 검증 규칙을 변경하지 않았다.

최종 통합 소스·테스트는 손 변형35개를 실제 실행한 SHA256과 일치한다. 통합 생성물·리뷰 형식·fmt와 인덱스 검사를 확인한 뒤 이 병합 커밋 한정 승인 환경 예외를 적용한다. 원래 과거/미래 오류 원인별 J-11 처리와 ADR의 정의 대기 항목은 남은 인계이며, 전체 A-16 기능 완료로 표시하지 않는다. master 참조 이동·push·PR은 없다.
