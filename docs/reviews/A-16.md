## 독립 검증과 한계

회차1 리뷰는 새 Claude Opus5.5, 비판은 새 Codex gpt-6.1-sol이다. 구현 보고서는 주지 않았다. T3 격리 사본만 사용했고 원본 사본의 추적 파일 SHA256·인덱스트리·HEAD·ref·상태를 전후 비교해 동일함을 확인했다(target/A-16/before-review1.json, after-review1.json).

Opus는 기존 통합3개 통과와 코드 대조를 수행했지만 role-without-edits/cwd-unknown/environment/dynamic-target 하네스 거부로 반례파일·손변형을 실행하지 못했다. 실행 확인으로 세지 않는다. Codex 비판자는 자기 사본 target/a16-review-critic에서 반례5개를 실행했고 원본·제품·기존테스트는 수정하지 않았다. observe-fx제거는 기존3개 통과 후 외화검증 실패, evaluate-fx제거는 추가검증도 통과했다. private 생성자 우회 컴파일은 E0624로 거부됐다. 두 사본의 프로젝트·훅 신뢰 적용은 확인 불가다.

1차 수정 회귀는 수정 전6개 중2개 실패(과거/마감전), 수정 후 통과했다. 미래 기록과 Clock동일시각 허용도 검증한다. 개별 보유 시각과 SyncRecord 시각의 일관성을 판정하는 domain 계약은 정의 대기로 남기며 이 수정으로 모든 자료 신선도를 보장한다고 주장하지 않는다.

## 검사와 환경 예외

최초 정상 훅은 Xcode 라이선스의 session-r1 R4 한 건만 실패했다. 후속 수동 검사에서 새 테스트 glob-import를 발견하여 명시적 import로 고쳤다. 그 상태에서 예외를 쓰지 않고 정상 훅을 재실행해 다시 R4 한 건과 라이선스 문구만 실패함을 확인했다. check-ts의 남은 줄, check 본문 전체를 순서대로 실행하여 전체1810개·커버리지1070개·모든 후속 검사를 통과한 뒤 9a8d798 커밋 하나에 LEFTHOOK=0을 적용했다. 사유는 커밋 메시지에 남겼다. 로그는 target/A-16/commit2.log, environment-check.log, remaining-check.log다.

프로젝트 신뢰와 훅 정의 신뢰·세션 적용 확인은 불가, Git lefthook 설치는 확인했다. 보호 변경은 새 ADR의 쓰기 경로를 등록한 .codex/config.toml과 공식 생성 harness/claude-hooks/hashes.json뿐이다. 기존 테스트 변경 승인0건, 새 의존성0개, 새 포트0개, 새 가짜 메서드0개, 새 검사 끄기0개다.

자동 just mutants-diff는 최초 기준 대비2개파일에서1개 선택, 기준 통과, 컴파일 불가1개·생존0개였다. viable0이므로 자동 변이로 회귀 검출을 입증했다고 하지 않는다. 손 변형은 별도로 실제 실행하고 ADR 끝에 변형별 증인을 남긴다.

## 자동 변이 보완

Clock 미래 거부 추가 뒤 첫 자동 변이는3개 비교 연산자 변형 미검출·1개 컴파일 불가였다(target/A-16/fix-mutants-diff.log). application만 실행하여 testkit-ports 증인을 포함하지 않았다. 가짜 없이 비교만 수행하는 순수 시간 검증을 분리하고 application 단위 테스트에 과거·동일·미래 입력을 고정했다. 재실행은5개 중3개 검출·2개 컴파일 불가·생존0·시간초과0으로 통과했다(target/A-16/fix-mutants-final.log). 컴파일 불가를 검출로 세지 않는다. 순수 함수 분리 후 손 변형24개도 모두 다시 컴파일·실행하여 검출했고 기준·원복 대조군이 통과했다. 새 검사 끄기·가짜·의존성은 없다.

## 1차 수정 검사 확정

정상 수정 커밋 훅은 R4 라이선스 테스트 한 건만 실패했다(target/A-16/fix-commit.log). 그 뒤 남은 검사를 순서대로 실행하는 중 자동 변이 미검출을 발견해 순수 시간 검증을 분리했다. 최종 소스에 대해 application 경계 단위 테스트·testkit-ports 통합7개와 좁은 clippy를 다시 확인했다. 후속 소스/원시타입 검사와 전체 테스트1815개·커버리지1071개 및 test-diff·disable-report·hooks-installed는 보완한 최종 소스에서 모두 통과했다(target/A-16/fix-environment-check.log). 이후 변경은 이 검사 기록뿐이다. 정상 훅의 유일한 환경 실패와 직접 실행한 나머지 검사 근거로 수정 커밋 하나에 승인 환경 예외를 적용한다.
