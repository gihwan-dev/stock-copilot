# 리뷰 기록 D-01 (Money, Currency, 반올림, 시간 타입 ADR)

구현과 수정은 Codex `gpt-6.1-sol`(T3 스레드, 작업 사본 `d-01`). 리뷰어는 회차 1과 2에 각각 새 Claude Opus 5.5 서브에이전트. 회차 2의 대상은 `master`를 첫 부모로 둔 병합 커밋이다. 결정은 ADR 0025에 있다. D-03, DS-01, D-15, DS-13과 병렬로 진행했다.

**비판 단계를 생략했다.** 두 리뷰 모두 지적을 임시 crate에서 재현했고 메인이 전부 판정했다.

## 의존성

잠금 전이라 구현 담당이 허용 목록에 더했다. 사용자 확인 대상이다.

| crate | 버전 | 기능 | 구분 |
|---|---|---|---|
| `rust_decimal` | 1.43.0 | 기본 기능 끔 | 일반 |

## 리뷰 (회차 1)

| 번호 | 등급 | 지적 | 평가 |
|---|---|---|---|
| 1 | 차단 | `checked_add`·`checked_sub`가 `Ok`를 주면서 자릿수를 잃음(`MAX + 0.4`가 `Ok(MAX)`) | 수정: 정확하지 않으면 `PrecisionLoss` |
| 2 | 중요 | 속성 테스트 생성기가 정수뿐 | 수정: 전체 범위 생성기와 역연산·교환·결합 속성 |
| 3 | 중요 | "반올림은 표시 함수에만"이 구조로 강제되지 않음 | 수정: 구조 검사 규칙(허용 파일 밖의 `Decimal` 반올림 메서드 금지). 검사 끄기 없이 구현 |
| 4 | 중요 | 방향을 모든 금액 표시에 붙였고 액과 률이 엇갈릴 때 규칙 없음 | 수정: 방향은 변화량 표시에만. 방향은 반올림 전 변화량의 부호, 표시가 0인 숫자는 부호 없음 |
| 5 | 중요 | 시간 crate ADR의 후보 비교 부실 | 수정: `jiff` 비교, 토스 날짜 계약, chrono 경계 |
| 6 | 중요 | 문자열 생성자가 없어 경계 파싱이 조용히 반올림 | 수정: 정규형 검사 뒤 정확 파싱만. 손실 파싱은 구조 검사로 금지 |
| 7~12 | 사소 | ADR 서술, `Copy`, `deny.toml` 이유 문구, 남는 `normalize()`, `maths` 기능 메모 | 수정. `MoneyError`의 `Display`는 application 단계로 미룸 |

## 리뷰 (회차 2)

회차 1의 1·4·6번은 닫힘. 리뷰어가 4천만 건을 큰 정수 기준과 대조했다: 틀린 `Ok` 0건, 거짓 거부 0건.

| 번호 | 등급 | 지적 | 평가 |
|---|---|---|---|
| 1 | 중요 | `checked_mul`·`checked_div`·`checked_rem`도 `Some`을 주면서 반올림하는데 규칙 밖 | 수정: 곱·나눗셈·나머지 계열 금지, 허용 파일 목록은 비어 있음 |
| 2 | 중요 | 속성 테스트에 독립 기준이 없어 틀린 변형 두 개가 살아남음. 횟수 설정 없음 | 수정: 256비트 정수 기준과 대조, 4,096회 명시 |
| 3 | 중요 | `.map(Decimal::trunc)`처럼 경로로 넘기면 잡지 못함 | 수정 |
| 4 | 사소 | `MAX + 0.4`는 `PrecisionLoss`, `MAX + 0.5`는 `Overflow` | 수정: 범위를 넘으면 `Overflow` |
| 5 | 사소 | `to_f64` 등 실수 변환 | 수정 |
| 6 | 사소 | `"00"`, `"-0"`이 통과해 문자열 왕복에서 표현이 달라짐 | 파서는 architecture 6.3과 같아 유지. S 묶음에 넘김 |
| 7~9 | 사소 | 표시 문자열 재파싱 경로, ADR 사실 오류 | 수정 |

## 메인 결정

- 기존 테스트 변경 금지는 `master`의 테스트에만 적용한다. 구현 담당이 자기 브랜치의 테스트 수정 때문에 멈춰서 정했다.
- Clippy `disallowed-methods`와 끄기 조합 대신 구조 검사를 쓴다. 끄기 개수를 고정한 `master` 테스트를 바꾸지 않기 위해서다.

## 메모

- 회차 3에서 리뷰어의 생존 변형 두 개와 경로 참조 변형 두 개가 모두 테스트에 걸렸다. `just mutants-diff`: 192개 중 146개 검출, 46개 컴파일 불가, 생존 0개.
- `just check` 시간이 242초에서 260초로 늘었다(D-15 테스트 포함).
- 회차 3 수정분은 재리뷰하지 않았다.
- 구조 검사가 못 잡는 형태(타입 별칭, 추론형 `parse`, 함수 포인터 변수)는 ADR 0025의 표에 있고 알려진 빈틈 목록에는 아직 등록하지 않았다.
