# A-07 거래내역 동기화 리뷰 기록

## 브리프

`SyncTransactions` 유스케이스. 결제일 기준 최근 14일 창을 매번 다시 받아 같은 행의 개수까지 맞추고, 사라진 행은 지우지 않고 표시하며, 하루 한 번 전체 기간을 검사한다(I-06). 결과 저장 뒤 `TransactionsSyncRecorded`를 정확히 한 번 낸다(ADR 0065). 멀티셋과 날짜 창은 기존 domain 함수만 사용하고 없으면 정의 대기로 남긴다. 시각은 Clock, 날짜 경계는 KST다. 가짜 테스트는 testkit-ports/tests에 두며 application/domain 개발 의존을 추가하지 않는다. 기존 테스트 단언 약화, 주석, 실제 키·계좌·API, 홈 설정 수정, push·PR·master 이동을 금지한다. ADR 초안 하나와 독립 Opus 리뷰·새 Codex 비판·수정·재리뷰를 남긴다. 상세 결정과 후속 작업은 A-07 ADR 초안에 있다.

## 비판 증거

비판자는 원본 테스트 8/8 통과, 시계 검사 삭제 변형 8/8 생존, 추가 재현 원본 5/5 통과, 같은 변형에서 2개 역행 재현 실패를 확인했다. 저장 결과 조회 컴파일 실험은 E0599, 기존 가짜를 확장 포트로 쓰는 실험은 E0277이었다. 대량 사라짐과 취소 미확인 알림은 기록 안에 보존됨을 확인했다. 실제 UI·S-03 어댑터 경쟁·TooMuchHistory 직접 실행은 NOT_RUN이다.

비판자의 check-fast는 미완주다. 임시 파일에 따른 commit-guard 실패와 기본 PATH의 pnpm 오류 뒤 올바른 PATH에서 commit-guard 통과를 확인했으나, 문서 변경으로 전체 검사에 승격된 실행을 자신이 시작한 프로세스만 종료했다(143). 부모의 전체 검사 성공과 구별한다. 증거와 재현 사본은 비판 사본의 target/a07-critique에 보존했다.
