## 실행 증거와 한계

1회차 Opus는 기존 통합 테스트 7개·순수 테스트 4개·정적 검사·clippy를 실행했다. 임시 파일 편집은 `[role-without-edits] adversarial-reviewer는 파일을 편집하지 않는다`로 거부돼 손 변형·임시 타입 실험은 NOT_RUN이며 우회하지 않았다. 1회차 Codex 비판은 기존 통합 7개와 임시 재현 3개를 합한 10개, 순수 테스트 4개를 통과시키고 봉인 증거 Default의 E0599 컴파일 거부를 확인했다. 임시 파일은 원복했고 대상 HEAD와 사본 상태가 유지됐다.

루트 수정 후 좁은 테스트는 13개가 통과했다. 전체 nextest는 1,736개, 커버리지용 nextest는 1,066개가 통과했고 coverage-check·test-diff·훅 설치 검사에 위반이 없었다. 자동 변경분 변이는 선택 22·검출 17·컴파일 불가 5·미검출 0·시간 초과 0이다. 손 변형의 최종 실행은 컴파일 가능한 25개를 모두 검출했고 복구 대조군도 통과했다. 컴파일 불가 시도는 검출 수에서 제외했다. 변형별 표는 A-17 ADR에 있다.

2회차 Opus는 통합 8개·순수 5개·clippy·생성 파일 일관성을 통과시켰다. 임시 편집은 role-without-writes로 거부돼 추가 손 변형과 타입 우회는 NOT_RUN이다. 2회차 Codex 비판도 통합 8개·순수 5개를 독립 실행해 통과했고, 기존 코드 지적의 해소와 새 차단·중요 코드 결함 없음, N1/N2의 문서 보완을 확인했다. N1/N2는 문서만 직접 수정했으며 추가 독립 리뷰를 요구하는 코드 변경은 없다.

1·2회차 Opus 전후 루트의 추적 파일 해시 스냅샷 차이는 0건이고 HEAD와 작업 트리도 유지됐다. 비판 사본들은 각 대상 SHA와 깨끗한 시작·종료 상태를 보고했다. 원본 비교에는 추적 파일 SHA-256·HEAD·git status를 사용했다.

## 환경과 보호 경로

프로젝트 설정의 hooks=true는 확인했으나 프로젝트 신뢰·훅 신뢰와 루트 세션의 런타임 적용은 미확인이다. Claude 리뷰 사본에서 역할 편집 훅의 거부를 관측했다. 루트의 실제 Git 훅과 직접 검사 결과를 증거로 사용한다.

환경 예외 사용: 예. 정상 커밋 훅은 session-r1의 R4 한 건만 Xcode 라이선스 오류로 실패했다. 사용자 환경 안내 2에 따라 남은 check-ts와 check 본문을 순서대로 전부 실행해 통과한 후 해당 커밋에만 LEFTHOOK=0을 적용하고 사유를 메시지에 기록했다. 테스트·훅 코드는 바꾸지 않았다. 라이선스 명령은 실행하지 않았다.

새 외부 패키지·포트·가짜 메서드·기존 테스트 변경·새 검사 끄기는 0건이다. 기존 검사 끄기 6건은 그대로다. .codex/config.toml과 harness/claude-hooks/hashes.json은 새 문서의 읽기 등록과 해시를 기존 스크립트로 생성한 보호 파일 변경이다.

## 메인 평가

완료 보고와 리뷰 기록을 읽었다. 위험을 늘리는 다섯 변경은 확인이 `Confirmed`일 때만 저장되고 주문용 확인은 호출되지 않는다. 남은 차단·중요 지적이 없다. Xcode 라이선스 미동의로 훅 자가 테스트 한 건이 환경 탓에 실패해, 메인이 그 한 건만 예외로 둔 전체 검사를 병합 트리에서 다시 돌린 뒤 병합한다.
