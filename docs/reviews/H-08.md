## 메모

- 새 규칙이 정상 코드에 주는 제약: 변수 색인은 `.at(i)`, `Record`의 변수 키 조회 대신 `as const` 객체나 `switch`, 금액을 제네릭 함수에 직접 넘길 수 없음(`useState(money)` 등), `children`은 `ReactElement | UiText` 형태로 받음. 화면 작업에서 막히는 것이 나오면 ADR 0012를 고친다.
- 알려진 빈틈: `Object.values`로 꺼낸 키, 내보내지 않는 지역 값의 원시 타입, 라이브러리 props의 `string`, 영문 JSX 속성 (ADR 0012).
- 2회차 수정분은 재리뷰하지 않았다. H-09 리뷰 때 ESLint 설정 전체를 다시 본다.
