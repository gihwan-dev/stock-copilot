- 완료 기준: 일봉 종가와 평가 가격 증거의 장 종료를 정규장 종료로 판정하고 D-31·D-48·D-49가 같은 선택 규칙을 쓴다. 한국 정규장 09:00~15:30과 애프터마켓 15:30~20:00에서 16:00에는 당일 정규장 종가를 선택하고 종료 전에는 당일 종가 주장을 거부한다. 정규장만 있는 달력, 반일장·휴장·미국 전일 선택을 유지하고 장중 가격은 종가 증거로 받지 않는다.

## 구현 기록

첫 구현과 1차 수정은 각각 정상 Git 훅의 전체 검사에 통과했다. 2차 독립 비판은 관련 domain 테스트 98개와 testkit-ports 관측 테스트 17개를 통과시켰다. 2차 수정은 새 0 보고 테스트의 변형 실패와 원본 성공을 확인했다. 기준 d235aaf8의 정상 훅에서 전체 테스트 2087개와 커버리지 테스트 1159개가 통과했고 커버리지·기존 테스트 변경 위반은 없었다 (종료 0). 프로젝트 신뢰나 세션 훅 적용을 Git 훅 성공으로 추정하지 않는다. 이 기록은 master 병합의 충돌을 해소하면서 함께 추가한다. 첫 병합 훅은 H-44 테스트의 하위 `commit-recipe`가 신호 9로 종료돼 실패했다. 원인은 확정하지 못했으며 해당 테스트만 재실행해 통과했다. 두 번째 전체 훅에서는 다른 하네스 테스트 두 건이 실패했고 그중 하나도 하위 프로세스가 신호 9로 종료됐다. 두 테스트의 단독 재실행은 통과했다. 이후 master가 T-08·T-09·T-10까지 진행해 충돌 중인 병합을 보존 후 중단하고 최신 master로 다시 병합했다. 설정이나 테스트를 바꾸지 않은 마지막 병합 훅 결과는 최종 보고에 기록한다.

## 병합 중 갱신

T-08은 `896049a64bbd02c263288964421e44dbcb2bb6e2`에서 정규장과 연장 거래의 달력 매핑을 병합했다. 기존 종목 일봉의 최종 세션 기준은 그대로다. ADR 0130은 그 소비 경로 수정을 D-50에 배정했지만 이번 지시에서 어댑터 수정이 금지돼 T-07 후속으로 명시했다. 실제 일봉의 의미와 실측은 확인하지 않았다. 이 문서와 ADR의 인계 변경은 master 병합 커밋에 포함하며 domain 코드는 바꾸지 않는다.
