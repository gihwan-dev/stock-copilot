# 리뷰 기록 A-04

## 커밋

| 회차 | 기준 SHA | 대상 SHA |
|---|---|---|

구현 커밋 전 기록이다. 커밋 후 새 독립 리뷰 대상 SHA와 결과를 추가한다.

## 리뷰

| 번호 | 등급 | 지적 | 평가 |
|---|---|---|---|
| C1 | 차단 | 주문 요약의 값 인자와 ADR 0045 참조 경계 충돌 | 해결: 메인 승인대로 &OrderSummary로 정정. 단언 유지. |
| C2 | 차단 | 고정 cargo-deny 0.20.2의 needs_checking이 개발 의존 순환에서 무한 재귀하여 정상 훅을 SIGABRT로 종료 | 두 crate 최소 재현 -6, 같은 설정의 비순환 대조군 0. 메인 승인 3번으로 해결: testkit을 잎으로 복구하고 testkit-ports로 분리. 같은 정책의 분리 최소 재현과 실제 작업 공간에서 네 검사 모두 통과. 독립 리뷰 대기. |

## 측정

| 항목 | 값 |
|---|---|
| 독립 Opus 리뷰·Codex 비판 | NOT_RUN: 정상 구현 커밋이 C2에서 차단됨 |
| testkit 좁은 테스트 | 46개 통과 |
| Draft 복제 회귀 | 새 테스트 1개 통과 |
| 승인된 A-02 서명 계약 회귀 | 해당 기존 테스트 1개 통과 |
| testkit clippy·arch-check·source-check | 통과 |
| edit-guard·새 보호 해시 회귀 | 7개·1개 통과 |
| 손 변형 | 재실행 25개 컴파일 성공·검출 25·생존 0·복구 검사 통과 |
| 자동 변경분 변이 | just mutants-diff 명령 실행. 사전 test-diff의 승인된 1건에서 중단되어 변이 실행은 NOT_RUN |

| 최신 master 병합·전체 검사 통과 | NOT_RUN·실패 |
| 세션 훅 | 미적용 확인됨(차단돼야 할 `git -c core.hooksPath=/tmp status`가 실행됨) |
| 새 외부 패키지·비동기 런타임 | 없음 |
| 기존 계약 테스트 변경 | 승인된 confirm_order 인자 서명 기대 문자열 1곳 |

세션 훅 미적용은 메인 결정에 따라 작업 중단 사유가 아니다. 실제 정상 커밋 훅과 검사 출력을 별도 기록한다. 독립 리뷰 완료나 전체 검사 통과를 미리 주장하지 않는다.

현재 정상 커밋은 없고 표의 회차별 대상 SHA를 만들어 적지 않았다. 체크를 통과한 것처럼 커밋하거나 독립 리뷰를 생략 완료로 판정하지 않는다.

메인 후속 결정에 따라 C2를 해결했다. 최신 정식 릴리스가 0.20.2라 1번은 불가했고 범위를 유지하는 출력 설정 실험도 실패하여 3번 구조 분리를 선택했다. 세부 근거와 인계는 A-04 ADR의 마지막 결정이 앞선 차단 기록을 대체한다.
