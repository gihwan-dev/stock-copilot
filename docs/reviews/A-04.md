# 리뷰 기록 A-04

## 브리프

포트별 성공·오류·다중 응답 대본과 인자·순서 기록, 미등록 호출 즉시 실패, 저장소 열 개의 메모리 의미, 추가 전용 감사와 비밀 저장, 고정 동기 시계, 별도 결과를 갖는 주문·위험 변경 확인 가짜를 구현한다. 포트마다 임의의 구현에 재사용하는 공개 제네릭 계약 함수를 제공하고 실제 가짜에 실행한다. AI 가짜는 A-11에 둔다. 새 외부 패키지·런타임·실제 API·실제 키는 사용하지 않는다.

사용자는 ADR 0045에 맞춰 confirm_order(&OrderSummary)를 승인했고 요약 Clone·단독 생성·내부 토큰 분해 공개는 금지했다. cargo-deny 개발 의존 순환은 승인된 세 번째 선택으로 해결한다: testkit은 작업 공간 의존 없는 잎이며 가짜는 testkit-ports에 둔다. application/domain은 testkit-ports에 개발 의존하지 않는다. Cargo·arch-check·필요한 보호 등록과 문서를 함께 정합화한다. 기존 단언은 유지한다.

Opus의 제목별 최초 등급은 차단 2·중요 5·사소 2다. 요약의 차단 2·중요 4·사소 3은 집계 오류다. 새 별도 Codex는 9건 중 확정 6·불확실 3으로 판정했고 5·7을 차단으로 상향했다. 6에 함께 들어 있던 두 기존 문구는 신규 지적에서 제외했다. 확정된 지적의 기각을 평가에서 뒤집은 건은 없다.

Opus는 43개 포트 테스트, A-02/domain 회귀, arch-check, cargo-deny 네 검사, clippy, 보호 해시를 실행했다. main-docs-only 훅이 코드 변경 실험을 막아 손 변형과 타입 경계 실험은 NOT_RUN이었다. 이 거부를 우회하지 않았다. Codex 비판자는 별도 격리 사본에서 오답 신호 구현·뉴스·봉 묶음·논거 증인과 손 변형 9개, 보호 밖 impl, 외부 타입 경계를 직접 실행하고 원복했다. 비판자의 전체 check-fast는 소유 프로세스만 종료하여 143·NOT_COMPLETED이며 통과로 세지 않는다. 둘 다 구현자 보고서는 받지 않았다.

2차 Opus는 59개 포트 테스트·xtask 10개·보호 해시 2개를 통과했다. 코드 편집 실험은 main-docs-only 훅에 거부되어 NOT_RUN이며 우회하지 않았다. 새 Codex 비판자는 독립 시험 19개, 원복 뒤 포트 59개, xtask 10개, 해시 2개를 실행했다. 초기 부재 양방향·기본값 대체 오답·격리 필터 변형·비Clone 권한 경계를 직접 재현했다. Opus 제목은 차단 1·중요 2·사소 4·추정 1이며 비판은 확정 차단 1·중요 2를 유지하고 정책 미확정과 권한 확대 기각을 구분했다. 새 확정 지적은 없었다. 이 둘도 구현자 보고서와 target/A-04를 읽지 않았다.

3차 Opus는 포트 64개와 arch-check 위반 0건을 직접 확인했다. 편집 실험은 cwd-unknown 훅에 거부되어 NOT_RUN이며 우회하지 않았다. 새 Codex 비판자는 임시 오답 어댑터로 공개 시나리오 3개 통과·독립 증인 2개 실패, 실제 가짜 대조군 2개 통과를 확인했다. 별도 정책·Draft/봉 분할 3개와 메타데이터/Unknown 1개, core·공개 시나리오·A-21 26개도 통과했다. 권한 타입 복제·생성·분해는 외부 컴파일의 의도한 10개 오류로 거부됐고, 보호 밖 테스트 파일의 UserPresence 구현은 arch-check 위반 1건, 제거 뒤 0건이었다. 소스와 실험을 원복한 뒤 대상 9218cb0과 clean 상태를 확인했다. 두 검토자 모두 구현자 보고서를 읽지 않았다.

3차 비판의 실행 확정 중요 두 건만 구현자가 직접 수정했다. 수정 전 공개 계약과 현재 회귀 네 개를 조합한 임시 복사본에서 네 오답 모두가 계약을 통과했다. 수정 후에는 네 오답을 의도한 계약 단언으로 각각 거부한다. 좁은 포트 검사 68개와 clippy가 통과했다. 4차 리뷰는 메인 결정에 따라 하지 않는다. 사소 두 건은 판정만 남겼으며 새로운 승인 절차나 타입 경계 우회를 추가하지 않았다.

3차 리뷰·비판과 실행 확정 중요 두 건의 수정을 끝냈다. 위 정상 훅은 전체 검사 항목을 통과한 뒤 승인된 test-diff 두 건에서 종료했으며 전체 레시피의 종료 코드 0으로 표현하지 않는다. 최종 문서 커밋의 정상 훅 결과는 그 커밋 메시지와 구현자 최종 보고에 함께 남긴다. 4차 리뷰는 하지 않는다. docs/progress.md는 편집하지 않는다.
