# DS-21 동작 슬롯 리뷰 기록

## 브리프

Card·EmptyState는 하나의 닫힌 Action, Dialog는 confirm/cancel 두 자리를 받으며 StatusBar와 타입을 공유한다. 내부 Button만 렌더한다. 기존 단언은 유지하고 prop 자료만 이관한다. 화면은 변형을 선택하지 않는다. 사용자 후속 승인으로 Card·EmptyState·StatusBar는 secondary, Dialog confirm은 primary, cancel은 secondary로 고정하며 위험 전용 변형은 만들지 않는다. DS-20 구현 부재는 인계한다. 최종 master 병합과 정상 전체 검사를 요구한다.

두 번째 Opus의 차단·중요는 0건이다. 두 번째 Codex는 Q1/Q3를 검증 빈틈으로 확정하고 Q2를 기각했다. 메인은 전부 수용했다. Q1은 base와 target의 첫 활성 버튼 초점 및 Enter가 같음을 독립 재현했으며 새 UX 정책을 만들지 않았다. 사소 수정이므로 workflow 2.6에 따라 메인이 diff·좁은 검사·정상 전체 훅을 확인하고 종료한다.

두 번째 비판자의 검사는 27개 중 26개 통과, 린트 fixture 1개는 scratch의 harness 상대경로 오류로 미완료다. 이를 제품 실패나 우회 검증 성공으로 세지 않는다. 주 작업 사본의 최종 좁은 검사에는 해당 린트 fixture를 포함해 30개가 통과했다. 실제 CSS·VoiceOver 증거로 확대하지 않는다.

## 오염 기록

첫 리뷰어가 신규 ADR을 통째로 출력하다 금지한 검증·손 변형 절도 노출했다고 보고했다. 독립 실행을 했다는 진술로 이 이력을 지우지 않는다. 비판자는 해당 절과 구현 보고를 읽지 않고 각 근거를 별도 scratch에서 재현했다. 재리뷰에서는 새 ADR·리뷰 기록·구현 보고·target 자료를 입력에서 제외한다. 첫 리뷰를 오염 없는 최종 승인 증거로 사용하지 않는다. 두 번째 Opus와 두 번째 Codex는 금지 자료 내용을 읽거나 출력하지 않았다고 확인했다. 두 번째 Opus의 scratch 쓰기 하네스 차단 3회 및 이후 절대 경로/Edit 사용 보고는 절차 이력으로 별도 기록한다. 메인이 차단 원기록을 재현한 것은 아니며, 이를 제품 결함이나 검사 통과 근거에 섞지 않는다.
