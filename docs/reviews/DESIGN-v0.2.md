A1~A3의 문구는 메인 에이전트의 결정문에서 정리한 것이다. 비판자 원문은 이 기록에 없다.

**기준 확률의 급수 식**

가정: 로그 가격이 방향 없는 무작위 움직임(가격이 마팅게일, 로그 가격의 표류 −σ²/2)을 하고, 목표 +T와 손절 −S에서 멈춘다. 기간 H가 끝나면 실패다. 로그 가격을 손절선에서부터 잰다.

기호: x₀ = −ln(1−S), L = ln((1+T)/(1−S)), wₙ = nπ/L, σ는 일 변동성, H는 거래일 수.

```
p₀(T, S, σ, H) = S/(T+S) + e^{x₀/2} · Σₙ bₙ · sin(wₙ·x₀) · e^{−λₙ·H}

bₙ = 4·wₙ·sinh(L/2)·(−1)ⁿ / ( L·(e^L − 1)·(¼ + wₙ²) )
λₙ = σ²·wₙ²/2 + σ²/8
```

- H가 무한대로 가면 합이 0이 되어 기간 제한이 없을 때의 값 S/(T+S)가 남는다.
- 메인 에이전트가 이 식을 문서에 옮기기 전에 직접 구현해 확인했다(Python, 4,000항. 200항에서도 소수 넷째 자리까지 같다).

| 입력 | 비판자가 확인한 값 | 직접 계산 |
|---|---|---|
| T 10%, S 5%, σ 2%, 20일 | 24.75% | 24.7475% |
| T 10%, S 5%, σ 1%, 20일 | 3.15% | 3.1518% |
| T 20%, S 10%, σ 2%, 120일 | 30.3% | 30.3258% |

- 같은 가정의 몬테카를로(하루 50단계, 경로 4,000개)는 23.6%, 3.0%였다. 이산 감시는 단계 사이의 경계 도달을 놓치므로 급수 값보다 조금 낮게 나오는 것이 맞다.
- 리뷰어 1절의 24.6%, 2.9%도 몬테카를로 값이라 같은 이유로 조금 낮았을 수 있다.
