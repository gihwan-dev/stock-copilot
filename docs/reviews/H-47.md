# 리뷰 기록 H-47 (밤 전체 변이 실행의 완주)

## 브리프

H-47: 현행 코드와 기본256회로 밤 조각이 CI에서 끝까지 돌도록 조각 수·시간 제한을 정하고, 미검출·시간 초과는 실패로 유지하며, 취소·불완전 실행의 로그와 작업 요약을 남긴다. macOS 전체 검사 실패를 진단·해결한다. 원격 쓰기는 하지 않으며 실제 완주는 병합 뒤 다음 밤에 확인한다. 보호 경로와 정확한 분할 기대값 갱신은 승인됐다.

추가 승인: 높은 부하에서 Cargo 잠금 대기로 FAIL+LEAK가 나는 기존 deadline 테스트는 단언을 유지하면서 사전빌드와 조건 대기로 바꾼다. ADR은 지정한 번호 없는 초안 파일로 유지하고 tasks/progress는 수정하지 않는다.

## 비판과 수정 증거

1번은 두 독립 실험에서 확인됐다. 비판자의 정상 코드에서는 반환 시 자식이 종료됐지만, SIGINT를 없애고 그룹 SIGKILL을 러너 kill로 바꾼 변형에서는 `alive_at_return=true`, 반환 후29.930초 대기 뒤 PASS였다. 기준 테스트는 같은 변형을 `nextest child survived deadline`으로 실패시켰다. 단언 문장은 남았으나 관찰 시점이 약해진 것이므로 수정했다.

수정 뒤 본 스레드의 독립 scratch Rust 테스트 바이너리에서 정상 코드는22.04초에 통과했고, 동일한 러너만 종료하는 컴파일 가능한 변형은31.99초에 기존 단언으로 실패했다. 기한 이후 정리용 release 파일은 이 판정이 끝난 뒤에만 사용한다. 반환 직후 살아 있는 자식이 나중에 소멸해도 판정은 바뀌지 않는다.

2번은 cargo-mutants27.1.0의 실제 빈 slice에서 종료0, mutants.json=[], 빈 missed/timeout/caught/unviable, outcomes.json 부재를 확인했다. 수정 뒤 같은 실제 CLI 산출물을 사용하는 회귀가 통과했다. 취소·실패·파일 하나 유실·빈 조각의 비어 있지 않은 결과·깨진 outcomes 자료는 계속 실패한다.

4번의 현재 대상 차이 우려는 비판에서 config4452개와 명시 인자4452개가 동일함을 확인해 기각했다. 비용은 실제이지만 분할 완전성·비중복의 전체 CLI 증거를 유지하기로 평가했다. 이를 빠른 수학적 모형만으로 대체하지 않았다.
