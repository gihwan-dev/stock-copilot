## 메인 평가

- 판정: 수용. 변경분 변이를 리눅스와 macOS로 나누고 조각으로 쪼개 병렬로 돌린 뒤 하나로 합쳐 판정한다. 한 조각이라도 놓침·시간 초과·실행 실패이거나 결과가 빠지면 전체 실패다. macOS 동시 실행은 주간·일간 변이와 합쳐 2개를 넘지 않는다(H-59 유지). 조각 분할과 합산 판정은 로컬에서 시험 가능한 코드에 있고 워크플로는 그것을 부른다.
- 메인이 더한 결정: `ci` 워크플로의 전체 검사는 `master`와 `merge/**` 푸시에서만 돈다(서명 검사는 모든 푸시). 작업 브랜치 푸시가 실행기를 차지해 병합 커밋의 검사가 30분 넘게 밀리던 것을 없앤다. 작업 브랜치의 CI 결과는 병합 판정에 쓰이지 않았으므로 검사 강도는 그대로다. 정책 테스트가 트리거 브랜치를 정확히 이 둘로 고정한다. 이 추가분은 좁은 리뷰 1회를 받았다(차단 0, 중요 1건 문서 수정).
- H-62와 한 묶음으로 리뷰했다(2회차, 차단 0). 워크플로 자체는 실행 기기에서 돌릴 수 없어 이 병합의 CI 실행이 첫 실측이다: 조각 작업이 예상대로 돌지 않으면 후속으로 고친다.
- 인계: 첫 몇 번의 병합에서 조각 수·실행 시간 실측, 큰 domain 변경(선택 변이 100개 이상)에서 시간 예산 확인.
