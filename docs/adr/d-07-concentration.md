# D-07 쏠림 계산

- 상태: 초안
- 기준 커밋: 09bc27a58efa647b041effcdcbf6528124879cd3

## 지표와 분모

R-11 Q6의 근거 문장: “가중치 `w_i = 원화 환산 평가액_i / 원화 환산 총자산`. 현금 포함 여부는 지표마다 정한다”. 같은 절은 “ETF는 한 종목으로 계산하고, 구성 종목 분해 비중은 따로 보여 준다”, “현금은 통화 비중에만 넣는다”고 정한다.

| 지표 | 식 | 분모와 현금 |
|---|---|---|
| HHI | Σ w_i² | D-06 AssetAllocation의 종목 행. 분모에는 현금 포함, 제곱합에는 현금 제외 |
| 유효 종목 수 | 1 / HHI | 같은 종목 HHI의 역수 |
| 상위 비중 | 내림차순 w_i의 상위 1·3·5개 합 | 같은 총자산 분모. 현금은 순위에서 제외 |

R-11의 근거 문장: “상위 N 비중”, “N = 1, 3, 5”, “5 미만이면 경고(HHI > 0.20)”. design 8장은 “유효 종목 수 5 미만 경고”를 기본값으로 정한다. 경고는 표시 반올림 전 HHI > 0.20으로 판단한다.

ADR 0043의 HoldingsComposition은 현금을 제외한 다른 분모다. R-11에 없는 재정규화를 하지 않는다. 따라서 현금이 있으면 동일 비중 n종목의 유효 종목 수는 n보다 클 수 있다. 유효 종목 수 = n이라는 항등식은 현금 없이 전액 균등 보유한 경우다. 이는 위험 분산의 보장이나 상관관계 지표가 아니다.

## 완전성과 값 경계

D-06 총자산 종목 비중의 오류는 입력값 없이 그대로 계산 불가로 전파한다. ZeroTotal, 현금만 보유, 모든 종목 평가액 0은 해당 없음이다. HHI 0의 역수를 만들지 않고 경고도 해당 없음으로 둔다. 비중 자체가 미소해서 제곱합이 표현 정밀도 아래로 소실되면 해당 없음 대신 산술 오류다.

지표 값은 봉인된 근사 타입이다. 공개 생성자·Ratio·Decimal·Amount·Money·Quantity 변환과 역직렬화는 없다. 표시용 문자열과 같은 종류 값끼리 비교, 정확도 표지만 공개한다. 내부 비중 접근자는 AssetWeight에 pub(crate)로만 더한다. 불완전 입력과 산술 실패는 닫힌 열거형으로 구분한다.

## 정확도 계약

Decimal 곱·나눗셈은 ADR 0029의 exact_arithmetic 전용 경로에서 checked 연산한다. 이 경로의 제곱은 봉인된 근사 비중의 통계 연산이며 정확한 금액 곱셈 API에는 적용하지 않는다. 제곱은 최대 십진 표현 정밀도로 근사하며 제곱합은 checked 덧셈, 역수는 기존 최대 정밀도 몫을 쓴다. 표시 정밀도로 중간 반올림하지 않는다. 근사 산출물을 정확 금액으로 반환하는 공개 경로는 없다.

각 D-06 입력 비중의 절대 오차는 0.5e-28 이하, 제곱 반올림 오차도 0.5e-28 이하다. 최대 4096종목에서 HHI 절대 오차의 보수적 상한은 4096 × (1.5e-28 + 0.25e-56)다. 역수는 작은 HHI에서 오차가 증폭된다. HHI 오차 상한 ε와 참값 h > ε에 대해 역수 오차는 ε / (h × (h − ε))에 역수 자체의 최종 자리 반 단위를 더한 값 이하이다. 엄밀한 참값의 경계 비교는 인증하지 않으며, ADR 0043처럼 저장된 최대 정밀도 근사값의 대소를 판단한다. 넘침·정밀도 실패를 값으로 숨기지 않는다.

R-11 예제 8의 HHI는 소수 4자리, 유효 종목 수는 6자리, 상위 비중은 2자리로 표시한다. 예제 기대값은 0.2300, 4.347826, 상위 1=0.35·3=0.75·5=0.95다. 균등 10종목 HHI는 0.1000이다. 표시용 문자열의 반올림은 계산 입력으로 재사용하지 않는다.

## 미해결과 후속

- R-11은 현금 포함 여부를 지표별로 명시하라고 했으나 HHI 행에 별도 문장이 없다. 종목 지표에서 현금을 제외한다는 위 해석은 초안이며 메인 검토 대상이다.
- 보유 없음의 경고를 문서가 정하지 않아 보수적으로 해당 없음으로 정했다.
- 예제에 없는 지표별 표시 자릿수, 변경 가능한 경고 기준의 설정 API는 U-10·G-01에서 사용자 확인이 필요하다. 이번 작업은 design 기본값만 구현한다.
- U-10·브리핑·get_allocation은 계산 불가와 해당 없음을 서로 구분하고 근사 표지를 유지해야 한다.
- hooks=true와 Git 훅 설치를 확인했다. 현재 세션의 프로젝트 신뢰와 훅 신뢰 적용 여부는 확정하지 못하므로 직접 검사 결과를 증거로 사용한다.

표시는 MidpointAwayFromZero로 반올림한다. 원래 유리수 참값이 정확히 표시 반 단위이면 D-06의 표현 오차로 아래·위 인접 표시가 가능하다. 속성 테스트는 이 경우에만 두 인접 표시를 허용하고, 별도로 HHI·상위 합은 24자리, 역수는 18자리 정수 잔차로 상대·절대 오차를 확인한다. R-11 고정 예제의 숫자와 자릿수는 정확히 일치해야 한다. 표시 전용 함수 등록을 decimal-rounding 허용 목록에 추가했으며 곱·나눗셈 허용 범위는 넓히지 않았다.
