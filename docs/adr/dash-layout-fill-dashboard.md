# ADR 초안: 현황과 거래내역은 창을 채우는 대시보드로, 넘치는 내용은 카드 안에서 스크롤한다

- 상태: 초안 (2026-11-26). 사용자 요청 "같은 줄 카드 높이가 제각각이지 않게, 메인 뷰는 스크롤 없이, 카드 안에서 스크롤".

## 배경

`내 현황`은 카드들을 세로로 쌓은 긴 페이지였다. 같은 줄의 카드(총평가·통화별 평가, 종목별·섹터별 비중)는 내용 높이만큼만 커져 높이가 달랐고, 메인 영역 전체가 스크롤됐다.

## 결정

1. 디자인 시스템에 채우기 배치를 둔다. 공개 목록(`index.ts`)은 바꾸지 않고 기존 컴포넌트에 리터럴 유니온 속성만 더한다.
   - `AppShell main: "scroll" | "fill"`: `fill`이면 메인 영역이 스크롤 영역 대신 창 높이에 맞는 세로 칸이 된다. 기본은 `scroll`.
   - `Page layout: "scroll" | "fill"`: `fill`이면 본문이 남은 높이를 채운다.
   - `Grid layout: "flow" | "fit-row" | "fill-row"`: 대시보드 한 줄. `fit-row`는 내용 높이, `fill-row`는 남은 높이를 다른 `fill-row`와 나눈다. 같은 줄 칸은 격자 늘이기로 높이가 같다.
   - `Card layout: "flow" | "fill"`: `fill`이면 칸 높이를 채우고 본문이 가로·세로로 스크롤한다. 이 안의 `Table`은 자기 가로 스크롤을 만들지 않고 머리글을 고정한다(`scroll-owner.tsx` 문맥).
2. `내 현황` 배치 (12열):

   | 줄 | 왼쪽 | 오른쪽 |
   |---|---|---|
   | 내용 높이 | 총평가 6 | 통화별 평가 6 |
   | 남은 높이 1/2 | 보유 종목 8 | 신호 4 (아래에 성적표 접기) |
   | 남은 높이 1/2 | 자산배분과 쏠림 8 (종목별·섹터별 표를 세로로) | 아침 브리핑·마감 리뷰 4 |

   현황을 아직 못 받았을 때는 상태 카드 한 줄 아래에 신호 6 · 브리핑 6 한 줄을 둔다.
3. 신호는 신호마다 카드였던 것을 "신호" 카드 하나 안의 목록(구분선)으로 바꾼다. 카드 안 카드를 만들지 않는다. 성적표는 신호의 확률이 얼마나 맞았는지 보여 주므로 같은 카드 아래에 접어 둔다. 상태마다 카드가 바뀌는 브리핑 카드에 두면 상태가 바뀔 때 접기 상태가 초기화된다.
4. 메인 채우기는 `ShellLayout`이 경로로 정한다: 종목 상세를 열지 않은 `/`와 `/transactions`만 `fill`이다. 지난 브리핑과 종목 상세, 설정은 지금처럼 페이지가 스크롤한다.

## 다른 선택지

- 스크롤 영역 내용 상자를 항상 `h-full`로: 긴 페이지에서 내용 상자 크기가 고정돼 스크롤 막대 계산(내용 상자 크기 관찰)이 갱신되지 않는다.
- 탭(분절 버튼)으로 카드 수 줄이기: 신호·비중·성적표가 가려지고, 기존 화면 테스트가 모든 내용이 한 화면에 있다고 가정한다.
- 새 `DashboardGrid` 컴포넌트: 공개 목록(`index.ts`)이 보호 파일이다.
- 격자 줄 템플릿(`grid-rows-*`)·`min-h-full`·`basis-0`: 디자인 시스템 클래스 허용 목록 밖이다. 줄마다 `Grid`를 두고 `flex-1`로 나눈다.

## 미해결

- 가장 작은 창(960×640)에서 아래 두 줄은 카드당 본문이 90px 안팎이라 표 두세 행만 보인다. 높이에 따라 줄 비율을 바꾸려면 높이 미디어 변형 토큰이 필요하다.
- 4열 칸(신호, 브리핑)은 채팅 패널을 연 1280px 창에서 190px 안팎으로 좁다. 성적표 표를 펼치면 카드 안에서 가로 스크롤한다.
