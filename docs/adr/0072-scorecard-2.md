## 기록과 가상 청산

공개 생성 경로는 D-24의 봉인된 매수 또는 매도 신호와 기록된 진입 관측에서 `ScorecardSignalRecord`를 만들고, 그 기록에서 `VirtualExitSignal::from_record`를 호출한다. 매수는 `BuySignalRecord`의 발생 구간을 사용한다. 가격 관측 시각은 실제 진입 시각과 같아야 하며 관측을 미래 시각으로 덮어쓰지 않는다. T·S는 기록이 소유한 과제의 거리와 실제 진입 관측 가격으로 계산한다. 임의 목표가·손절가를 받는 `from_entry`는 crate 내부로 닫았다.

과제의 별도 영속 ID는 기존 D-17에 없으므로 `ScorecardTaskId`는 불변 `EstimateTask` 전체를 소유해 구조적 동일성을 검사한다. 추정 ID, 모델/기간, 프롬프트, 확률, 원래 과제와 판정 기록도 함께 결합한다. `SignalReturn`은 과제와 추정 ID, 방향을 보존한다. 식별자가 다른 수익률은 `ConflictingReturn`이다. 기존 D-17 생성 경로의 식별되지 않은 관측은 새 수익률과 결합하지 못한다. `ScorecardSignalRecord::observation`이 원래 과제의 D-27 판정을 실행하고 식별된 D-17 관측을 만든다.

정규장과 H는 D-27 달력을 실제 진입 시각부터 재사용한다. 명시한 만기와 달력 만기가 다르면 판정 불가다. 진입 시각은 과제 생성 이전일 수 없다. 확정 수정주가·종목·통화·수정 기준·중복 봉 검증도 D-27을 재사용한다. 실제 진입 이후 기업 행위만 추려 기존 `OutcomeAdjustment::from_actions`에 전달하고 실제 진입 기준 시각을 보존한다. 기존 조정 알고리즘을 복제하지 않는다. 환산이 정확한 유한 십진수로 표현되지 않거나 넘치면 판정 불가다.

| 매수 상황 | 결과와 가격 | 근거 문장 |
|---|---|---|
| 목표 장중 도달 | 목표 도달, 목표가 | design 6.6: “목표가나 손절가에 닿으면 그 가격” |
| 손절 장중 도달 | 손절 도달, 손절가 | 같은 문장 |
| 목표 이상으로 시작 | 목표 도달, 시가 | design 6.6: “시가가 그 가격을 넘겨 시작한 날이면 시가” |
| 손절 이하로 시작 | 손절 도달, 시가 | 같은 문장 |
| 만기까지 미도달 | 만기 청산, 종가 | design 6.6: “기간이 끝나면 그날 종가에 청산한 것으로 본다” |
| 아직 진행 중 | 진행 중, 가격 없음 | 미래 봉으로 확정하지 않음 |
| 필수 봉 누락·거래량 0·수정 기준 불일치 | 판정 불가, 가격 없음 | ADR 0035·0051, 보수적 자료 완전성 판단 |

진입일과 양쪽 가격 도달일은 1분봉으로 순서를 확인한다. design 6.6은 기준일과 목표·손절에 모두 닿은 날을 1분봉으로 판정하고 순서를 알 수 없으면 실패로 정한다. 같은 온전한 분봉의 양쪽 도달은 손절 우선이다. 부분 진입 분봉에서 도달하면 진입 이후인지 확인할 수 없어 판정 불가다. 필요한 분봉 누락도 판정 불가다. 장중 H의 만기는 닫힌 분봉 종가를 쓰며 부분 만기 봉은 판정 불가다.

일봉으로만 확인한 장중 도달 시각은 `TradingDay(거래일)`이다. 종가 시각을 실제 도달 시각으로 주장하지 않는다. 갭 시가·분봉·만기는 `At(시각)`이다. 목표·손절 payload를 외부에서 만기로 다시 포장할 수 없다. 신호·가격·비용의 Debug는 원문 금액을 노출하지 않는다.

기존 `session.start() >= now` 조기 종료는 제거했다. 시작 시각까지는 분봉 창에서 완료 봉이 없고 진행 중을 반환하며, 미래 세션은 `now < end`에서 끝나므로 중복 조건이었다. 시작 시각 경계를 회귀로 고정한다. 거래량 0 검사는 완전한 만기 봉 열에서 실제 판정을 바꾸므로 유지한다.

## 매수 비용과 매도 방향

D-22의 수수료·매수 세율·매도 세율과 시장·적용 기간을 재사용한다. 누락을 0으로 대체하지 않는다. 결합 요율도 0 이상 1 이하다.

`c_buy = commission + buy_tax`, `c_sell = commission + sell_tax`

`r_net = (P_exit / P_entry) × (1 - c_sell) / (1 + c_buy) - 1`

매수 초과수익은 `r_net - r_benchmark`다. R-11의 100주·72,000원 예제는 매수 7,201,080원, 순매도 7,184,520원으로 고정한다. 비례 비용을 사용하며 실제 원 단위 절사·최소 수수료를 가정하지 않는다. D-09의 `PerformanceValue`를 재사용하며 거래 통화를 유지한다. 비용 비율은 기존 checked 십진 연산을 쓰고 Decimal 계수 직접 산술은 bootstrap 파일 안에만 둔다.

R-12 2.4의 “매도 제안의 성과 = −(종목 초과수익)”와 이번 확정 지시에 따라 방향은 `Buy` 또는 `SellAvoidance`다. 매도는 보유분 매각 뒤 종목 움직임을 평가하므로 목표·손절을 적용하지 않고 만기 종가까지 관측한다. `r_asset = P_maturity/P_entry - 1`, `r_sell_excess = -(r_asset - r_benchmark)`다. 매도 비용은 반영하지 않는다. 결과의 `GrossSellAvoidance`가 이 기준을 드러낸다. `net()` 접근자의 매도 값은 `-r_asset`이며 매수 순수익률과 혼동하지 않도록 `basis()`와 함께 사용한다.

## 벤치마크 근사와 편향 차단

확정 결정: 종목 시장의 **진입 거래일 벤치마크 종가부터 청산 거래일 벤치마크 종가까지** D-09 `BenchmarkSeries` 구간을 연결한다. `r_benchmark = Π(1+r_B,i)-1`이다. 시작·끝 종가가 없거나 통화가 다르면 비교 불가다. 날짜를 시장 달력의 정규장 종가에 연결하며 정산일 문자열만 비교하지 않는다.

진입·청산이 모두 정규장 종가 시각이면 `Exact`, 하나라도 장중이면 `DailyCloseApproximation`이다. 같은 거래일의 진입·청산은 벤치마크 0에 항상 근사 표지를 붙인다. 필요한 그날 종가가 아직 없으면 계산하지 않는다. 구간에 포함된 근사 표본 수를 결과에 보존한다.

근사는 장중 구간의 벤치마크 움직임을 하루 단위 종가 변화로 대체한다. 진입일 장중부터 종가까지의 움직임을 제외하고 청산일부터 종가까지의 움직임을 포함할 수 있어 초과수익을 어느 방향으로든 왜곡할 수 있다. 정확한 장중 성과로 해석하면 안 된다. 목표·손절 표본을 일괄 누락시키던 선택 편향을 없애려는 결정이다.

확정 결정: D-17에서 만기가 지나 판정이 끝난 신호 중 초과수익을 낼 수 없는 신호가 한 건이라도 있으면 `Withheld(IncomparableSamples, 건수)`다. 구간과 우위·열위를 반환하지 않는다. 비중첩 선택에서 빠진 완료 신호의 비교 불가도 보수적으로 보류시킨다. 진행 중·만기 전·D-17 판정 불가는 기존 제외 규칙을 유지한다. 중복은 한 번 세고, D-23 비중첩 선택은 계산 가능한 경우에도 그대로 적용한다. 표본 부족 `InsufficientSamples`와 보류는 다른 값이다.

설계와 D-09 ADR에는 현재 `Market::Kr/Us`보다 세분화된 종목 거래소와 지수 대응 계약이 없다. 통화 일치만 강제한다. 코스닥과 KOSPI의 적절성은 종목 거래소 분류와 지수 선택 계약을 만드는 후속 작업에 인계한다. 국내 가격지수의 배당 제외 표지는 원래 시리즈에 남는다.

## 정수 부트스트랩

확정 결정: 표본마다 초과수익을 소수 **12자리 half-even**으로 양자화한 뒤, 배율 `10^12`의 `i128` 정수로 합과 평균을 계산한다. 평균의 정수 나눗셈도 half-even으로 반올림한다. 구간과 재표본 평균은 12자리다. Decimal을 합산했다가 복원하던 28자리 산술 오류를 제거한다. 입력 상한은 65,536건이고 초과는 닫힌 `TooManyInputs`다. 양자화 계수 절댓값은 `10^24` 이하(수익률 절댓값 `10^12`)이며 이를 벗어나면 닫힌 산술 오류다. 입력과 묶음 수의 최악 조합에서도 `10^24 × 65,536² = 4,294,967,296,000,000,000,000,000,000,000,000 < i128::MAX`임을 상수 테스트로 증명한다. 평균을 구한 뒤의 계수는 원 표본 범위 안에 있으므로 Decimal 96비트 계수로 복원 가능하다.

확정 묶음 키는 한국 날짜가 아닌 **종목 시장 달력의 진입 세션 날짜**다. 미국 장의 한국 다음날 표시와 무관하다. 서로 다른 시장의 같은 날짜도 같은 묶음으로 본다. R-12의 “같은 날 만든 제안끼리”의 상관을 보수적으로 넓게 잡는 선택이다. 청산일은 키가 아니다. 입력을 날짜·수익률로 정렬하고 날짜별 합과 건수를 보존한다. 원래 날짜 묶음 수만큼 묶음을 복원 추출하며 뽑힌 모든 신호의 가중 평균을 계산한다.

재표본은 2,000회, 보간 없는 백분위법이다. 정렬한 2,000개 평균의 50번째·1,950번째(0 기반 49·1949)를 사용한다. 정수 SplitMix64와 하위 16비트 거절 추출을 쓰며 시드는 호출 인자다. 새 의존성과 부동소수점은 없다. D-17·D-23의 30건 기준에 맞춰 신호 최소 30건과 날짜 묶음 최소 30개를 요구한다. 날짜가 30개면 신호도 최소 30건이다. 미달하면 구간을 내지 않는다. 0 포함은 등호를 포함한 `EdgeNotConfirmed`, 하한 양수는 `Superior`, 상한 음수는 `Inferior`다.

## 검증과 남은 인계

28자리 실제 비용 표본 200·2,000건, 1/3 30건, 공개 비용 0.00015·벤치마크 -30% 경로를 회귀로 둔다. 양자화와 정수 평균을 독립 정수 계산과 4,096회 대조한다. 이웃 순위 값이 서로 다른 2,000개 재표본을 테스트에서 독립 생성·정렬해 두 백분위와 비교한다. 규칙별 청산 예제, 순수익률·입력 순서·평균 범위 속성 검사도 유지한다. 외부 crate에서 공개 기록 생성은 컴파일되고 임의 가격 생성은 접근 제한으로 거부되는지 별도로 확인한다.

정수 가격 예제의 독립 분위 계산은 분자가 10^12의 배수이고 분모가 30이므로 나머지가 0·10·20뿐이다. 이 예제에 도달할 수 없는 동률 분기를 두지 않는다. 일반 28자리 양자화와 양·음수 half-even 동률은 별도 4,096회 정수 대조와 고정 예제로 검사한다. 준비된 묶음은 이미 입력 상한과 계수 상한을 통과한 정수 합이므로 같은 범위를 다시 검사하지 않는다. 비정상 내부 정수에 대한 합·평균 오류 검사는 유지한다.

자동 변이는 실행하지 않는다. 최종 소스의 손 변형 40개 이상을 별도 임시 복사본에서 컴파일·실행하고 검출 테스트를 변형별로 기록한다. 컴파일 실패와 시간 초과는 검출로 세지 않는다. 이전 회차의 25/25 보고를 이번 증거로 재사용하지 않는다.

- 2,000회·보간 생략과 최소 날짜 30개는 R-11·design에 수치가 없는 초안 상수다. 30건을 실력 증명으로 표현하지 않는다.
- 실제 진입 때문에 원래 추정의 만기가 달라지면 D-17 결합에서 제외한다. 실제 신호 구간으로 비중첩 집계할지는 후속 계약이다.
- 부분 분봉·무거래 봉은 자료 부족으로 처리한다. 배당락·특수 기업 행위는 S-23 확인 전 임의 조정하지 않는다.
- 종목 거래소와 지수의 대응, 실제 체결 원 단위 비용은 후속 계약이다.
- 이번 확정 다섯 결정은 확인 대상으로 남기지 않는다. 남은 초안 상수와 후속 계약만 메인에게 인계한다.
