# H-48 병렬 작업에서 깨지는 검사 수정

- 상태: 초안

## 결정

루트 `.claude/worktrees`만 테스트 파일 탐색에서 제외한다. 전체 gitignore를 따르지 않는다. 다른 위치의 미도달 테스트와 접두사만 같은 폴더는 계속 검사한다.

리뷰 대상 원본은 브리프의 작업 브랜치로 찾은 등록된 작업 사본 하나다. 등록된 다른 작업 사본이나 메인 저장소의 병렬 변경은 리뷰 오염이 아니다. 대상의 파일 내용·인덱스·HEAD와 HEAD의 심볼릭 참조 이름은 비교한다. 참조가 다른 이름으로 같은 커밋을 가리켜도 차단한다. 공유 Git의 다른 브랜치 참조는 병렬 작업이므로 비교하지 않는다. Git 조회 실패는 차단한다.

문서에 없던 세부는 대상 작업 브랜치의 체크아웃만 감시하고 대상을 확정할 수 없으면 미확인으로 기록하고 메인의 진행을 중단하는 것으로 정했다. 모든 공유 ref를 비교하면 병렬 작업을 다시 막기 때문이다. 리뷰어 사본은 메인 저장소 밖 T3 격리를 사용한다.

작업 절의 H-48 행 추가 승인을 일반적인 tasks 수정 금지보다 우선 적용했다. progress는 수정하지 않는다. 외부 의존성 추가와 검사 끄기 주석은 없다.

## 검증

회귀: 루트 에이전트 사본 제외, 정상 경로의 미도달 파일 유지, 다른 사본 변경·생성 무시, 대상 파일·인덱스·HEAD·동일 SHA의 참조 이름 이동 차단.

`just mutants-diff 775bc89f0d2876458ca51927db94766b13ad9950`은 위반 없음으로 끝났다. 제품 Rust 소스 변경이 없어 application/domain/order-execution을 주간 전체 대상으로 출력했다. 이를 Rust 변이 실행 통과로 간주하지 않으며 JS 변경은 위 손 변형으로 검증했다.

세션 프로젝트 신뢰와 훅 신뢰 및 적용 여부는 이 환경에서 확인하지 못했다. 시작 pnpm frozen ignore-scripts 및 lefthook 설치는 성공했다. Git 훅의 검사 결과를 별도로 기록한다.

## 인계

H-48: 메인은 보호 파일과 승인된 기존 테스트 변경을 서명 정책에 따라 통합한다. 원격 쓰기와 master 이동은 하지 않는다.

## 1차 리뷰 평가와 수정

메인 체크아웃을 감시에서 제외한 관찰은 맞지만 이를 차단 결함으로 본 주장은 비판에서 기각됐다. 사용자의 사건 서술에는 메인 병합 변경도 오탐에 포함돼 있다. 이 작업의 원본은 리뷰 대상 사본 하나이며 대상 브랜치 참조를 다른 사본에서 옮겨도 대상 HEAD 비교로 차단한다.

대상 확인 실패는 오염이 아니다. 시작 기록에 원인을 보존하고 unchecked로 차단하며 상한 뒤에도 동일한 원인을 알린다. 원본 변경을 되돌리라는 잘못된 지시는 내지 않는다. 브리프나 전사본을 읽지 못하면 대상 브랜치를 포함한 브리프로 다시 시작한다. 이번 실행의 실제 모델 전사본 지연은 실측하지 않았다. 기존 ADR0018 E3a에는 시작 훅 뒤 전사본 생성이 실측돼 있으며 그 순서를 호환 회귀에서 검증한다.

일반 리뷰 브리프에도 기준 커밋과 대상 작업 브랜치 및 대상 SHA를 필수로 명시한다. 이는 에이전트 간 입력 계약이며 제품 사용자 설정은 늘리지 않는다. 대상 사본은 이름 있는 작업 브랜치, 리뷰어 자신의 사본은 detached여도 된다. 중복 등록처럼 대상이 모호하면 고르지 않는다.

역할 정의의 native isolation 설정을 제거하고 T3가 준비하는 저장소 밖 작업 사본만 사용하도록 해당 운영 절을 정리했다. 추가 강제 장치를 구현했다고 주장하지 않는다. Git 조회 오류에는 실패한 명령과 원인을 보존하고 감시 경로의 접두사 반례를 회귀로 추가했다.

## 2차 리뷰 평가와 수정

가드가 T3 Opus를 거부하고 native 리뷰를 허용하던 불일치를 수정한다. 생산 운영은 T3 격리만 허용하며 native Agent는 거부한다. native 시작·종료 훅은 호환 회귀 어댑터로 범위를 명시한다. T3 최상위 리뷰에는 이 훅의 자동 실행을 주장하지 않고 메인이 내용·인덱스·HEAD·참조 스냅숏을 직접 비교한다.

시작 훅은 역할별 pending 입력을 전사본 대체 경로로 사용한다. 전사본은 시작 뒤 생성될 수 있다는 ADR0018 실측을 수용한다. 입력 미확인 상태는 리뷰어가 고칠 수 없어 차단을 반복하지 않고 즉시 unchecked와 원인을 메인에게 알린다.

S8의 쓰기·되돌리기 대상과 브리프를 대상 사본으로 바꾼다. 판정기는 상태·차단 횟수뿐 아니라 정확한 대상 파일 차이를 요구한다. 과거 녹화는 고치지 않는다. 대상 증거가 없는 과거 S8은 현행 판정에서 실패하는 것이 맞다. 실제 Claude 모델 회귀는 실행하지 않았으며 생산 T3 경로를 검증했다고 세지 않는다.

접미사 브랜치 반례를 추가한다. 이 변경의 필수 기대값 수정은 native 허용→거부, reviewer pending 없음→있음, 과거 S8 통과→대상 근거 없는 실패다. 단언을 삭제하지 않고 더 강한 계약으로 바꾼다.

H-36 인계: T3 전용 운영의 실제 모델 회귀를 별도 측정한다. native S7/S8 모델 경로는 생산 경로가 아니며 실제 실행 NOT_RUN이다. 과거 녹화의 S8은 현행의 정확한 대상 변경 근거를 충족하지 못하므로 실패로 남긴다.

리뷰의 고정 기준은 시작 뒤 master가 전진해도 유지한다. 구현 시작용 현재 기준 끝 검사를 리뷰에 재사용하지 않고, 등록된 대상 사본의 HEAD에서 기준 커밋이 조상인지 검증한다. 대상 부재·HEAD 조회 실패·조상 불일치는 거부한다. 이 반례를 발견해 진행 중이던 자기 커밋 검사만 중단하고 수정했다. 중단한 실행은 통과로 세지 않는다.
