# ADR 0049: D-07 쏠림 지표

- 상태: 확정 (2026-11-14)
- 수정 기준: 2cf2b9ac55c6f6ec70e6a73640e4be8684124ca6

## 분모 결정과 사용자 확인 대상

HHI·유효 종목 수·상위 1·3·5 비중·경고는 모두 D-06 HoldingsComposition<AllocationInstrument>와 CompositionWeight를 사용한다. 현금을 분자와 분모에서 제외한다. 쏠림은 주식 부분이 몇 종목에 몰려 있는가를 뜻하며, 유효 종목 수는 사실상 n종목이라는 뜻이다. 현금 최소 비중은 다른 원칙이다.

R-11 Q6의 근거 문장은 “현금 포함 여부는 지표마다 정한다”, “개인에게 가장 읽기 쉬운 표현이다(\"사실상 n종목\")”, “균등 10종목이면 HHI 0.10”이다. 예제 8의 [0.35, 0.25, 0.15, 0.10, 0.10, 0.05] 합은 1이다. 총자산 비중에서 현금을 분모에만 남기면 이 해석과 달리 현금이 늘수록 한 종목 쏠림 경고가 사라진다. 따라서 이번 수정은 현금을 제외한 주식 부분의 구성비로 분모를 정한다. ADR 0043의 AssetWeight 정책 상한 비교와 섞지 않는다.

| 지표 | 식 | 표시 |
|---|---|---|
| HHI | Σ w_i², w_i = 선택 평가액_i / 보유 선택 평가액 합 | 소수 4자리 |
| 유효 종목 수 | 1 / HHI | 소수 6자리 |
| 상위 비중 | 비중 내림차순 상위 1·3·5개 합 | 소수 2자리 비율 |

보유 없음·현금만 보유·모든 종목 평가액 0은 해당 없음이다. 보유 평가 오류는 계산 불가로 전파한다. 현금 평가 오류는 보유 구성비 자체의 완전성을 바꾸지 않는다. ETF는 R-11의 “ETF는 한 종목으로 계산하고”에 따라 한 종목이다.

사용자 확인 대상: 위 보유 구성비 해석, 표시 4·6·2자리, 보유 없음의 해당 없음 처리, ETF 단독 보유의 경고가 적절한가, 경고 기준을 정수 종목 수 1..=4096으로 받는 제한. 이 파일의 사용자 확인 대상을 메인이 취합한다. 이번 회차의 구현은 위 결정을 따른다.

## 전용 근사 계산과 정확 표시

concentration_arithmetic.rs만 쏠림의 근사 제곱·합·역수를 checked Decimal 연산한다. exact_arithmetic.rs에 추가했던 근사 제곱 함수는 제거한다. CompositionWeight의 crate 내부 접근자는 CompositionInput만 반환한다. CompositionInput은 원래 평가 분자·분모를 비공개 Statistic으로 보존하며 Amount·Money·Ratio·Decimal 접근자가 없다. 입력을 만드는 from_evaluation은 정확 평가액을 받는 단방향 경계다. 근사 비중을 금액으로 꺼내는 경로가 아니다.

ADR 0029의 “D-07 … 산술 API는 제공하지 않는다”는 근사 비중의 일반 산술을 공개하지 않는다는 뜻을 유지한다. 이번 파일은 쏠림 전용의 봉인된 결과만 만드는 내부 통계 경로다. 메인은 0029에 다음 문장을 추가한다: “D-07은 보유 구성비를 전용 봉인 입력으로 받아 concentration_arithmetic에서만 근사 제곱·합·역수를 계산하며, 근사 값의 Amount·Money·Ratio·Decimal 변환과 일반 산술 API를 crate 내부와 외부 모두에 제공하지 않는다.”

근사 HHI의 절대 오차 상한은 최대 4096종목에서 4096 × (1.5e-28 + 0.25e-56)다. 유효 종목 수의 수학적 범위는 [1, 양수 평가 종목 수]이고 전체 보유 수 상한은 4096이다. 봉인 생성자는 근사 역수와 정확한 유리수 모두를 [1, 전체 보유 수] 범위로 제한하며, 근사 역수의 마지막 자리 오차가 이 구현 경계를 넘으면 그 경계로 제한한다. 이 근사값은 정확한 금액이나 정확 비율로 반환하지 않는다.

표시는 근사 몫을 다시 반올림하지 않는다. D-06이 사용한 원래 선택 평가 분자·분모를 정수 계수로 맞추고, 임의 길이의 u32 자리 배열로 제곱합·합·표시 배율을 정확 계산한다. 정확 유리수에서 MidpointAwayFromZero로 반올림한다. 정수 자리 곱의 중간값은 (2^32−1)^2+(2^32−1) 이하, 자리 합은 2(2^32−1)+1 이하이므로 u64에 들어간다. wrapping 메서드는 이 증명 안의 자리 분해에만 쓴다. 자리 배열은 캐리를 추가하므로 큰 정수 자체의 폭을 잘라내지 않는다. 자릿수는 소수 28자리 정렬, 최대 4096행, 표시 최대 6자리로 한정된다.

표시 경로에 Decimal 형식화가 없다. 범위를 검사한 유한 정수 단위에서 정수부와 최대 여섯 소수 자리만 문자열로 조합하고, 공개 display는 저장된 표시 문자열만 복사한다. 유효 종목 수의 표시 단위도 최대 4,096,000,000이어서 고정 Decimal 버퍼를 넘지 않는다. 내부의 잘못된 입력·범위는 결과 생성 시 오류로 거부하며 표시 함수가 panic하지 않는다.

## 봉인과 경고, D-12 인계

ConcentrationStatus와 ConcentrationError는 비공개 상태를 감싼 구조체다. 외부 생성·역직렬화·수정 경로가 없다. kind·metrics·error 등 조회만 제공한다. 상태 종류와 오류 종류는 닫힌 읽기용 열거형이다. 지표와 입력의 Debug는 전체 정밀도를 출력하지 않는다.

ConcentrationThreshold는 1..=4096 정수 종목 수로 검증하며 기본값은 design 8장의 5다. warning_with_threshold가 설정 기준을 입력으로 받고 warning은 기본값을 쓴다. 경고 결과는 Warning/Clear/NotApplicable/Unavailable이다. D-12는 이 닫힌 결과를 현재 상태 검사의 경고 항목으로 소비하면 된다. Warning은 주문 차단 판정이 아니다. NotApplicable과 Unavailable을 Clear로 합치지 않는다. D-12의 정책용 접근자와 구별하도록 D-06 접근자는 concentration_statistics_input으로 이름을 정한다.

경고는 표시된 유효 종목 수가 아니라 정확 평가액 유리수에서 N_eff < 설정 기준인지 비교한다. 5−ε가 5.000000으로 표시돼도 경고다. 마지막 표현 자리보다 작은 경제적 평가 차이, 제공자의 평가 오차·시각 차이는 이 계산이 구별하지 못한다. ETF 한 종목의 실제 분산을 분해하지 않아 단독 ETF 보유가 경고인 한계도 남는다.

## 검증 계약

리뷰어의 현금 표 전체, R-11 예제, 현금 없는 균등 4096종목, MAX·1e-28 평가액, 봉인·Debug·설정 경계·불완전 평가를 검증한다. Config::with_cases(4096) 생성기는 평가액 1e-4..1e12와 혼합 크기·동률을 포함한다. 독립 u128 유리수 기준은 생산 코드의 큰 정수 경로와 달리 나머지의 십진 자리별 나눗셈으로 표시를 계산한다. 표시값은 허용 오차 없이 일치해야 한다.

자동 변이 실행은 사용자 지시로 중단한다. 이번 회차는 새 파일들의 분기 제거 손 변형 12개 이상과 전체 just check로 검증한다. 새 의존성·검사 끄기는 없다. 프로젝트 hooks=true는 확인했으나 세션 신뢰 적용은 확정하지 못하므로 직접 검사와 Git 훅 결과를 증거로 사용한다.
