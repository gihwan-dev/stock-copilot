# ADR 0052: D-31 평가 스냅샷과 일간 손익

- 상태: 확정 (2026-11-14)
- 병합 기준: master b071f162740f2ae64bdeb7ec22db5afacce4cdfc
- 근거: 사용자 리뷰 수정 결정, I-09, design 2.4, R-11 Q1·Q4·Q5 및 예제 6·7, ADR 0028·0029·0031·0034·0035·0038·0044·0047

## 서로 다른 양

| 공개 타입 / 소비자 | 정의와 근거 | 정본·대조 |
|---|---|---|
| `HoldingsDailyProfit::compare` / 화면의 오늘 손익 | 보유 종목 일간 손익. 통화별 `오늘 주식 평가 − 전일 주식 평가 − 당일 순매수 체결 금액`. 순매수는 매수 체결 금액에서 매도 체결 금액을 뺀 값이다. 배당·이자·환전·입출금은 제외한다. design 2.4의 종목 평가 변동 표시와 이번 사용자 결정에 따른 식이다. 기존 문서에 식이 없으므로 초안, 사용자 확인 대상이다. | ADR 0038에 따라 토스 요약 값, 요약이 없으면 완비된 종목별 토스 일간 값만 선택한다. 계산값·Matches/Different/Unavailable/NotProvided를 별도로 노출한다. 계산값을 토스 제공값으로 위장하지 않는다. |
| `AccountChange::between` / D-09 수익률 입력 | 계좌 변동. 통화별 `(주식 평가 + 결제 현금)의 변화 − 구간 순외부유입 − 구간 환전 순유입`. 원화 합계는 각 스냅샷 당시 Mid로 환산한 평가 변화에서 각 흐름 시각 Mid로 환산한 순외부유입을 뺀다. 환전은 계좌 내부 흐름이므로 원화 합계에서 차감하지 않는다. R-11 Q1의 현금 원장·외부 흐름 분류와 이번 사용자 결정에 따른다. 흐름 시점 환산의 세부식은 초안, 사용자 확인 대상이다. | 토스 일간 손익과 대조하지 않는다. 화면의 오늘 손익으로 쓰지 않는다. 정확 통화별 값은 `AccountCurrencyChange`, 환산값은 `AccountKrwChange(KrwValuation)`로 분리한다. |

전일은 달력의 직전 영업일과 강제로 맞추지 않고, 호출자가 전달한 직전 스냅샷이다. 시각이 현재보다 같거나 뒤라면 `previous()` 접근 자체도 WrongPeriod다. 전일 누락·조회/재계산 출처·주식/계좌 완전성을 공개한다. 통화별 토스 선택값에도 전일 출처 또는 전일 오류를 보존한다.

## 스냅샷 상태와 출처

| 구분 | 보존·완전성 |
|---|---|
| `Observed` | `PortfolioValuation`의 통화별 주식 평가와 토스 종목별 일간 값을 보존한다. 주문 가능 금액은 `SnapshotCashBasis::OrderBuyingPower`와 `BuyingPower`로 따로 보존한다. 예수금으로 더하지 않는다. 주식 완전성과 계좌 완전성을 각각 제공하며, 계좌 부분은 WrongCashBasis로 계산 불가다. |
| `Recalculated` | D-28 결제 로트, D-11 확정 원주가 일봉, 당시 유효 Mid, D-30 확정 구간의 대조 일치 결제 현금을 사용한다. 재계산 출처를 조회 출처로 바꾸는 API가 없다. 평가 시각과 나중 기록한 시각을 따로 보존한다. |
| 주식 불완전 | 이력 누락, 봉 누락·중복·기준 불일치, 미확정 봉, 행사 정산·입고 대기, 시각 불명·뒤늦은 수량 행, 산술 실패를 오류로 남긴다. 원가 미상은 D-28 로트에 남기며 평가에 0 원가를 넣지 않는다. |
| 계좌 불완전 | 현금·환율 누락, 기간 밖, 원장 대조 불일치, 서로 다른 현금 기준은 완전 계좌 합계가 될 수 없다. 완전한 주식 부분은 별도로 읽을 수 있다. |
| 환산 | 통화별 `Money`와 원화 `KrwValuation`을 분리한다. Mid를 사용하면 Approximate와 실제 쓴 환율의 종류·시각·출처·유효 구간을 유지한다. |

## 재계산 규칙

| 항목 | 규칙과 근거 |
|---|---|
| 수량·현금 | 둘 다 KST 결제일 기준이다. ADR 0044의 계산용 결제 멀티셋·기업 행사를 사용한다. 현금은 ADR 0047 대조 일치 원장과 같은 기간 토큰을 사용하며, 그 기간 안에서만 완전하다. 결제 전 매수는 주식에도 현금에도 아직 반영하지 않는다. 시각이 평가 이후인 처리 행은 현금에서 되돌리고, 수량 행은 불완전으로 둔다. |
| 현금 접근 | `SnapshotLedgers`는 두 통화의 `CashLedger`와 `ConfirmedFlowPeriod` 참조만 받는다. 임시 `SnapshotCashInput`·`SnapshotExternalFlows`는 제거했다. `CashLedger::snapshot_basis`와 기존 현금 효과 함수의 crate 내부 접근만 추가하며 공개 Money 변환을 만들지 않는다. 원장과 토큰의 통화·기간·전체 외부 흐름, 재계산의 계산용 행 멀티셋까지 대조한다. 증권 이관 분류가 있으면 `SnapshotLedgers::with_transfer_classifications`로 D-30 분류 사실을 함께 전달하며, 같은 사실로 토큰을 다시 만들어 일치를 확인한다. |
| 가격·행사 | R-11 Q1의 “수정 전 일봉(adjusted=false)과 그날 환율을 곱한다”를 따른다. 분할 전 수량에는 분할 전 원주가를 쓴다. 가격일과 결제일 사이에 가격 기준을 바꾸는 기업 행사가 있으면 수량과 가격 정합을 주장하지 않고 InvalidCandle이다. 심볼 변경은 가격 기준을 바꾸지 않는다. |
| 이력 범위 | 결제 계산 행의 주식 종목 집합이 이력 집합과 과거 심볼 별칭에 포함되어야 한다. 빠진 종목은 MissingHistory다. 중복 ID·같은 시장의 심볼 별칭 중복·역심볼 분기·순환을 거부한다. |
| 시장별 날짜 | ADR 0028과 D-10의 한국 KST/미국 현지 거래일 타입을 따른다. 가격 날짜는 각각 MarketCalendar에서 읽고, 수량·현금 마감일은 평가 시각을 KST로 투영한다. KST 1월 3일에 미국 현지 1월 2일 가격을 쓰는 예제를 고정한다. 한국 달력 날짜와 KST 평가 날짜 불일치는 거부한다. |
| 휴장·미완료 장 | 한 시장만 쉬면 직전 확정 세션 종가를 쓰고 HolidayCarry를 남긴다. 두 시장 모두 휴장이면 생성하지 않는다. 아직 마감하지 않은 시장은 직전 종가와 AwaitingSession을 남긴다. 직전 세션도 확인할 수 없으면 가격 누락이다. I-09·R-11에 양국 휴장 비대칭의 별도 식이 없으므로 이번 사용자 결정에 따른다. |
| 0주·대기 | 0주이면 종가가 없어도 정확 0이다. 전량 매도 후 상장폐지만 남으면 영구 대기로 만들지 않는다. 실제 입고 대기나 단주 정산 대기가 남으면 0주여도 불완전이다. |
| 누락·상한 | 가격·환율·현금을 0으로 치환하지 않는다. 이력·행사·봉·흐름 환율은 4096개 상한을 둔다. 입력 정렬 및 독립 정수/유리수 기준 대조로 순서 무관성과 반복 결정성을 검증한다. |

## 흐름 구간과 환율

외부 흐름은 D-30 `FlowPeriod::Confirmed`의 개별 `ExternalFlow`를 받아 `(전일 평가 시각, 현재 평가 시각]`에 든 것만 합한다. 주말·휴일·저녁 입금도 이 구간에 들어가면 포함된다. 시작 경계는 제외하고 끝 경계는 포함한다. 불확정 기간, 통화·기간 불일치, 현재 스냅샷과 다른 토큰은 계산 불가다. 처리 시각과 결제 현금 반영 시각의 구간 소속이 다르면 WrongPeriod로 남겨 일시적인 반영 차이를 성과로 만들지 않는다.

통화별 계좌 변동에서는 D-30 원장의 ExchangeIn/ExchangeOut 현금 효과를 같은 시각 구간에서 뺀다. 원화 계좌 합계에서는 환전은 상쇄되고 스프레드·환율 변화는 평가 변화에 남는다. 외화 외부 흐름은 각 흐름 시각에 유효한 유일한 Mid 환율 사실이 필요하다. 없거나 둘 이상이면 원화 계산 불가이며 통화별 계산은 유지한다. 각 날 평가를 그날 환율로 먼저 환산하므로 R-11 예제 6의 −1,250,000원은 −500 USD를 오늘 환율로만 곱한 −550,000원으로 바뀌지 않는다.

## 토스 값과 대조 범위

| 경우 | 결과 |
|---|---|
| 요약 일간 값 제공 | 제공 통화 값을 정본으로 보존한다. 요약에 USD가 없으면 계산 USD나 종목 USD를 끼워 넣지 않는다. |
| 요약 없음, 해당 통화 모든 종목 일간 값 제공 | 종목 제공값의 합을 선택하고 TossHoldings 출처를 남긴다. 하나라도 누락되면 선택값 없음이다. |
| 원화 합계 | 토스가 준 원화 요약만 `krw_selected`로 제공한다. 서버 환율을 모르므로 원화 합계 대조는 Unavailable이다. 토스 원화와 계산 달러를 합하지 않는다. 외국 주식이 있는 경우 요약 원화를 국내 주식 통화별 값과 같다고 대조하지도 않는다. |
| 매매 없음, 수집 동기화 있음 | 순매수 체결 금액 0으로 주식 평가 차이를 대조한다. 배당·이자·환전은 영향이 없다. |
| 매수·매도 행 존재 또는 수집 동기화 없음 | D-08은 settlementDate와 처리/취소 시각 transactionTime만 제공한다(ADR 0034). 체결일 접근자가 없으므로 당일 순매수를 계산할 수 없다. 계산값 MissingExecutionDate, 대조 Unavailable, 토스 선택값은 보존한다. 과거 매매인지도 추측하지 않아 보수적으로 전체 제공 이력에 적용한다. |

## 인계와 미해결

| 대상 | 남은 일 |
|---|---|
| T-13 | 주문 가능 금액과 예수금의 실제 필드·미체결 주문·미결제 대금 반영을 실측한다. 예수금 필드가 확인될 때까지 Observed 계좌 변동을 풀지 않는다. 같은 결제 현금 기준 스냅샷끼리만 계좌 변동을 계산한다. |
| T-06 / D-08 | 체결일과 체결 금액 사실을 제공하는 접근자를 확보한 뒤 순매수 체결 금액을 연결한다. 현재 매도일 대조는 Unavailable이며 일치라고 보고하지 않는다. |
| 미국 기업 행사 | 현지 행사일과 KST 결제일 정규화를 실측/확정해야 한다. 날짜가 어긋난 행사와 종가의 기준은 현재 보수적으로 불완전이다. |
| A-16 / S-18 | 빠진 날을 시장별 달력으로 호출하고, 원본 조회와 재계산 기록을 구분해 추가 저장한다. 실제 직전 스냅샷 선택과 수집 완전성 검증은 호출자 책임이다. |
| D-09 | AccountChange만 수익률 입력으로 사용하고 전일 출처·완전성을 확인한다. HoldingsDailyProfit은 화면 오늘 손익에만 사용한다. |
| ADR 0047 메인 반영 | “대조용으로만 제한은 화면의 현재 현금 표시에 적용한다. D-31은 대조가 일치한 CashLedger와 같은 기간 ConfirmedFlowPeriod가 있을 때에만 결제 기준 잔액을 crate 내부 경로로 과거 평가 스냅샷에 사용하며 주문 가능 금액과 혼용하지 않는다.” |
| ADR 0047 메인 반영 | “환전은 계좌 전체 외부 흐름이 아니다. 통화별 계좌 변동에서는 환전 행의 현금 효과를 통화 간 흐름으로 제외하고, 원화 합계에서는 외부 흐름으로 차감하지 않는다.” |

새 의존성·주석·검사 끄기는 없다. 확정 ADR 0047과 master의 기존 테스트는 수정하지 않는다.
