# ADR 0001. 리서치 반영 뒤 확정한 제품 결정

- 상태: 확정
- 날짜: 2026-11-11
- 결정한 사람: 사용자 (근거와 정리는 [open-issues.md](../open-issues.md))
- 반영한 문서: [design.md](../design.md) v0.2

## 맥락

리서치 16건([research/](../research/))이 v0.1 설계의 여러 전제를 바꿨다. 사용자가 [open-issues.md](../open-issues.md)의 0장(단순함), 1장(확률 신호), 2장(약관), 3장(실행 분리), 4.1(추천안)을 확정했다. 리서치의 추천과 사용자 결정이 다르면 사용자 결정을 따른다. 이 문서는 그 결정을 한곳에 모은다. 하네스와 개발 도구에 관한 결정(I-11 ~ I-17)은 이 문서에 넣지 않았다.

## 결과

- design.md v0.2의 1·2·4·5·6·7·8·9·10장이 이 결정을 따른다.
- 리서치 추천과 다르게 정한 것은 9번(API 키 대신 구독), 11번(앱 전용 설정 폴더 대신 기존 로그인), 20번(위험 설정 변경에 본인 확인 요구하지 않음)이다.
- 감수한 위험(9, 10번과 관심 종목 노출)은 design.md 9.1에 "감수"로 적었다.
- 바뀌면 다시 볼 조건: Anthropic이 소비자 약관의 증권 조항을 바꾸거나 개인 자동 실행을 기술로 막을 때(9, 10번), `--restricted`나 사전 점검의 동작이 CLI 버전에서 바뀔 때(12번), 추정 기록 기간의 적중률이 기준 확률과 구분되지 않을 때(2, 6번).
