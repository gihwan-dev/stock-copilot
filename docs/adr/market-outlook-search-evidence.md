# 시장 전망 보완 조사의 질의와 출처

2026-11-27

시장과 전망 기간은 대화 문맥을 읽은 채팅 모델이 선택한다. MCP 도구는 `market_outlook`에서 `market`(kr, us)과 `horizon`(day, week, two_weeks, month, quarter)만 받는다. 앱은 두 값으로 직전 관측 기간과 앞으로의 전망 기간을 명시한 공개 질의를 만들고 기존 검색 가드의 검사와 감사 기록을 거친다. 이 경로에는 채팅 원문과 계좌를 조회하는 단계가 없다.

데스크톱 운영 수집기인 Claude Code에서 WebSearch 호출 ID와 성공한 도구 응답을 짝지어 출처를 읽는다. 허용한 질의의 완료 이벤트와 같은 질의의 출처가 있어야 한다. URL, 제목, 날짜를 확인하고 실행일 기준으로 지난 1·7·14·31·92일 이내의 자료를 해당 기간에 사용한다. 보도일, 관측일, 페이지 갱신일은 각각 표시한다. 실행 시각은 별도 `collected_at`에 기록한다.

출처는 도메인·날짜·제목으로 요약해 기존 MCP 비신뢰 텍스트 정규화를 거친다. 수집 모델이 작성한 자유 문장은 증거를 추가하지 못한다. 호출 실패나 날짜 없는 링크만 있는 응답은 수집 실패로 끝난다. 이 판정은 검색 도구가 돌려준 자료의 출처와 시점을 확인하며 기사 내용의 진위까지 검증하지는 않는다.
