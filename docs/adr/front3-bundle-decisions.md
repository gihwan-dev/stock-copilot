# front3 묶음 결정 표

- 상태: 확정 (2026-11-25, 묶음 구현 담당이 정함. 경량 절차 ADR 0173)
- 범위: 설정 기본 3항목과 고급 틀(U-23), 코어 이벤트 구독 훅과 `detach`(U-05), 채팅 문구 한 줄(P-3). `src-tauri`와 `crates/*`는 고치지 않았다.

| 작업 | 정한 것 | 다른 선택지 |
|---|---|---|
| U-23 | 기본 3항목은 새 기능 폴더 `settings-basic`(토스 연결, 투자 성향, 주문 켜기)에 두고, 고급은 같은 폴더의 `AdvancedSettings`(DS `Disclosure`, 처음엔 접힘)가 front2의 네 섹션을 감싼다 | 기본·고급 탭, 고급 별도 경로 |
| U-23 | DS `Disclosure`의 패널을 접혀 있을 때도 DOM에 남기고 `hidden`으로 숨긴다(`keepMounted`). 기존 front2 화면 시험이 `/settings`에서 고급 항목을 바로 찾고, 접힌 동안에도 입력 중인 값이 사라지지 않는다 | 접히면 패널을 빼기(기존 시험 수정 필요) |
| U-23 | 코어 명령이 없으므로 `SettingsClient`에 `investmentProfile`·`setInvestmentProfile`·`orderSwitch`·`requestOrderSwitch` 포트를 더하고 앱 기본값은 `no-data`다. 응답 스키마는 `shared/ipc/profile-schema.ts` | 생성 바인딩을 손으로 고치기 |
| U-23 | 주문 켜기 스위치와 투자 성향은 화면이 요청만 보내고 코어가 돌려준 값만 보인다. 켜기·더 공격적인 성향·상한 완화의 네이티브 확인 창(SEC-12)은 코어 몫이라, 사용자가 취소하면 코어가 이전 값을 돌려주고 스위치는 그대로다 | 화면에서 낙관적 갱신, 화면 쪽 확인 창 |
| U-23 | 투자 성향 선택지: 기간 3, 위험 성향 3(design 6.2), 종목 상한 5~30%(기본 20), 섹터 상한 20~60%(기본 40). 제외는 종목 유형 다섯(ETF·ETN·우선주·스팩·리츠) 고정 목록 체크다. 섹터 제외는 섹터 목록을 코어가 보내야 하고 코어 글자를 화면 문구로 바꿀 수 없어 이 묶음에서 만들지 않았다 | 섹터 자유 입력 |
| U-23 | 토스 연결은 연결 상태 한 줄과 키 두 칸("키 다시 넣기")이다. 연결 상태 쿼리 키는 첫 실행 화면과 같은 `toss-connection`이라 결과를 함께 쓴다. 키는 누르는 즉시 비우고 `gcTime: 0` 변경으로 한 번 보낸다 | 첫 실행 화면으로 보내기 |
| U-23 | "키를 넣으면 켜집니다" 한 줄은 고급 > 뉴스·데이터의 선택 키 칸(front2 N-14)이 그대로 맡는다 | 기본 화면에 따로 한 줄 |
| U-23 | 설정을 별도 macOS 창(머리줄 버튼, 메뉴 막대, ⌘,)으로 여는 것과 주 창 기본 제목 표시줄은 `src-tauri` 몫이라 건너뛰었다. 화면은 기존 `/settings` 경로에 있다 | - |
