# ADR 0188: 뉴스 보존 정리, DART·SEC 정기 수집, 실패 진단과 후퇴, 미국 장중 주기

- 상태: 확정 (2026-11-26). [ADR 0187](0187-holding-news-collection.md)의 "하지 않은 것"과 v0.5.3 실사용 진단 결과를 이어서 정한다. design.md 5.2 표 변경은 사용자가 승인했다.

## 배경

v0.5.3 첫 수집 회차(18:20 KST)의 진단 기록: 한경 50건, 매경 50건(연결 1), 연합 210건(연결 2), 한은 100건, 연준 20건, Google 뉴스 6종목 44건(중복 2, 저장 42, 연결 24). 이데일리는 `transport=connect`(8ms)로 연결부터 실패했고, KIND는 200을 받았지만 해석에 실패했다. Yahoo는 미국 보유 종목이 없어 호출하지 않았다.

## 결정

1. **보존 정리.** 하루 한 번(03:45 KST) `news_retention` 작업이 뉴스 행을 수집 시각 기준으로 지운다. Google 뉴스 7일, 언론사·한은·연준·Yahoo 90일이다. 공시는 지우지 않는다. 연결·검색 색인·시각 행을 같은 거래에서 지운다. 진단 기록에는 `job id=news_retention summary=news_pruned processed=<지운 건수>`가 남는다.
2. **DART·SEC 정기 수집.**
    - DART: 선택 키가 있으면 `DartLatestFeed`가 오늘(KST) 목록 첫 쪽(100건)을 받는다. 종목 코드가 있는 공시는 주소 힌트로 그 종목에 바로 잇는다. 키가 있고 마지막 DART 회차가 성공(수집 또는 새 항목 없음)이면 KIND를 쉰다. DART가 실패하거나 키가 없으면 KIND가 돈다.
    - SEC: 뉴스 설정의 연락처가 있으면 `SecTrackedFeed`가 미국 보유·관심 종목(최대 20개)의 최근 7일 제출 서류를 회사마다 최신 5건까지 받는다. 연락처가 이메일 하나뿐이면 앞에 앱 이름을 붙여 SEC가 요구하는 두 낱말 User-Agent를 만든다. 티커→CIK 표는 하루에 한 번 갱신한다.
    - 설정 화면의 선택 키 카드와 SEC 카드는 연결 상태(미설정, 첫 수집 대기, 연결됨, 연결 실패)를 한 줄로 보여 주고, 키가 없을 때는 넣으면 무엇이 좋아지는지 한 줄 안내를 띄운다. 상태는 기존 소스 상태 기록에서 읽는다.
3. **KIND 실패 진단과 대체.** KIND 응답을 해석하지 못하면 `source-rejected source=KindDisclosure detail="stage=… shape=… items=… kept=… skipped=… ct=…"`를 남긴다. 본문이나 제목은 남기지 않는다. 해석에 실패하면 같은 회차에 키 없는 DART RSS(최근 50건)로 대체하고 `fallback=dart-rss items=N`을 남긴다.
4. **연결률 진단.** `news-feed` 줄에 `name_seen`(보유·관심 종목 이름이 제목에 글자로 들어 있는 기사 수), `needs_context`(이름은 있지만 일반 명사로 보고 증권 문맥이 없어 보류), `group_only`(그룹명 접두만 있어 지주사로 잇지 않음)를 더한다. `name_seen - linked - needs_context - group_only`가 경계 규칙으로 거른 수다.
    - 이 진단으로 찾은 결함: 한글 이름 앞 경계에 닫는 괄호가 없어 `[특징주]삼성전자`, KIND의 `[유]삼성전자`처럼 괄호 바로 뒤의 이름을 놓쳤다. 닫는 괄호류(`)]}>’”」』`)와 `:`, `|`를 앞 경계에 더했다.
5. **실패 후퇴.** 같은 피드가 3회 연속 실패하면 6시간 간격으로 물러났다가 한 번 성공하면 원래 주기로 돌아간다. 이데일리처럼 연결부터 실패하는 소스가 10분마다 시도하지 않게 한다. 이데일리 주소는 확인할 수단이 없어 바꾸지 않았다(셸의 `curl` 확인은 하네스가 막는다). 이데일리 기사는 종목별 Google 뉴스 검색으로 계속 들어온다.
6. **야간 주기.** 장 상태로만 나눈다(고정 시각을 쓰지 않는다는 5.2 원칙 유지). 미국 장중에는 국내 공시·언론사 피드를 60분, Google 뉴스를 120분으로 늘리고 Yahoo·SEC를 15분으로 줄인다. 국내 장 마감 뒤는 공시가 몰리므로 30분을 유지한다.

## 다른 선택지

- 야간을 KST 시각(예: 00~07시)으로 정의: 5.2의 "고정 시각을 쓰지 않는다" 원칙과 부딪히고, 한국의 밤 대부분은 이미 미국 장중이다.
- DART가 있으면 KIND를 완전히 끄기: DART 목록은 접수 시각이 없고, 키가 틀리면 공시가 끊긴다. DART가 성공한 동안만 KIND를 쉰다.
- 이데일리 주소를 추측해 바꾸기: 확인 수단 없이 바꾸면 다른 실패를 숨긴다. 후퇴와 상태 표시로 둔다.
- 새 상태 화면: 설정의 키·SEC 카드에 한 줄로 충분하다 (P-1).
