# ADR 초안 D-15: 수집 정보의 출처와 비신뢰 텍스트

- 상태: 초안
- 기준: df24cd3b0b81e077f6a2b776225b63d76297671b
- 관련: D-15, D-16, N-09, M-08, SEC-4, SEC-10

## 결정

NewsItem과 Disclosure는 CollectedItem을 포함한다. CollectedItem의 출처는 InformationSource의 필수 인자이며 Web, News(NewsSource), Disclosure(DisclosureSource)로 구분한다. 소스 목록은 현재 등록할 내부 소스의 닫힌 집합이다. 외부 소스 코드를 파싱하는 열거형이 아니므로 Unknown을 추가하지 않는다. 알려지지 않은 외부 소스의 등록 정책은 A-03·N-01에서 정한다.

제목과 본문은 비공개 필드를 가진 UntrustedText만 받는다. 신뢰 문자열로의 From, Deref, Display, 직렬화 구현을 제공하지 않는다. 경계에서 명시적으로 as_str을 호출해야 원문을 읽는다. 이 값은 검증된 지시문이나 안전한 HTML을 뜻하지 않는다. HTML·제어 문자 제거와 MCP untrusted_text 출력 정규화는 M-08에서 수행한다. 원문을 조용히 잘라 저장하거나 신뢰 텍스트로 승격하지 않는다.

DisclosureKey는 (DisclosureSource, ReceiptNo)로만 구성하며 URL·제목이 바뀌어도 키가 같다. KIND와 DART의 같은 번호는 서로 다른 키다. ReceiptNo는 ASCII 표시 문자 1~64바이트로 원문 보존한다. DART의 14자리 규칙을 SEC EDGAR까지 확대하지 않는다. 구체적인 제공자별 접수번호 검증은 어댑터가 맡는다.

Cluster는 필수 대표 기사와 추가 기사 목록을 불변으로 보관하고 같은 정규화 URL의 중복을 거부한다. 제목 유사도, 종목 대응과 48시간 조건의 군집 결정은 N-09의 범위다.

모든 문자열 입력은 복제 전에 바이트 상한을 검사한다. URL은 8192바이트, UntrustedText는 65536바이트, ReceiptNo는 64바이트다. 이것들은 외부 서비스의 공식 제약이 아니라 내부 자원 상한이다. 오류에는 입력값을 넣지 않는다.

## URL 정규화와 보수적인 수용 범위

R-07 Q6은 스킴, www./m., 추적 인자를 언급하지만 정확한 치환표와 제거 목록이 없다. 스킴·DNS 호스트 대소문자만 정규화하고 http와 https, www.와 m.은 서로 구분한다. 호스트별 동등성이 확인되지 않은 주소를 합치지 않는다. 경로·쿼리 순서·중복 키·기사 번호·프래그먼트는 보존한다. Google 중계 URL을 제목만으로 원문과 합치지 않는다.

추적 인자는 정확히 소문자 utm_source, utm_medium, utm_campaign, utm_term, utm_content만 제거하는 임시 내부 정책이다. 그 밖의 인자와 인코딩된 이름은 기사 식별자일 수 있으므로 보존한다. 쿼리를 디코딩하고 다시 인코딩하지 않는다.

새 의존성을 추가하지 않는다. URL 파서 url 2.5.8은 Cargo.lock에 있으나 작업 공간 기능 통합 시 serde 등 domain 금지 전이 의존성이 생긴다. 허용 규칙을 넓히지 않고 URL 입력을 좁힌다. ASCII DNS 호스트를 갖는 절대 HTTP(S) 주소만 받으며 인증 정보, 포트, IPv6, 원시 비ASCII·공백·제어 문자·역슬래시, 잘못된 퍼센트 인코딩, 점 경로와 마지막 DNS 레이블이 숫자뿐인 호스트를 거부한다. 브라우저가 축약 IPv4나 정수 주소로 해석하는 경우를 지원 범위에서 뺀다. 빈 경로는 /로 통일한다. 수용 범위 밖의 주소는 어댑터가 실패로 처리해야 한다. 이 타입은 외부 링크 열기 권한이나 HTTPS 허용 여부를 대신 판정하지 않는다.

## 미해결

- www./m. 호스트와 HTTP/HTTPS의 제공자별 동등성 및 추적 인자 목록은 문서에 명세되어 있지 않다. 위 임시 목록의 실제 피드 적용 범위도 N-09 녹화 자료로 확인해야 한다. 이름이 다른 추적 인자는 제거하지 않아 같은 기사가 남을 수 있다.
- 인코딩된 추적 키, IDN, 포트와 IPv6, 퍼센트 인코딩 동등 표현의 지원은 명세와 domain 의존 정책 확인이 필요하다. 지원 범위를 넓히기 위해 규칙을 약화하지 않는다.
- 발행·수집 시각은 D-01 병합 뒤 추가한다. 이번에는 시간 crate와 시간 필드를 두지 않는다.
- 생성 속성 검사는 외부 crate 없이 기사 ID·추적 이름·값 조합을 순회한다. proptest 의존 정책이 정해지면 무작위 생성·축소 기반 검사를 보강할 수 있다.
- UntrustedText의 길이 상한과 본문 저장 정책은 별개다. 언론사 본문 보관 금지, 소스별 본문 읽기, Google 제목 한정 정책은 N-17·M-06 및 저장 어댑터가 강제해야 한다.
