# front1 묶음 결정 표

경량 절차(ADR 0173)로 `front1` 묶음(U-09, U-10, U-11, U-21, U-27, U-16, U-17, U-25, DS-12)을 구현하며 문서가 정하지 않은 것을 정한 기록이다.

| 작업 | 정한 것 | 다른 선택지 |
|---|---|---|
| U-09 | 코어 화면 명령(현황·자산배분·거래내역·자체 점검·상태)이 아직 IPC에 없어 `shared/ipc/screen-sources.ts`에 화면 자료 타입과 `ScreenSources` 포트를 두고, 기본값 `pendingScreenSources`는 모두 "자료 없음"(`no-data`)을 돌려준다. `App`의 `sources`로 주입하고 테스트는 가짜 원본을 넣는다. 코어 명령이 생기면 native 묶음이 `call.ts` 함수로 바꿔 끼운다 | `src-tauri`에 빈 명령을 추가(native 묶음과 충돌), 생성 바인딩 손편집(생성물 검사 실패) |
| U-09 | 화면 쿼리 키는 `["portfolio","view"]`처럼 기존 키의 하위 키(`screenKeys`)다. 코어 이벤트 무효화는 접두어로 그대로 닿고, 다른 곳이 상위 키에 둔 값과 섞이지 않는다 | 상위 키를 그대로 사용 |
| U-09 | 주 화면은 U-04의 앱 연결 확인(app_version)을 먼저 거치고, 현황 자료가 없을 때 "앱이 준비됐어요." 빈 상태를 보인다 | 연결 확인 제거(U-04 고정 테스트와 어긋남) |
| U-09 | 네 상태: 불러오는 중, 자료 없음(`no-data` 오류 또는 빈 자료), 오류(다시 시도), 정상 | 자료 없음을 오류로 표시 |
| U-10 | 자산배분은 차트 대신 종목별·섹터별 비중 표와 상한 단계(여유·주의·초과) 배지, 쏠림 한 문장으로 보인다. 차트는 화면 테마 훅이 없어 넣지 않았다 | DonutChart(테마를 고정해야 함) |
| U-10 | 상한 단계와 쏠림 판정은 코어가 정해 보낸 값을 그대로 표시한다 | TS에서 비중 비교 |
