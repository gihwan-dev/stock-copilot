# 야간 확률 추정의 기준가와 인용 원장

한국 시간 01시에 닫힌 시장의 마지막 체결은 정규장 종가와 다를 수 있다. 거래소 캘린더가 닫힘을 확인하면 최근 끝난 정규장의 날짜와 일치하는 확정 수정 일봉 한 개의 종가를 추정 기준으로 쓴다. 자료가 없거나 날짜·종목·수정 기준이 다르면 과제를 건너뛴다. 거래 중에는 체결시각과 수집시각을 구분하고 기존 5초 기준을 적용한다. 주문 제안의 평가에는 기존 실시간 시세를 사용한다.

확률 사건의 시작은 과제의 기준 시각이다. 닫힌 시장에서 관측한 기준가에 대해 저장소는 정규장 종료 시각도 함께 보관한다. `get_estimate_task`의 `reference_time`은 원자료 시각이고 `asked_at`은 과제 시각이다. 야간 기준에는 `reference_source=finalized_regular_close`가 붙는다. 기존 저장 기록은 실시간 기준으로 복원한다.

`submit_estimate`는 종전의 성공한 도구 호출 참조와 수집된 기사·공시의 handle을 받는다. 수집 항목은 동일 실행의 성공한 `search_news` 또는 `get_disclosures` 결과의 `items[].handle`에 반환됐고 원문이 아직 저장돼 있어야 한다. 종목 연결이 있는 자료는 해당 과제의 내부 ID 또는 수집 단계가 저장한 종목 코드와 대조한다. 입력 인자와 기사 본문에 적힌 handle은 조회 증거가 될 수 없다. 조회가 반환한 행에는 출처·안정 키·URL·제목·본문의 SHA-256이 함께 기록된다. 같은 ID를 재사용한 기사나 바뀐 자료는 거절한다. 한국어 결과는 3만 자와 원장의 65,536바이트 한도를 함께 적용해 다음 페이지로 넘긴다. 출처 URL과 공시 키는 저장소에서 읽는다. 제출 소비, AI 추정 및 인용 원장을 한 SQLite 트랜잭션에 저장한 뒤 평가 이벤트를 발행한다. 인용 없는 추정도 채점 이력에 남고 신호 판정에서 근거 부족으로 처리한다.

운영 로그에는 주기 실행에서 시도한 수, 과제별 중단 사유와 평가 결과를 남긴다. 진단은 주문 승인이나 예측 성과 측정에 쓰이지 않는다.

미국 달력의 구간 시각은 토스 응답에서 서울 시각으로 표현된다. 일봉은 응답 행의 거래일로 연결하고, 실제 체결 시각과 판단 시각은 동일한 순간의 미국 동부시각으로 환산한다. 2007년 이후 전환 규칙만 사용한다. [NIST 현행 서머타임 규칙](https://www.nist.gov/pml/time-and-frequency-division/popular-links/daylight-saving-time-dst)
