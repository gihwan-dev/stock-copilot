# fin-ux 묶음 설계 결정 기록

| 작업 | 정한 것 | 다른 선택지 |
|---|---|---|
| 원인 | 배포 앱에서 온보딩이 안 보인 원인은 실제 진입점 `main.tsx`가 `<App />`를 설정 클라이언트 없이 그려 `FirstRunGate`가 조립에서 아예 빠진 것이다(설정 클라이언트가 없으면 게이트 없이 라우터만 그림). 창 설정(`create:false`, `visible:false`)은 Rust가 준비 뒤 `show()`하므로 원인이 아니다 | 창 설정 변경 |
| 원인 수정 | 실제 진입점은 `CoreApp`(= `App` + `coreSetupClient`)을 그린다. `coreSetupClient.checkTossConnection`은 실제 코어 명령 `get_settings`의 `toss_connection`(`connected`/`needs-key`)을 연결 상태로 옮긴다. 키 저장·IP 조회·복사 명령은 아직 코어에 없어(S-12·U-06·U-07 미완) 실패로 답하고 화면은 "토스에 연결하지 못했어요"를 보인다 | 키 확인 Rust 명령을 새로 만듦(IPC 계약·권한 파일 변경이 커서 이 묶음 밖), 지어낸 `needs-keys` 고정값 |
| 원인 수정 | 테스트·스토리처럼 `App`을 직접 그리는 곳은 지금처럼 게이트가 없다(`setupClient`를 넘길 때만 게이트). `ds-screen-bootstrap` 고정 테스트의 `App.tsx` 대역에 `CoreApp` 내보내기 한 줄을 추가형으로 더했다 | `App` 기본값에 게이트를 넣어 기존 화면 테스트 수십 개를 바꿈 |
| 온보딩 | 단계는 토스 키 붙여넣기 → (필요할 때) 허용 IP 두 화면이다. 환영·투자 성향·완료 화면은 두지 않는다. P-1·UX-4·U-28이 첫 실행 조작을 키 붙여넣기와 IP 등록 둘로 묶고, 투자 성향은 기본값으로 시작한다(design 2.5, P-4). 환영 문구는 키 화면 제목·설명이 대신한다 | 환영·투자 성향 한 문항·완료 화면(조작 수가 문서 상한을 넘음) |
| 온보딩 | "나중에 할게요"(키 없이 둘러보기)를 두 화면에 보조 버튼으로 둔다. 고르면 이번 실행 동안 주 화면으로 가고, 다음 실행에는 다시 키 화면이 보인다(저장하지 않음). 필수 조작이 아니므로 P-1 상한에 들지 않는다 | 건너뛰기 상태 저장(새 설정 항목이 늘어남), 건너뛰기 없음(코어 키 저장이 없어 실제 앱이 키 화면에 갇힘) |
| 온보딩 | 화면 틀은 DS `StepScreen`(진행 점, 큰 제목 한 줄, 설명 한 줄, 본문, 아래쪽 큰 기본 버튼과 보조 버튼). 기존 고정 테스트가 문구 일부("client_id와 secret을 붙여 넣으세요", "허용 IP 관리에 아래 IP를 추가하세요", "허용 IP 등록")와 입력 이름(`client_id`, `secret`, `현재 IP`), 버튼 이름("연결하기", "IP 복사")을 묶고 있어 그 부분은 유지했다. IP 화면의 기본 버튼은 "IP 복사"다 | 테스트 문구까지 새로 씀(기존 테스트 변경) |
| DS | `StepScreen`·`ListRow`를 공개 컴포넌트로 추가하고 카탈로그·부하 이야기에 등록했다. `StepScreen`만 `max-w-dialog-width` 폭 예외를 `LENGTH_EXCEPTIONS`에 추가형으로 등록(고정 테스트 목록 갱신). 아래쪽 고정은 `fixed`·`sticky`(넘침 정책 #20) 대신 세로 flex로 버튼을 끝에 둔다 | 위치 고정 클래스 허용 목록 확대 |
| 설정 | 기본 화면은 토스 연결·투자 성향·주문 켜기 세 행(`ListRow`: 제목·현재값·화살표/스위치)을 한 카드에 둔다. 토스 연결 행의 화살표는 첫 실행 게이트의 키 화면을 다시 연다(게이트가 없는 조립에서는 화살표 없음). 투자 성향 행은 기간을 현재값으로 보이고, 화살표로 위험 성향·비중 상한·제외 수를 펼친다. 주문 켜기는 행 끝 스위치(이름 "주문 켜기") | 행마다 별도 화면으로 이동(라우트가 늘어남) |
| 설정 | 고급(AI·뉴스·주문·원칙·시스템 요약)은 지금처럼 접힌 "고급" 아래 둔다. 그 아래 편집 영역(작업별 모델, 수집 소스, 나의 투자 원칙, 시스템, 투자 성향과 주문 설정 바꾸기)은 접지 않았다. 기존 고정 테스트(U-28 설정 화면, E-09)가 펼치지 않은 상태에서 이 문구와 버튼을 찾기 때문이다. 접으려면 사용자 서명으로 그 테스트를 바꿔야 한다 | 편집 영역까지 "고급"에 넣음(기존 테스트 변경) |
| 설정 | 확인 창은 DS `Dialog`에 `placement="sheet"`(화면 아래쪽 정렬)를 더해 전체 삭제 확인에 쓴다. 주문 켜기 확인은 macOS 본인 확인 창이라 바꾸지 않는다 | 바텀시트 전용 컴포넌트 추가 |
