# DS-06 직접 그리는 SVG 차트

- 상태: 초안

## 결정

메인 결정에 따라 Recharts를 사용하지 않는다. 선·영역·도넛·트리맵은 외부 의존성 없이 SVG로 그린다. Recharts 3.10.1이 끌고 오는 @reduxjs/toolkit 2.14.0의 선언은 고정 TypeScript 7.0.2 검사와 충돌했다. 필요한 네 가지 그림에 상태 관리 라이브러리까지 가져올 이유가 없다. package.json·의존성 허용 목록·잠금 파일의 이전 추가는 원복했다. 새 의존성은 0개다.

네 공개 컴포넌트는 동일하게 data, label, empty, theme만 받는다. data는 이름과 코어가 보낸 십진수 문자열의 순서 있는 목록이다. 색·축·눈금·범례·확대·이동·토글·높이 선택지는 없다. 선은 한 계열이고 x축은 입력 순서의 균등 간격이다. theme은 light 또는 dark이며 제공자가 선택한다. SVG는 CSS 토큰 변수를 직접 해석하므로 색 값을 별도로 복제하지 않는다.

숫자 변환과 계산은 LineChart.tsx, DonutChart.tsx, Treemap.tsx에서만 한다. AreaChart는 LineChart의 순수 함수를 사용한다. ChartCoordinate와 ChartPath는 표시용 브랜드다. 원래 십진수 문자열은 ChartDecimal 브랜드로 봉인하며, 화면에 쓰는 문구는 messages.ts에 둔다. ChartDecimal을 JSX에 표시하는 정확한 브랜드 예외를 no-ui-text에 더한다. 원시 문자열과 다른 브랜드는 계속 금지한다. 부동소수점 좌표에서 숫자 라벨을 역으로 만들지 않는다.

ChartFrame의 d와 viewBox만 동적 SVG 기하 예외로 등록한다. 다른 표현 속성이나 파일은 예외가 아니다. fill·stroke·opacity·초점 색은 토큰 클래스만 사용한다. 조각은 순서대로 chart-1부터 chart-6이며 이름은 SVG title, 선택한 항목의 상세 문장, 같은 순서의 항상 보이는 대체 표에 있다. 표는 숨겨진 표보다 마우스·키보드·낭독 모두에서 원문을 확인하기 쉽고, 작은 조각에 긴 이름을 밀어 넣지 않는다. 색에만 의존하지 않는다.

## 좌표와 이상 입력

| 경우                            | 처리                                                                                                                              |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 비어 있음                       | empty 문구, 차트 없음                                                                                                             |
| 잘못된 문자열·빈 이름·중복 이름 | 그릴 수 없음, 부분 그림도 만들지 않음                                                                                             |
| 십진수 정밀도                   | 지수·공백·선행 0은 거부. 소수 최대 15자리, 선행 0을 제외한 유효 숫자 최대 15자리. 이를 넘으면 그릴 수 없음                        |
| 선·영역 한 점                   | 중앙 (50, 30)에 점. 선분은 없음. 기존 최소 2점 명세보다 최신 메인의 한 점 처리 지시를 우선                                        |
| 선·영역 상수·전부 0             | 세로 중앙. 0으로 나누지 않음                                                                                                      |
| 선·영역 음수                    | 정상. 최솟값과 최댓값을 y=55와 5로 대응                                                                                           |
| 선·영역 2~500점                 | x=5~95, 입력 순서의 균등 간격                                                                                                     |
| 500점 초과                      | 그릴 수 없음. 임의 표본 추출 없음                                                                                                 |
| 도넛·트리맵 음수                | 전체를 그릴 수 없음. 절댓값으로 바꾸지 않음                                                                                       |
| 도넛·트리맵 0                   | 조각은 생략, 원문 표에는 유지. 전부 0이면 empty                                                                                   |
| 도넛·트리맵 7개 이상            | 그릴 수 없음. 코어에서 묶어야 함                                                                                                  |
| 양수 조각이 합의 0.5% 미만      | 그릴 수 없음. 최소 각도·폭을 부풀리지 않음. 정확히 0.5%는 허용                                                                    |
| 도넛 마지막 호                  | 끝을 정확히 2π로 고정. 한 조각은 바깥·안쪽 각 두 반원으로 닫힌 고리를 만듦                                                        |
| 트리맵                          | 단순한 세로 slice-and-dice. 양수의 입력 순서를 유지하고 0은 생략. 누적 비율로 x 경계를 정하고 마지막 끝은 100. 전체 크기는 100×60 |

모든 계산은 표시용이다. 금액·비중·확률의 도메인 결과를 만들거나 바꾸지 않는다. SVG 문자열로의 숫자 변환은 경로 좌표에만 쓴다. 부동소수점의 면적 합·접점 비교는 단위 테스트에서 1e-9·1e-12 허용 오차를 쓴다. 마지막 끝은 정확한 상수로 확인한다.

## 상호작용과 반응형

각 점·조각은 tabIndex=0이며 초점 또는 포인터 진입에서 이름과 원문 값을 표시한다. 둘이 겹치면 키보드 초점을 우선한다. 포인터 이탈이 키보드 상세를 지우지 않는다. 데이터가 바뀌면 같은 이름의 현재 값을 찾아 표시하며 삭제된 항목의 옛 값을 남기지 않는다. SVG는 role=img, 접근성 이름, viewBox=0 0 100 60, w-full과 차트 높이 토큰을 사용한다. 고정 픽셀 폭·자르기·독립 스크롤 영역은 만들지 않는다. 대체 표의 긴 이름·원문 값은 status-sentence의 줄바꿈을 따른다.

스토리는 네 컴포넌트 각각 라이트·다크의 정상·빈 상태·한 점·6개 부하·제한 초과 오류를 제공한다. 500점 경계는 생성된 독립 테스트 자료로 검사한다. DS-19·DS-20의 전용 검사 함수는 현재 작업 사본에 없으므로 그 도구에 의한 실측 통과를 주장하지 않는다.

## 버린 대안

| 대안                              | 버린 이유                                        |
| --------------------------------- | ------------------------------------------------ |
| Recharts 및 전이 상태 관리 의존성 | 타입 선언 충돌과 필요한 기능에 비해 큰 의존성    |
| skipLibCheck·선언 위조            | 하네스 검사 강도를 낮춤                          |
| squarified 트리맵                 | 최대 6개 항목에 불필요한 배치 복잡성과 순서 변동 |
| 작은 조각의 최소 각도 강제        | 실제 비중보다 크게 보임                          |
| SVG 칸 안에 긴 이름 강제          | 좁은 폭·작은 조각에서 잘림과 겹침                |
| 자동 축 눈금·반올림               | 원문과 다른 숫자를 표시하거나 화면 설정을 늘림   |

## 기계적인 기존 테스트 기대 목록 갱신

단언과 기존 원소는 유지한다. 첫 전체 검사는 아래 고정 목록 세 곳의 불일치만 보고했다.

| 파일·테스트                                              | 전                               | 후                                                   |
| -------------------------------------------------------- | -------------------------------- | ---------------------------------------------------- |
| local-allowlists.test.mjs · file allowlists              | CHART_NUMBER_ALLOWLIST 비어 있음 | 계산 파일 3개 정확히 열거                            |
| ds-internal-review.test.mjs · exact protected file lists | 기하 파일 목록 없음              | ChartFrame 한 파일의 새 목록 추가                    |
| knip.test.mjs · production allowlist                     | 기존 57개                        | 기존 원소를 유지하고 차트 파일 8개 추가, 정확히 65개 |

새 숫자 변환 허용 파일 각각에 대해 허용 항목을 제거하면 위반이 드러나도록 harness/eslint-violations에 통과 대조군 세 개도 추가한다. 기존 위반 예제와 기대 오류는 바꾸지 않는다.
