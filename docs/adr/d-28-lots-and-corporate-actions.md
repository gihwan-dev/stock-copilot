# D-28: 로트 원가와 기업 행사

- 상태: 초안
- 기준: af70b46fc6c62a0d1a7b036c9977b3d2f3d47366
- 근거: R-11 Q2·Q3·Q5, R-01 Q5·Q14, ADR 0029·0034·0038

## 결정

로트의 입력은 SettledRowSet의 active_settled_for_calculation뿐이다. 취소·사라짐·미결제 행은 이 접근자의 판정을 따르고 원본 이력을 다시 검색하지 않는다. 거래 금액은 amount를 그대로 쓰며 체결 단가와 수량으로 재구성하지 않는다. 실제 commission·tax를 매수 원가에 더하고 매도 대금에서 뺀다.

LotBook은 한 계좌의 한 InstrumentId를 계산한다. 시장·상품·심볼로 주식 행을 고르고, 코드 변경 전후의 심볼을 함께 읽는다. 시장·통화의 잘못된 조합과 변경 전후 시점에 맞지 않는 심볼은 오류다. Lot의 생성자와 필드는 닫고 취득일·잔여 수량·원가·세금 확인 상태를 공개 접근자로 읽는다. 오류에 입력값은 넣지 않는다.

CostBasisMethod는 Fifo와 MovingAverage다. FIFO는 오래된 결제 로트부터 소진한다. 이동평균은 매수 때 남아 있는 로트 원가를 수량 비례로 재배분하고 물리적 수량은 오래된 로트부터 소진한다. 취득일은 유지하며 같은 결제 멀티셋을 다시 읽어 두 방식의 보기를 각각 만든다. 이동평균의 원가는 토스 화면 평단을 덮지 않는다.

원가는 Known(Money) 또는 Unknown이다. 증권 입고는 분류 정보 없이 외부 이관이나 주식배당으로 단정하지 않고 원가 미상 로트가 된다. 증권 출고는 수량·원가만 차감하고 매도 실현손익을 만들지 않는다. 미상 원가가 이동평균 풀에 들어가면 풀 원가는 미상이며 그 원가를 사용하는 실현손익도 미상이다. 전체 청산 후 새 매수는 다시 알려진 원가를 가질 수 있다. 외부 흐름의 사용자 분류와 TWR 판정은 D-30·D-09에 넘긴다.

수량의 합·차·배수와 금액의 산술은 기존 exact_arithmetic만 쓴다. 총원가를 정본으로 보존하고 단가는 LotUnitPrice에 통화와 RatioQuotient의 정확·근사 구분을 함께 담는다. 근사 단가를 Money로 되돌려 원가에 곱하지 않는다. 부분 소진 원가는 정확히 표현할 수 있을 때만 성공하며 유한 십진 표현이 불가능하면 PrecisionLoss다. 곱셈 중간값이 MAX를 넘는 부분 원가 배분도 Overflow로 보수적으로 거부한다.

원화 세금용 원가 보기는 각 USD 결제 행의 양수 exchangeRate로 그 행의 실제 비용 포함 금액을 정확히 환산한다. 환율이 없거나 0 이하이면 계산하지 않는다. 거래 통화 원가 보기는 환산하지 않는다. 이는 신고 세액 확정이 아니며 세법 환율과 토스 신고 방식의 미확인 사항은 R-11에 남아 있다.

## 행사

| 행사 | 처리 |
|---|---|
| 분할 | 양수이며 1보다 큰 배수. 수량만 곱하고 취득일·총원가 유지 |
| 병합 | 0보다 크고 1보다 작은 배수. 수량·원가 보존 후 종목 전체 단주를 정산 대기 청구량으로 보존 |
| 무상증자 | 1주당 추가 비율 r>0, 수량에 1+r을 곱함. 원가 유지, 세금 확인 필요. 입고 행을 연결하면 증가 수량과 일치해야 함 |
| 주식배당 | 계산용 접근자에 실제로 있는 유일한 증권 입고 행으로 새 로트 생성. 명시된 0·확인 금액·미상 원가를 구분. 연결한 행을 다시 일반 입고로 계산하지 않음 |
| 코드 변경 | InstrumentId·취득일·원가 유지, 현재 Symbol만 변경. 원본 행과 행사 입력에 과거 심볼이 보존됨 |
| 상장폐지 | 수량·원가 유지, Delisted로 닫음. 0원 평가를 만들지 않으며 이후 거래·행사 자동 적용 거부 |
| 합병·인적분할·교환 | 닫힌 변형으로 인식하되 ManualActionRequired. 비율이나 새 원가를 추정하지 않음 |

행사 식별자는 한 번만 적용하며 중복은 오류다. 입력 순서와 무관하게 기준일로 정렬하고 미래 기준일은 거부한다. 거래는 결제일·처리 시각으로 정렬한다. 같은 날 다른 종류 거래의 처리 시각이 없거나 같으면 순서를 추정하지 않는다. 행사일의 다른 거래 및 같은 날 복수 행사도 AmbiguousOrder다. 연결된 입고 행만 있는 행사일은 허용한다.

## 미해결과 후속

- 병합 단주는 R-11의 현금 지급 원칙을 따르되 실제 정산금이 없으므로 0원이나 임의 시세로 매도하지 않는다. FractionalEntitlement로 수량을 보존하고 이후 계산을 막는다. 정산 내역의 표현과 행 연결은 T-06 실측 후 메인이 담당 작업을 지정해야 한다.
- 기업 행사와 같은 날 거래의 권리 기준 순서는 R-11에 없다. 호출자가 임의 순서로 우회할 수 있게 하지 않고 오류로 둔다. T-06의 실제 행사 내역과 기준일 자료가 확보되면 담당 작업에서 순서를 확정한다.
- 무상주·주식배당의 의제배당 취득가액은 R-11에서도 미확인이다. NeedsConfirmation을 없애거나 세무상 원가 0을 자동 확정하지 않는다.
- 연간 기본공제·세율·절사·배당 원천세 추정은 이번 작업에 넣지 않는다. 현재 tasks에 별도 세금 계산 작업이 없으므로 메인이 후속 작업을 지정해야 한다. D-30은 실제 현금 흐름, D-31은 과거 평가, D-09는 기간 수익률을 담당한다.
- 기업 행사 감지와 사용자 확인 UI·외부 흐름 분류는 이 순수 도메인 구현에 포함하지 않는다. 실제 키·계좌·주문 전송 경로는 사용하지 않는다.
