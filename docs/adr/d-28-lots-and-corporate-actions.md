# D-28: 로트 원가와 기업 행사

- 상태: 초안
- 기준: af70b46fc6c62a0d1a7b036c9977b3d2f3d47366
- 근거: R-11 Q2·Q3·Q5와 예제 2·5, R-01 Q5·Q14, ADR 0029·0034·0038, D-28 적대적 리뷰 수정 지시

## 결정

입력은 `SettledRowSet::active_settled_for_calculation`뿐이다. 취소 상계·미결제·사라짐은 D-08의 판정을 따르며 원본 이력을 다시 검색하지 않는다. 금액은 실제 `amount`·`commission`·`tax`를 사용한다. 매수 원가에 비용을 더하고 매도 대금에서 비용을 뺀다. 단가로 금액을 재구성하지 않는다.

| 항목 | 결정과 이유 |
|---|---|
| 원가 방식 | 닫힌 `Fifo`·`MovingAverage`. FIFO는 결제일·시각·정규 순서로 오래된 로트부터 소진한다. 이동평균의 금액 정본은 풀의 수량·총원가이며 매수 때 로트별 원가를 재배분하지 않는다. 물리적인 취득 로트는 취득일·출처를 유지한다. |
| 부분 소진 | `총원가 × 소진 수량 / 소진 전 수량`을 임의 길이 정수 분자·분모로 계산한 뒤 거래 원가 통화의 최소 단위(KRW 1원, USD 1센트)에서 0 쪽 절사한다. 잔여 원가는 정확한 뺄셈으로 구한다. 로트·풀을 전량 소진하면 잔여 원가 전부를 가져간다. 따라서 모든 매도 열에서 소진 원가 합과 잔여 원가 합이 취득 원가와 정확히 같다. |
| 표시 단가 | 정확·근사 구분과 통화를 가진 `LotUnitPrice`만 공개한다. 유한 십진수면 정확값, 아니면 Decimal 표현 범위에서 최근접 짝수 반올림 근사값이다. 근사 단가에서 Money로 돌아가는 경로는 없다. 원가 배분은 단가를 사용하지 않는다. |
| 행사 비율 | 양의 정수 쌍 `(구주 수, 신주 수)`. 분할·병합은 대체 비율, 무상증자·주식배당은 추가 배정 비율이다. 수량은 약분한 정수 분자·분모로 유지하여 3:1·7:3과 역비율이 정확하다. 유한 Decimal로 표현할 수 없는 수량도 유리수 접근자로 손실 없이 읽는다. |
| 단주 | R-11 Q5의 유무상교부·주식배당·분할·병합 원칙에 따라 종목 전체의 정수 수량을 주식으로 남기고 나머지는 `FractionalEntitlement` 현금 정산 대기로 분리한다. 매도 대금은 추정하지 않는다. 주식 원가와 단주 원가의 합을 보존한다. 주식배당 단주는 새 배당 로트에서 먼저 소진한다. |
| 미국 소수 보유 | 원래 소수 수량이 있는 미국 계좌에서 행사 결과도 소수이면 실제 계산용 입고 행이 필요하다. 이 행의 수량을 정본으로 삼고 `FractionalReceiptQuantity` 표지를 남긴다. 정수 몫과 다음 정수 사이의 수량만 인정한다. 입고량이 이론량보다 작으면 차이는 현금 대기, 크면 마지막 취득 로트 수량에 차이를 더하고 원가는 유지한다. |
| 입고 연결 | 행사 ID에 유일한 입고 행을 연결한다. 기준일부터 90일 이내의 같은 시장·종목 이력·통화의 입고 중 기대 수량이 맞는 행을 찾는다. 명시한 행도 계산용 접근자에 있어야 한다. 여러 후보·재사용·불일치는 오류다. 연결에는 `ReceiptMatch` 표지를 남긴다. 입고일까지 `Pending`, 이후 `Received`이고 수량은 기준일에 한 번만 센다. 연결한 원본 입고를 다시 로트로 만들지 않는다. |
| 시각이 같은 거래 | 같은 날 알려진 시각은 먼저 정렬한다. 시각이 같거나 실제 거래 중 시각 누락이 있으면 취득을 처분보다 먼저 두고 전체 Transaction의 정규 Ord로 정렬한다. 내용이 다른 행의 순서를 가정했으면 `TransactionOrder`를 남긴다. 중복 행은 멀티셋 개수만큼 처리한다. 연결한 기업 행사 입고는 시각 가정 대상에서 제외한다. |
| 코드 변경 | 명시된 from→to 이력을 양방향 조회하여 모든 심볼 행을 읽는다. 어느 심볼로 요청해도 현재 심볼·수량·원가가 같다. 끊김·분기·순환 이력은 오류다. InstrumentId·취득일·원가는 유지한다. |
| 상장폐지 | `Delisted` 상태로 닫고 평가액을 0으로 만들지 않는다. 이후 매수·행사는 거부한다. 폐지 후 결제되는 매도·출고는 결제 행을 정본으로 받아들이며 `DelistedSettlement` 표지를 남긴다. |
| 실현손익 | 매도 행별 소진 원가·손익·출처·가정 표지를 공개한다. 미상 원가를 소진한 매도만 Unknown이다. 이후 알려진 원가의 매도는 다시 계산된다. 누적 손익은 미상 발생 사실을 유지한다. |

`Lot`·풀·행사·유리수의 생성 경계를 닫고 공개 접근자로 읽는다. 오류는 닫힌 열거형이며 입력값을 담지 않는다. Decimal 곱·나눗셈은 ADR 0029의 전용 경로만 사용한다. 새 정수 유리수 계산은 Decimal 곱·나눗셈을 사용하지 않는다. 중간 곱이 Decimal MAX를 넘어도 최종값이 표현 가능하면 성공하며 실제 결과가 표현 불가일 때만 Overflow·PrecisionLoss다. 새 의존성은 없다.

분류되지 않은 증권 입고는 원가 미상이다. 0원 취득으로 간주하지 않는다. 증권 출고는 보유 수량과 원가를 차감하며 실현손익을 만들지 않는다. 이동평균 풀에 미상 원가가 섞이면 풀 원가도 미상이고, 전량 청산한 뒤 새 취득은 알려진 원가로 시작한다. 보유 초과 매도는 오류이며 0으로 자르지 않는다.

## 행사별 규칙

| 행사 | 수량·원가·상태 |
|---|---|
| 분할 | 신주>구주. 유리수로 정확히 대체하고 정수 주식과 현금 대기를 분리. 취득일·합계 원가 유지 |
| 병합 | 신주<구주. 같은 원칙. 30주를 구주 3·신주 1로 병합하면 정확히 10주 |
| 무상증자 | 구주당 추가 배정을 기존 로트 수량에 더함. 원가 유지·세금 확인 필요. 15주에 구주 10·신주 3이면 19주와 단주 0.5주 |
| 주식배당 | 추가 배정을 별도 로트로 생성. 명시한 0·확인 금액·미상 원가와 세금 확인 상태. 미입고면 대기 |
| 코드 변경 | 식별자만 변경하고 취득일·원가 유지 |
| 상장폐지 | 수량·원가 유지, 후속 결제 매도는 표지와 함께 허용 |
| 합병·인적분할·교환 | 닫힌 변형으로 인식하되 `ManualActionRequired`. 새 원가를 추정하지 않음 |

행사 ID 중복·미래 기준일을 거부하고 기준일 순으로 적용한다. 행사 당일의 연결되지 않은 실제 거래와 같은 날 복수 행사는 권리 순서 근거가 없어 `AmbiguousOrder`다. 현금 정산 대기는 그 자체로 후속 보유 거래를 막지 않으며 총원가에는 대기 원가를 포함한다.

## 대조와 검증

R-11 예제 2의 FIFO 잔여 1,150원·실현 300원, 이동평균 잔여 1,100원·실현 250원을 유지한다. 예제 5는 결제별 실제 환율·비용을 원화로 환산한 FIFO 원가 12,192,180원·실현 6,268,962원, 이동평균 원가 13,153,140원·실현 5,308,002원을 유지한다. 연간 세액은 이 작업에서 계산하지 않는다.

독립 정수 기준과 비교하는 FIFO·이동평균 원가 보존 속성 검사, 정수 비율과 역비율 왕복(유리수 산술은 모든 비율, 실제 주식은 단주 분리가 없는 경우), 국내 정수 수량·수수료와 미국 소수 수량 입력표를 둔다. 최종 변이 결과는 SHA와 함께 구현 보고에 남긴다. 생존·시간 초과를 수정했으면 전체 변이를 다시 실행한다.

## 미해결과 후속

- R-11은 저장·중간 계산의 반올림을 원칙적으로 금지하지만, 반복되는 비유한 부분 원가의 화폐 배분 방향은 정하지 않았다. 이번 수정 지시에 따라 0 쪽 절사를 채택한다. 세법·토스 원가 배분의 실제 최소 단위와 방향은 T-06 실측 후 메인이 확정해야 한다. 표시에 쓰는 최근접 짝수 반올림과 별개다.
- 미국 소수 보유의 실제 행사 입고량·현금 지급 방식은 R-11에 없다. 실제 입고를 정본으로 삼는 보수적 초안이며 T-06 실측이 필요하다. 입고가 없으면 이 경우를 추정하지 않는다.
- 입고 연결의 90일 상한은 문서로 확정된 운영 규칙이 아닌 보수적 초안이다. 행사 ID와 거래 행의 외부 연결 정보·실제 최대 지연을 T-06에서 확인한다. 같은 수량 후보가 여러 개면 수동 연결이 필요하다.
- 행사 당일의 실제 거래 빈도 실측 필요. 기준일과 결제일·권리일의 선후는 T-06 자료 후 확정한다. 같은 날 복수 행사도 순서 근거가 필요하다.
- 단주 현금의 실제 금액·결제 행 연결과 무상주·주식배당 의제배당 원가는 미확인이다. `NeedsConfirmation`·현금 대기를 유지한다. 후속 현금 흐름은 D-30, 과거 평가는 D-31, 기간 수익률과 외부 흐름 분류는 D-09에 넘긴다.
- 폐지 뒤 결제 행에서 실제 체결일을 증명할 수 없으므로 결제 행 정본과 표지를 사용한다. T-06에서 체결일 출처를 확인한다.
- 연간 기본공제·세율·신고 세액·세액 절사·배당 원천세는 범위 밖이다. 현재 tasks에 독립 세금 계산 작업이 없어 메인이 담당 후속 작업을 지정해야 한다. 원화 원가 보기는 결제별 양수 환율이 있을 때만 정확하게 환산하고 신고 세액을 확정하지 않는다.
