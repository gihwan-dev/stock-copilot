# ADR D-58: 추정 수익률의 갭·모호 실패 청산 가격

- 상태: 제안 (2026-11-24)
- 날짜: 2026-11-24
- 결정한 사람: 메인 에이전트(D-54 메인 평가 결정 반영, 추가 선택지는 사용자 확인 대기)
- 관련 작업: D-58
- 기준: 33d41e8dd43556a28d6b6b90f0db52bf879f42cf
- 근거: D-58, D-54, ADR 0051, ADR 0072, ADR 0136, ADR 0151

## 맥락

ADR 0151(D-54)은 추정별 수익률 계산 경로 `domain::estimate_return`을 도입하면서 두 가지 청산 가격 정책을 보류로 두었다.

1. 목표·손절 경계를 넘겨 열린 봉(정규장 시가와 장중 분봉 시가 모두): `EstimateReturnError::GapPricePending`으로 보류했다.
2. 같은 봉에서 목표와 손절에 모두 닿은 확정 모호 실패(`OutcomeState::Failure(OutcomeFailure::Ambiguous)`): `EstimateReturnError::AmbiguousExit`로 보류했다.

이 ADR은 기존 보호 파일인 ADR 0151의 12행·14행(갭 `GapPricePending` 보류, 같은 봉 모호 실패 `AmbiguousExit` 보류)과 31~32행(정규장·장중 분봉 시가 갭 및 같은 봉 모호 실패의 정의 대기)을 대체한다. 나머지 보류 사유와 보정 이력 상한 정책은 ADR 0151의 결정을 유지한다.

D-54 메인 평가는 두 경우에 대해 다음 정책을 확정하고 D-58로 등록했다.

- **갭**: 목표·손절 경계를 넘겨 열린 봉은 그 봉의 시가를 청산 가격으로 쓴다(정규장 시가와 장중 분봉 시가 모두). 실제 체결 가능 가격에 가깝고 손절 갭의 손실을 숨기지 않기 위함이다.
- **같은 봉 모호 실패**: 손절 가격으로 청산한 것으로 계산한다(보수적인 쪽).
- **나머지 보류**: 제출 전 도달, 제출가가 이미 경계 밖, 제출 시각 가격 없음, 같은 분봉·장중 제출일의 일봉, 정확히 환산되지 않는 분할, 제출일·청산일 벤치마크 종가 결측은 그대로 둔다.

## 정의 대기와 선택지

두 확정 결정(갭 → 봉 시가, 같은 봉 모호 실패 → 손절가)만으로 하나로 정해지지 않는 경계 선택지는 임의로 결정하지 않고 보류한 뒤 아래 표로 제안한다.

| 항목                                                                                                       | 현재 동작                                                                                                                             | 선택지                                                                                                               | 사용자에게 보이는 영향                                                                                                                                                                                                                                          |
| ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 목표 갭 시가 + 같은 분봉 손절 동시 도달 (`open >= target && low <= stop`, 정확 경계 `open == target` 포함) | `Err(EstimateReturnError::AmbiguousExit)`로 보류                                                                                      | A. 시가 갭 우선: `Target`·봉 시가로 청산 / B. 모호 실패 우선: `Stop`·조정 손절가로 청산 / C. 현재 보류 유지          | A는 장 시작 직후 목표가 이상으로 출발한 사실을 반영하지만 성적표 `Miss` 판정에 양의 목표 수익률이 표시된다. ## 결과

- `crates/domain/src/estimate_return.rs`의 갭 청산과 같은 봉 모호 실패 청산이 순수 도메인 정확 십진 산술(`Price`, `Money`, `Ratio`, `RatioQuotient`)로 완결된다.
- `crates/domain/src/virtual_exit.rs`와 `crates/domain/src/estimate_outcome.rs`는 `ExitAnchor::Estimate`의 `HorizonSelection::Hours` 익일 단축장 만기(`end == session.end()`)에서도 `estimate_outcome`과 동일하게 분봉 평가를 유지해 장중 분봉 갭·모호 실패를 보존하고 `OutcomeMismatch` 회귀를 막는다(D-29 `ExitAnchor::Recorded` 동작은 유지).
- 기존 `GapPricePending` 변형은 제거되고, `AmbiguousExit`는 목표 갭 시가와 같은 분봉 손절 도달이 충돌하는 정의 대기 경로에만 남는다.
- 기존 D-54 테스트 6건 중 2건(`d54_entry_adjustment_requires_basis_after_submission`, `d54_unrepresentable_adjustment_is_reported_for_each_price`)은 `adjusted_entry` 인자 축소에 따른 기계적 호출부 변경(단언 수·호출 구조 보존)이고, 4건(`d54_ambiguous_failure_has_a_distinct_exit_error`, `d54_gap_prices_wait_for_the_estimate_policy`, `d54_preopen_submission_precedes_a_same_day_daily_exit`, `d54_return_rejects_earlier_or_partially_observed_exit_and_gap`)은 `GapPricePending`·`AmbiguousExit` 보류 기대값 변경과 `d54_gap_prices_wait_for_the_estimate_policy` 내 갭 분봉 시작 30초 전 제출 1건의 `EntryTimingPending`→`Ok`(D-54 3차 리뷰 3번 인계) 전환을 포함한다. 정책 변경 4건은 단언 문장 수가 늘고 `for` 반복을 포함해 현행 `xtask test-diff`의 `safe_block` 구조 보존 규칙을 넘으므로 `harness/test-diff/approvals.toml` 단독으로는 해소되지 않으며 H-62 / ADR 0153 예외 병합 절차와 메인의 명시 확인이 필요하다.
- 인계:
  - `A-15`·`S-18`: 제출 시점 가격 관측·비용·완전 봉·기업 행사를 `estimate_return`에 연결하고 `AmbiguousExit`·`EntryTimingPending`·`ExitUnavailable` 보류 사유를 보존한다.
  - `E-08`: 갭 시가 청산과 모호 실패 손절가 청산 결과, `AmbiguousExit` 보류 사유, 벤치마크 근사 표지를 성적표·복기에 표시한다.
  - `T-07`: 일봉·분봉 시가와 현지 오프셋의 정합성을 보장한다.
