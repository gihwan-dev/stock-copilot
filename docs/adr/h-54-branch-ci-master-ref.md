# H-54: 원격 브랜치 검사와 기준 참조

- 상태: 초안

## 배경

브랜치 체크아웃에는 로컬 master가 없을 수 있다. 훅 진입 테스트가 현재 저장소에서 그 브랜치를 읽어 CI의 전체 검사에서 실패했다.

## 결정

테스트 입력의 master 커밋은 원격 추적 참조의 커밋 객체로 확인한다. 이 테스트는 master 브랜치를 기준 브랜치로 지정한 입력을 거절하는 동작을 검사하며, 검사 성공을 위해 로컬 master를 새로 만들지 않는다. 복제본 회귀는 로컬 master가 없는 상태와 원본 원격 추적 참조의 일치를 확인하고 실제 훅 진입 테스트를 실행한다. 원격 추적 참조가 없으면 테스트는 실패한다. 병합 게이트와 승인 판정의 신뢰 경계는 바꾸지 않는다.

## 검증과 한계

원격 브랜치 push와 실제 macOS 실행은 메인이 수행한다. 복제본 전체 검사의 결과는 실행 뒤 기록한다.

## 인계

H-54: 메인이 브랜치를 푸시한 뒤 macos-branch 전체 검사와 변경분 변이를 확인한다.

## 원격 macOS 변경분 변이 시간 제한

메인이 제공한 master bde0689 원격 실측에서 Linux는 10분 22초에 성공했고 macOS는 전체 검사를 마친 후 선택 변이 25개, jobs 1, test-threads 3을 20분 내 끝내지 못했다. 기준선 빌드 76초와 테스트 26초였다. 기존 원격 판정은 GitHub의 단계 상태가 timed_out일 때만 시간 초과로 구분하고, 내부 20분 제한으로 단계가 failure가 되면 CHECK_FAILED로 표시한다. 주어진 로컬 관측은 컴파일 불가 5개를 제외한 20개를 검출했다.

macOS의 변이는 동일한 차이·기준·무작위 정렬 끄기 조건에서 먼저 목록을 만들고 한 조각당 최대 7개가 되도록 4, 8, 16, 32, 64, 128 중 선택해 순서대로 실행한다. 한 조각이 20분 제한에 이르고 더 나눌 수 있으면 전체 조각을 더 작은 조각으로 다시 검사한다. 각 실행에서 test-diff 사전 조건도 검사하고 전체 계획 목록과 각 실행 목록, 기준선과 완주 결과가 정확히 맞아야 성공한다. 25개는 7, 7, 7, 4로 나뉜다. 이미 기록된 허용되지 않은 생존·개별 시간 초과가 있으면 제한 초과를 재시도 사유만으로 표시하지 않고 실패로 남긴다. 재시도도 완주하지 못하면 RETRY_MUTATION_TIMED_OUT으로 실패한다. 분할은 기준선을 여러 번 실행하므로 전체 CI 시간 단축이나 원격 20분 내 완주를 보장하지 않는다. 로컬 합성 Rust 작업 공간에서 실제 네 조각의 목록 일치를 확인했다. 실제 bde0689 변경과 GitHub macOS 러너에서의 소요 시간은 메인의 푸시 후 확인이 필요하다.

Linux 전체 이전은 store-sqlite가 macOS CommonCrypto에 묶인 기존 계약과 맞지 않아 선택하지 않았다. jobs 2는 3코어 러너의 기존 안전 한도를 넘으므로 선택하지 않았다. 시간 제한 자체를 늘리지 않았다.

## 3차 리뷰 후 시간 예산

분할을 순서대로 재시작하면 개별 조각이 20분 안에 끝나더라도 작업 전체의 120분을 넘을 수 있다. 25개 선택의 비어 있지 않은 조각 수는 분할에 따라 4, 7, 13, 25개이며 각 조각의 기준선을 다시 실행한다. 리뷰의 경로는 계산상 가능하지만 원격에서 발생한 사실은 아니다. 조각 번호만 재사용하면 경계가 겹치므로 검사를 건너뛰지 않는다.

작업 첫 단계 시각으로부터 115분을 예산으로 잡고 다음 조각의 20분과 준비 여유 2분이 남지 않으면 `RETRY_MUTATION_BUDGET`으로 실패한다. 시간 기록 뒤에는 단조 시계를 사용한다. 조각의 선행 준비가 여유를 초과하거나 첫 단계 전 준비에 5분을 넘게 쓰면 GitHub의 작업 제한이 먼저 종료할 수 있어 이때의 원인은 특정하지 않는다. 이 예산도 검사를 통과시킨 증거가 아니다. 실제 변경분 분할의 원격 소요 시간은 메인이 푸시해 확인한다.

## 3차 수정 검증

수정 범위는 8609b825d8915a2eb8a56873b557afe27bce3144 → 77ab38679a1de07b312f56e619e2a7d3607e4e19다. 정상 훅은 Node 992개, Rust nextest 2,223개와 커버리지 1,147개를 통과했으나 test-diff는 기존 테스트 변경 8건에 대한 별도 master 승인 부재로 실패했다. 이어 남은 끄기 보고와 훅 설치 검사는 따로 통과했고 감사 공간은 전후 0개였다. 이 커밋에 한해 지시문이 허용한 예외를 적용했으며, 변경분 변이는 같은 사전 조건에서 멈춰 실행되지 않았다.
