# front2 묶음 결정 표

- 상태: 확정 (2026-11-25, 묶음 구현 담당이 정함. 경량 절차 ADR 0173)
- 범위: 첫 실행(U-06, U-07, U-28)과 고급 설정 화면(U-22, U-08, U-15, AI-10, N-14, G-01, J-10). `src-tauri`와 `crates/*`는 고치지 않았다.

| 작업 | 정한 것 | 다른 선택지 |
|---|---|---|
| 공통 | 코어 명령이 아직 없으므로 `shared/ipc/settings-client.ts`에 화면이 쓰는 포트 `SettingsClient`(명령별 함수, `Promise<Result>` 반환)를 두고, 앱 기본값은 모든 명령이 `no-data`를 돌려주는 `unavailableSettingsClient`다. 코어 명령이 생기면 `call.ts`에 바인딩 호출을 더해 같은 타입을 채운다 | 없는 명령 이름으로 `invoke`를 직접 부르기(실행 시 프레임워크 오류), 생성 바인딩을 손으로 고치기(생성물 검사 실패) |
| 공통 | 응답 스키마는 `shared/ipc`의 `setup-schema.ts`·`ai-schema.ts`·`news-schema.ts`, 브랜드와 입력 검증은 기존 허용 파일 `schema.ts`에 둔다. 허용 목록 파일은 바꾸지 않는다 | 새 스키마 파일을 원시 타입 허용 목록에 추가(고정 테스트 수정 필요) |
| 공통 | 클라이언트는 각 기능 폴더의 `ui/client.tsx` 컨텍스트로 주입하고, `App`이 `settingsClient` 속성을 받아 넘긴다 | `shared/ipc`에 컨텍스트(`shared`에서 JSX 금지, 컨텍스트 타입이 원시 타입 검사에 걸림) |
| 공통 | 화면 테스트는 기존 U-04와 같이 `apps/desktop/tests/*.test.mjs`의 `screenDom`(jsdom)으로 쓰고, 가짜 클라이언트는 테스트 JS 안에서 실제 Zod 스키마를 거쳐 만든다(`tests/front2-fake.mjs`). 이 폴더는 보호 경로지만 잠금이 꺼져 있어 새 파일 추가만 했다 | `src` 안 Vitest(렌더 라이브러리 가져오기 금지), 생성물인 `testing/responses.ts`에 자료 추가 |
| 공통 | 화면 테스트용으로만 쓰는 스키마 내보내기는 `knip`(전체 `just check`)에서 미사용으로 보일 수 있다. 코어 바인딩이 붙으면 사라진다 | 스키마를 숨기고 가짜를 형식 검증 없이 만들기 |
| U-06 | 키는 입력 중에만 컴포넌트 상태에 있고, 누르는 즉시 두 칸을 비운 뒤 코어로 한 번 보낸다. 제출은 `useMutation`(`gcTime: 0`)으로 하고 끝나면 `reset()`으로 변수까지 지운다. 연결 결과(키가 없는 상태 값)만 쿼리 캐시에 남는다 | 비제어 입력, 키를 쿼리 캐시에 두기 |
| U-06 | 연결 상태를 받지 못하면(코어 없음·오류) 첫 실행 화면을 띄우지 않고 주 화면으로 간다. 문제는 자체 점검 상태 띠(U-21)가 알린다 | 오류 화면에서 멈추기 |
| U-06 | 키 형식 검사는 빈 값·공백 포함·512자 초과만 거른다. 실제 키 형식은 토스가 판정한다 | 정규식으로 키 길이·문자 고정(토스 형식 미확인) |
| U-07 | 다시 시도는 연결 상태 쿼리의 `refetchInterval` 60초 하나뿐이고, 허용 IP 화면일 때만 켠다. 손으로 누르는 "다시 확인" 버튼은 두지 않는다(1분 1회 상한을 화면 쪽에서 따로 지킬 필요가 없다) | 버튼과 시각 비교로 상한 지키기 |
| U-07 | 현재 공인 IP 조회는 허용 IP 화면 컴포넌트 안의 쿼리(`gcTime: 0`)로만 부른다. 다른 화면에서는 0건이다 | 앱 시작 때 미리 조회 |
| U-07 | 복사는 브라우저 클립보드 대신 코어 명령 `copy_text` 포트로 한다(웹 API 직접 사용 금지 규칙). IPv4·IPv6 모두 받는다 | `navigator.clipboard` |
| U-07 | 공개 IP 확인 서비스 선택 ADR과 실측 S-22는 조립 루트(`src-tauri`)와 사용자 실측 몫이라 이 묶음에서 건너뛰었다 | - |
| 공통 | 설정 고급 묶음은 기능 폴더 넷(`settings-system`, `settings-ai`, `settings-news`, `settings-principles`)으로 나누고, `app/settings.tsx`가 섹션을 한 화면(기존 `/settings` 자리)에 이어 붙인다. 고급 틀(U-23)이 오면 그 안으로 옮긴다 | 기능 하나(문구 파일 250줄 상한에 걸림), 묶음마다 경로 |
| U-22 | 계좌가 둘 이상일 때만 고급 > 시스템에 계좌 선택이 보인다. 선택지 이름은 순서 문구("첫 번째 계좌"…다섯 번째까지)이고 고른 계좌 번호는 읽기 전용 칸에 보인다(코어가 보낸 글자는 화면 문구로 바꿀 수 없다). 바꾸면 계좌 선택을 뺀 모든 조회를 무효화한다 | 계좌 번호를 선택지 이름으로 쓰기 |
| U-08 | 화면 몫은 고급 > 시스템의 "토스 자료 갱신" 안내 세 문장이다. 주기·즉시 갱신·장중 판정은 코어(J-01 스케줄러) 몫이라 이 묶음에서 만들지 않았다 | 주기 조절 칸(설계에 없음) |
| U-15 | 전체 삭제는 확인 창을 거치고, 성공하면 쿼리 전체를 무효화한다. 키도 지워지므로 연결 상태가 `needs-keys`가 되어 첫 실행 화면으로 돌아간다. 키체인 삭제 자체는 코어 몫이다 | 앱 재시작 요구 |
| AI-10 | 작업 종류는 채팅·확률 추정·심층 연구·브리핑과 리뷰·뉴스 분류와 요약·웹 수집 여섯, 모델은 Opus·Sonnet·Haiku 셋, 추론 강도는 low~max 다섯으로 고정 목록이다. 한도 비율은 50~90% 10단위 선택지다 | 코어가 목록을 보내기(화면 문구로 바꿀 수 없음) |
| AI-10 | 학습 설정 바로가기는 앱이 정한 고정 주소 `https://claude.ai/settings/data-privacy-controls`를 기존 `open_external`로 연다 | 안내 문장만 두기 |
| AI-10 | Claude 설정 위치는 빈 칸이 기본(기본 위치 사용)이고, 값은 `/`나 `~`로 시작하는 경로만 받는다 | 폴더 선택 창(코어 명령 필요) |
| J-10 | 시각이 있는 예약 작업만 HH:MM 칸과 저장 버튼을 둔다. 장중 감시·미국장 전 점검·종목 추정 순환처럼 시각이 코어가 정하는 작업은 켜기·끄기만 있다 | 모든 작업에 시각 칸 |
| N-14 | 소스 표는 코어가 보낸 소스만 행으로 그리고(15종 이름 문구 준비), 소스마다 수집 켜기·AI 본문 읽기·수집 주기(1·2·5·10·15·30·60분 선택지)를 둔다. 본문 읽기가 `locked`인 소스(연합뉴스)는 꺼진 채 비활성이다 | 주기 자유 입력 |
| N-14 | 선택 키(DART·FRED)는 키 칸을 누르는 즉시 비우고 `gcTime: 0` 변경으로 한 번 보낸 뒤 `reset()`한다. 화면에는 "키가 저장돼 있어요"/"키를 넣으면 켜집니다"만 보인다 | 저장된 키 일부 표시 |
| N-14 | AI를 깨우는 기준은 하루 변동 ±3/5/7/10%, 같은 종목 뉴스 1시간 3/5/10/20건 선택지다. 공시 기준은 고정 문장이다 | 공시 등급 선택 |
| N-14 | 종목 약칭 표는 화면에서 행을 편집하고 저장 때 한꺼번에 검사해 보낸다. 종목 코드는 기존 `Ticker` 브랜드(영숫자 6자리)로 검사한다 | 행마다 즉시 저장 |
| G-01 | 투자 원칙은 자유 서술(4000자 이하), 현금 최소 비중(0·5·10·20·30%, 기본 10%), 쏠림 경고 기준(유효 종목 수 3·4·5·6·8·10개 미만, 기본 5)을 한 번에 저장한다. 현금 최소 비중 기본값은 설계에 없어 코어 응답을 따르고 가짜는 10%로 둔다 | 항목마다 즉시 저장 |
| U-28 | 문구 정적 검사는 이 묶음이 맡은 화면(`onboarding`, `settings-*`)의 `messages.ts`만 본다. master에 들어온 채팅 문구 `features/chat/messages.ts`의 "터미널에서 Claude에 다시 로그인해 주세요."는 P-3과 부딪히지만 다른 묶음 파일이라 고치지 않고 보고한다 | 앱 전체 검사(다른 묶음 문구로 실패) |
| U-28 | 종단 시험은 가짜 클라이언트로 키 화면 → 허용 IP 화면 → 주 화면을 지나며 사용자 조작을 "연결하기"와 "IP 복사" 두 번으로 센다(입력은 조작에 넣지 않는다). 1분 재시도는 시험에서 `setInterval`을 가로채 한 번 돌린다. 터미널 명령 금지는 지나간 화면 글자와 모든 `messages.ts` 문구에서 확인한다 | 실제 앱 창을 띄우는 E2E(금지) |
