# 대시보드 위젯의 도킹과 화면 모양

넓은 모니터에서 가운데 브리핑이 길어지면 양옆 보유 종목표와 자산배분표가 먼저 끝나 회색 바탕이 노출됐다. 보고서를 읽으면서 계좌 상태를 계속 비교할 수 있게 화면의 남은 높이를 위젯에 배정한다.

- 대시보드에는 계좌 요약, 보유 종목, 오늘 브리핑, 신호, 자산배분, 보유 자산 평가, 새 종목 후보, 경제와 산업 동향이 있다. 총평가와 통화별 평가는 요약 위젯을 공유한다.
- 기존 의존성인 react-resizable-panels의 Workspace가 분할 비율과 활성 탭, 독립 프레임의 이동과 크기를 관리한다. 각 위젯의 등록 ID는 하나다. 사용자는 헤더를 끌거나 배치 메뉴로 탭을 묶고 나누며, 대시보드 안에서 프레임을 따로 띄울 수 있다.
- 표는 도구줄과 설명을 제외한 본문의 높이를 채운다. 행과 브리핑이 넘치면 해당 프레임에서 스크롤한다. 열이나 행을 움직일 때는 원래 데이터와 종목 상세, 브리핑 출처, 신호 승인 동작을 그대로 사용한다.
- QHD 기본 배치는 계좌, 읽을 자료, 신호와 비중을 좌우에 둔다. 좁은 창에서는 같은 자리에서 관련 위젯을 탭으로 전환한다. 창 너비 구간별로 도킹 배치를 저장해 작은 창을 구경한 뒤 큰 모니터로 돌아와도 정리해 둔 자리를 찾을 수 있다.
- 도킹 저장소에는 위젯 ID와 기하 정보만 남긴다. 제거한 위젯이나 빈 배치도 정상적인 사용자 설정이다. 저장 형식이 손상되면 기본 배치를 사용한다. 화면 모양의 간격, 안쪽 여백, 모서리는 배치와 별도로 저장한다.

모델 회귀는 `node harness/vitest-check/check.mjs`에서 자동 실행한다. 실제 Chromium의 드래그, 키보드, 프레임 높이와 조사 근거 탐색은 `node --test --test-concurrency=1 fixtures/dashboard-dock/{docking,research}.browser.mjs`로 확인한다.
