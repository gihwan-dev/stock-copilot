# D-27 추정 판정

- 상태: 초안
- 기준: 8b92baa111b5c7796ab93c8201a58e7fe37608e6
- 근거: design 6.6, ACC-9, open-issues 1.1, ADR 0028·0029·0035·0041·0044·0046

## 규칙

확정된 수정주가만 사용한다. 기준일은 관측 이후 정규장 분봉을 사용한다. 일봉에서 목표와 손절이 모두 닿은 날도 분봉을 사용하며, 분봉 안에서 둘 다 닿거나 필요한 분봉이 빠지면 모호 실패다. 일봉 누락은 자료 부족이며 만료 실패로 확정하지 않는다. 아직 끝나지 않은 분봉은 자료 부족으로 만들지 않는다.

T·S의 저장된 근사값을 정확한 확률이나 주문 가격으로 바꾸지 않는다. 판정 경계에만 정수 계수 산술을 사용한다. 목표는 기준가×(1+T), 손절은 기준가×(1−S)다. 정수 분자·분모의 교차 곱으로 비교하므로 나누어떨어지지 않아도 반올림이 필요 없다. 표현된 근사 T·S의 수학적 참값 오차는 D-21 수치 계약 밖의 미해결이다.

OutcomeAdjustment는 종목, 기준 관측 시각, 봉의 수정 기준, 양의 정수 구주·신주 비율을 보존한다. 가격은 구주/신주를 곱한다. 여러 행사의 누적 비율과 배당 등 수정 요인의 완전성은 어댑터가 증명해야 하며, 알 수 없는 수정은 이 사실을 생성하지 않는다. 봉의 수정 기준을 혼합하지 않는다.

캘린더는 today 행을 기준일에서 시작해 next_business_day 연결로 확인한다. 다음 행의 previous_business_day도 대조한다. H 정수일은 기준일 이후 H번째 정규 거래일 마감이다. Hours는 기준일 정규장 길이의 1/4을 정규장 시간으로 누적하며 휴장 시간은 세지 않는다. 캘린더가 모자라면 판정 불가다.

결과의 성공·실패만 CalibrationFact로 변환한다. 종목·기간·원래 구간 [관측 시각, 만기]를 판정에서 고정하며 조기 도달로 구간을 줄이지 않는다. 판정 저장의 추가 전용 강제는 A-15·S-18 책임이다.

## 미해결과 보수적 초안

- 목표·손절의 등호는 design의 '닿으면'에 따라 포함한다.
- 시가 갭으로 한 경계 밖에서 시작해도 같은 분봉에서 양쪽에 닿으면 모호 실패다. 한쪽만 닿으면 고가·저가의 해당 판정을 따른다. 일봉 양쪽 도달은 시가로 생략하지 않고 분봉을 요구한다. 시가의 가상 청산 가격은 D-29의 책임이다.
- 관측이 분 중간이면 그 분봉은 기준 이전 움직임을 분리할 수 없어 모호 실패다. 만기가 분 중간이면 만기 이후를 포함한 분봉으로 성공을 만들지 않는다.
- 정규장 밖 움직임의 포함 여부와 배당락은 T-13·S-23 실측 후 확정해야 한다. 현재는 정규장만 쓴다.
- 미래에 다른 봉을 추가해 이미 확정한 결과가 바뀌지 않는 성질은 기존 자료와 모순되지 않는 뒤 시각의 자료 추가에 한한다. 과거 봉 변경·수정 기준 변경은 같은 입력이 아니다.
- 프로젝트 설정의 hooks=true를 확인했다. 세션 프로젝트 신뢰와 훅 정의 신뢰가 실제 적용되었다는 증거는 없으므로 직접 검사와 Git 훅 결과만 검증으로 삼는다.

## 검증과 인계

새 테스트는 목표·손절·만료, 기준일 이전 움직임 제외, 일봉 양쪽 도달의 분봉 순서, 모호함과 일반 일봉 누락의 차이, 등호와 시가 갭, Hours·휴장·부분 분봉, 40·126거래일 만기, 중복 충돌·시장·수정 기준 검증, D-23 사실 변환을 고정한다. 두 속성 테스트는 각각 Config::with_cases(4096)이다. 첫 속성은 임의의 다섯 거래일 경로의 실제 일봉을 시간순으로 순회하는 독립 기준과 비교한다. 독립 경계는 기존 정확 Money 산술로 계산하고 제품의 정수 교차 곱을 재사용하지 않는다. 조기 종결 시점까지의 접두 입력, 만기까지 모든 후속 봉을 더한 입력, 순서를 섞은 입력 및 만기 뒤 봉 추가의 결과가 같다. 둘째는 정수 배율 1~10을 기준가 환산과 모든 봉 가격에 같이 적용한다. 임계값 근처의 연속 전체 가격 공간이나 모든 기업 행사 조합을 포괄한 증명은 아니다.

분할 1:2에서는 기준가 100을 50 기준으로 비교하며 50의 보합 경로는 즉시 손절이 아니다. 병합 2:1에서는 200 기준으로 비교하므로 200의 보합 경로는 즉시 성공이 아니다. 3:7의 비유한 비율도 분자·분모 비교로 보존한다. 여러 행사의 누적 비율은 약분 후 ShareRatio의 양의 u64 쌍으로 표현 가능한 경우만 공급할 수 있다. 이를 넘는 이력은 어댑터에서 판정 불가로 남겨야 하며 반올림해 넣지 않는다.

D-23 변환은 성공을 Hit, 손절·만료·모호 실패를 Miss로 만든다. 진행 중·판정 불가는 None이다. 모델·추정 ID·AI 확률만 추가로 받고 종목·Horizon·원래 [관측, 만기] 구간은 판정 근거에서 가져온다. 기존 CalibrationFact의 공개 사실 생성 API를 제거하는 호환성 변경은 하지 않는다.

프로젝트·훅 신뢰가 세션에 적용됐다는 외부 증거는 없다. frozen install, lefthook install, 기준 전체 검사, 최종 전체 검사 및 커밋 훅으로 검증한다. 새 의존성, 기존 테스트 본문 변경, 검사 끄기, 실제 키·계좌 접근은 없다. 기존 파일 변경은 lib.rs 끝의 모듈·공개 목록 추가뿐이다.

직접 고른 손 변형 16개(목표 등호, 손절 등호, 분할 환산, 목표 거리, 손절 거리, 기준일 분봉, 분봉 목표, 분봉 손절, 모호 실패, 만료 실패, 수정 기준, 확정 상태, 종목, 중복 충돌, 보정 실패 변환, 캘린더 연속성)를 각각 컴파일한 뒤 고정 회귀 테스트로 검출했다. 최종 16개 모두 검출됐으며 생존·컴파일 불가·시간 초과는 0개다. 초기 목표 등호 및 캘린더 연결 변형이 드러낸 테스트 빈틈을 보강한 뒤 재실행했다. 자동 변이 도구는 실행하지 않았다. 정상 구현에서 새 테스트 23개와 두 모듈의 줄 커버리지 100%를 확인했다. 최종 전체 검사는 Git 커밋 훅의 just check 결과로 확인한다.


영역 커버리지 검사에서 도달 불가능한 오류 전파 분기를 정리했다. 분봉은 Timestamp를 매번 더해 만들지 않고 실제 종료 시각의 연속 60초 간격을 검사한다. 완전히 같은 중복 분봉은 한 번만 읽는다. 테스트는 판정 모듈 내부에 두어 테스트 전용 파일을 제품 측정 대상으로 만들지 않는다. 별도 `just coverage-check`에서 414개 테스트 전부 통과, 줄·영역 위반 0건을 확인했다.

Hours의 정수 나노초 산술은 정규장 한 구간의 최대 24시간 계약 안에서만 한다. 차이는 양수이며 86,400×10^9 미만 또는 같은 값으로 i64 범위 안이다. 시작 나노초와 더한 값도 u64 범위 안이다. 초 몫은 86,400 이하, 나노초 나머지는 10^9 미만이므로 바이트 분해 시 손실이 없다. 이 범위의 wrapping 연산에는 실제 wrap이 없다. 최종 Timestamp와 TimeInterval은 기존 검증 생성자로만 만든다. 정규장 길이의 1/4이 나노초 단위로 나누어떨어지지 않으면 내림한다. 1나노초보다 작은 허용 시간으로 성공을 늘리지 않는 보수적 초안이다.

캘린더의 날짜 연결뿐 아니라 정규장 실제 시각의 증가도 검증한다. D-10은 미국 현지 날짜를 스스로 계산하지 않으므로 날짜 행만 증가하는 역순 세션 입력이 타입상 가능하다. 이런 입력은 Calendar로 거부하고, 앞선 세션을 정규장 시간에 다시 더하지 않는다. 날짜가 연결됐으나 실제 정규장이 역순인 반례를 고정했다.

동일한 일봉 절대 시각에 서로 다른 현지 날짜가 붙은 입력은 충돌로 거부한다. 입력 순서에 따라 일봉 날짜가 달라지도록 중복 제거하지 않는다. 서로 다른 오프셋으로 같은 순간의 현지 자정을 표현한 반례의 정순·역순 결과가 같다.

검사 중 기존 portfolio_valuation.rs:1576의 속성 테스트 보조 함수 ZeroCost 경로가 한 번 생성되지 않아 영역 커버리지에서 실패했다. 기존 코드·테스트·난수 설정은 바꾸지 않았으며 정상 명령 재실행에서 414개 전부 통과, 커버리지 위반 0건을 확인했다. 기존 속성 표본의 분기 도달을 결정적으로 고정하는 후속 검토는 메인에 인계한다. 이 문제를 D-27의 테스트나 하네스 예외로 덮지 않는다.
