## 관측 분봉과 순서

확정된 수정주가만 사용한다. 진행 중인 봉은 판정 입력에서 제외한다. 분봉은 종료 시각으로 식별하는 [종료−1분, 종료) 구간이다. 관측 시각 이하에 끝난 분봉은 제외한다. 관측이 들어 있는 첫 분봉은 관측 이전 움직임을 포함하므로 다음 규칙으로 판정한다. 관측이 정확히 분 경계이면 이후 첫 봉 전체가 판정 구간이다.

| 관측이 든 부분 분봉 | 결과 |
|---|---|
| 목표·손절 모두 미도달 | 건너뛰고 다음 봉으로 진행 |
| 손절만 도달 | 손절 실패 |
| 목표만 도달 | 관측 이전 고가일 수 있으므로 모호 실패 |
| 둘 다 도달 | 모호 실패 |

기준 거래일과 일봉의 양쪽 경계 도달일은 시간순 1분봉을 쓴다. 온전한 분봉은 목표만 닿으면 성공, 손절만 닿으면 손절 실패, 양쪽이면 모호 실패다. 등호를 포함한다. 시가 갭도 양쪽 도달의 예외가 아니다. 시가를 쓰는 가상 청산 가격은 D-29의 책임이다.

## 판정 시작과 만기

판정 시작은 관측 시각 이상에 있는 첫 정규장 구간과 관측 시각의 최댓값이다. 장전·장후·휴장 중 관측했다면 다음 정규장 시작으로 이동한다. 날짜 연결과 실제 정규장 시각의 증가를 모두 검증하며 거래소 미래 일정을 외삽하지 않는다.

정수 H의 만기는 기존 ADR 0046 해석을 유지해 판정 시작 거래일 **이후 H번째 정규 거래일의 장 마감**이다. 따라서 정규장 안 관측의 기존 만기는 보존하고, 장 밖 관측은 실제 판정 시작 거래일로 기산점을 이동한다. Hours는 그 첫 정규장 길이의 1/4을 정규장 시간으로만 누적한다. 장이 닫힌 시간은 세지 않는다. D-21의 H=0.25·5·40·126 초안을 재사용하며 새 설정은 없다.

Hours 만기가 분 중간이면 만기를 포함하는 분봉 전체를 제외한다. 그 봉에서 목표에 닿았어도 성공으로 삼지 않고, 앞선 확정 봉에서 미도달했다면 사유는 기간 만료다. 390분 장의 97.5분 만기를 고정 예제로 둔다.

결과의 원래 과제 구간은 [기준 관측 시각, 만기]를 보존한다. 장 밖 관측에서 실제 판정 시작이 늦어져도 원래 과제 시작을 지우거나 조기 도달로 구간을 줄이지 않는다. 캘린더 facts가 부족하면 Calendar로 판정 불가다.

## 자료 누락과 진행 중

판정 시각보다 뒤의 분봉은 사용하지 않는다. 아직 해당 정규장이 끝나지 않았고 분봉이 덜 들어왔으면 진행 중으로 두고, 뒤에 있는 목표 봉만으로 성공을 확정하지 않는다. 누락된 분봉 앞에 손절이 있었을 가능성을 제거하지 못하기 때문이다. 장 종료 후에도 필수 분봉이 없거나 순서를 알 수 없으면 모호 실패다. 확정 거래일의 일반 일봉 누락은 MissingCandles이며 기간 만료 실패로 바꾸지 않는다.

## 미국 일봉과 현지 거래일

일봉은 시장 현지 거래일로 식별하며 캘린더의 해당 날짜 정규장에 대응시킨다. 국내 일봉 오프셋은 +09:00, 미국은 동부 현지 -05:00 또는 -04:00만 허용한다. KST로 찍힌 미국 일봉은 InvalidCandle로 거부한다. 미국 DST의 실제 날짜별 오프셋 선택은 시간대 DB가 없는 domain이 추정하지 않는다. **T-07은 미국 일봉을 실제 현지 거래일과 해당 날짜의 동부 오프셋으로 정규화해야 한다.** 기준일 이전 일봉과 정규장 시작 전 움직임을 다음 거래일의 성과로 옮기지 않는다.

## 수정 계수의 출처와 정확 산술

호출자가 ShareRatio를 직접 넣는 OutcomeAdjustment 생성자는 제거한다. OutcomeAdjustment::from_actions만 생성 경로다. D-28 CorporateAction은 행사 ID·기준일·종류·정수 비율을 봉인하지만 종목을 자체 필드로 보존하지 않는다. 따라서 수집된 종목 맥락과 봉인된 CorporateAction을 OutcomeCorporateAction으로 묶고, domain이 과제의 InstrumentId와 대조한다. 행사 ID를 종목 ID로 오인하지 않는다.

행사 기준일은 시장 현지일의 시작으로 해석한다. (관측 시각, 봉의 수정 기준 시각]에 들어오는 현지 기준일만 적용한다. 같은 관측일에 이미 적용된 행사는 다시 적용하지 않는다. 분할·병합만 지원하며 해당 구간의 다른 행사, 다른 종목, 같은 행사 ID의 중복은 Adjustment로 거부한다. 행사 순서를 정규화한 뒤 구주/신주 가격 비율을 domain이 누적한다. 행사 목록이 비어 있으면 항등 환산이며 임의의 1:2를 따로 공급하는 API는 없다.

여러 행사의 정수 분자·분모를 직접 곱하므로 누적 비율을 u64 한 쌍으로 줄이거나 반올림하지 않는다. 기준가×(1+T), 기준가×(1−S)와 봉 가격의 비교도 정수 교차 곱이다. 저장된 근사 T·S에서 비교용 경계를 만들며 가격·Ratio·Money를 공개 결과로 만들어 근사 표지를 지우지 않는다. 분할 1:2의 100→50과 병합 2:1의 100→200 보합은 즉시 손절·성공이 아니다.

## D-23 공개 경계

CalibrationEstimate::new와 CalibrationFact::new는 pub(crate)다. 유일한 공개 사실 생성 경로는 판정 결과의 calibration_fact다. 성공은 Hit, 손절·만료·모호 실패는 Miss이며 진행 중·판정 불가는 None이다. 모델·추정 ID·AI 확률만 추가로 받고 종목·Horizon·원래 [관측, 만기]는 판정 근거에서 가져온다. 외부 crate의 두 생성자 호출은 E0624, 옛 임의 비율 생성자는 E0599로 거부됐고 정상 변환 API는 컴파일됐다.

## 검증과 미해결

관측 부분 분봉 네 경우, 장 중간 관측 이전의 목표 고가 제외, 진행 중 누락과 종료 후 누락, 장 밖 관측, 진행 중 일봉 제외, 현지 일봉, 기업 행사 구간·종목·종류·중복, 97.5분 만기를 고정 회귀로 둔다. 관측 초 0~59·분봉 경로·목표/손절 경계 ±10^-26·Hours를 생성하는 독립 대조를 Config::with_cases(4096)로 실행한다. 독립 기준은 기존 정확 Money 산술과 시간순 분봉 탐색을 쓰며 제품의 정수 교차 곱을 재사용하지 않는다. 기존 순서·접두 입력 단조·분할 불변성 속성도 유지한다.

- 기준일 분봉이 보존 기간 밖으로 사라지면 이후 일봉에 목표가 있어도 모호 실패다. 이 규칙과 장 밖 관측의 기산점 이동·누락은 표본 선택 편향을 만들 수 있다. **J 작업은 기준일 분봉을 보존 기간 안에 수집해 보관해야 한다.** 성적표는 이 편향을 실력 차이로 해석하면 안 된다.
- 행사 사실의 출처·목록 완전성은 D-28/T 어댑터 책임이다. 기준일의 실제 효력 시각과 배당락·무상증자 등 수정 요인은 T-13/S-23 실측 후 별도로 확정한다. 현재는 지원하지 않는 행사를 추측하지 않는다.
- 미국 현지일·DST 정규화의 실제 API 연결, 근사 T·S의 참값 오차 전체 증명, 전 가격 공간의 속성 증명은 이번 검증 범위 밖이다.
- 기존 portfolio_valuation의 ZeroCost 속성 표본 커버리지 누락을 이전 회차에 한 번 관측했다. 기존 코드·테스트·난수 설정은 바꾸지 않았다. 해당 분기의 결정적 고정은 메인 인계다.
- 프로젝트 hooks=true와 직접 검사·Git 훅 결과를 구분한다. 세션의 프로젝트·훅 신뢰 강제 적용 증거는 확보하지 않았다. 실제 키·계좌·새 의존성·새 검사 끄기는 없다.

리뷰 수정의 테스트 38개(세 속성 테스트 각 4,096회 포함)가 통과했다. 로컬 master 1cd405c9f7ff11be0a26d1eb892766463aaf722a를 병합하고 양쪽 모듈·공개 목록을 보존했다. 직접 지정한 손 변형 29개를 병합된 코드에 주입해 전부 검출했다. 리뷰에서 생존한 관측 이전 분봉 포함 및 진행 중 일봉 사용 변형을 포함한다. 이 중 공개 생성자 노출 2개는 외부 컴파일 거부 계약으로 검출했고 나머지는 고정 회귀가 실패했다. 생존·컴파일 불가·시간 초과는 0개이며 자동 변이 도구는 실행하지 않았다. 최종 전체 검사는 Git 커밋 훅의 just check 결과로 확인한다.

행사 구간의 수정 기준 날짜도 수정 기준 시각 자체의 시장 현지 오프셋으로 읽는다. 관측 당시 오프셋을 미래 수정 기준 시각에 고정 적용하지 않는다. 미국 관측 EST와 수정 기준 EDT를 가로지르는 자정 경계의 행사가 포함되는 회귀를 둔다. T-07은 수정 기준 시각도 해당 시장 현지 오프셋으로 제공해야 하며 KST 미국 수정 기준은 Adjustment로 거부한다.

최종 수정 기준에서 병합 후 커버리지 대상 테스트 481개가 모두 통과했고 줄·영역 커버리지 위반은 0건이다. DST 경계 보완 뒤에도 손 변형 29개를 다시 실행해 전부 검출했다. 기존 테스트 본문·난수 설정·검사 정책은 변경하지 않았다.

최종 검사 중 master에 D-22가 추가되어 f9f0c5f0b7dff04ad4a184aadf882f4af1fee376도 추가 병합했다. D-27 구현과 손 변형 대상은 그대로 보존하며 D-22의 모듈·공개 목록·보호 생성물을 함께 유지한다.
