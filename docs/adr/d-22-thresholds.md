# D-22 거래 비용과 임계값

- 상태: 초안
- 기준: 8b92baa111b5c7796ab93c8201a58e7fe37608e6
- 근거: open-issues 1.2~1.4, design 6.2·6.3·ORD-8, R-01 Commission, R-11 Q3, ADR 0027·0029·0041·0045·0046

## 계산과 봉인

손익분기는 p₀+c/(T+S), 매수는 손익분기+여유분, 매도는 max(p₀−여유분,0.05)다. 비용 가산이 정확히 5%p이면 허용하고 초과만 거부한다. 근사 T·S·p₀는 EstimateTask에서만 받으며 계산은 전용 thresholds_arithmetic에 둔다. 결과에서 Decimal·Ratio·금액을 꺼내는 공개 경로는 없다. D-24 비교는 CalibratedProbability만 받는다. 표시 문자열은 백분율 소수 첫째 자리, 중간값은 0에서 멀어지는 방향으로 반올림한다.

ORD-8의 “15%p로 강제”는 최솟값이 아닌 정확한 대체다. 0~29건의 InsufficientSamples이면 설정이 크거나 작아도 15%p다. 30건 이상은 설정을 쓴다. 표본 수를 따로 입력하지 않는다.

예 표는 Python Decimal 80자리, 원래 급수 식을 독립 계산한 뒤 소수 28자리 입력으로 고정했다. H=0.25·5·40·120의 p₀는 각각 0.2726583497377840129425013015, 0.2752596578945449105591702896, 0.2806863606500262171700824076, 0.2858154623201750689564720914다. 반올림 전 결과는 며칠 31.25274575/41.25274575/17.52596579%, 몇 주 29.38625176/39.38625176/18.06863607%, 반년 29.34227201/39.34227201/18.58154623%다. 소수 첫째 자리 표시는 예 표와 모두 같다. 몇 시간은 비용 가산 16.6667%p로 과제 없음이다. 표시된 T·S·p₀를 다시 입력하여 중간 반올림하지 않는다.

## 비용 구성의 닫힌 표

| 시장·통화 | 매수 | 매도 | 처리 |
|---|---|---|---|
| 국내 KRW | 계좌 Commission 요율 + 매수 세율 | 계좌 Commission 요율 + 매도 세율 | 코스피 매도 거래세·농특세, 코스닥 거래세를 합산한 사실을 어댑터가 전달 |
| 미국 USD | 계좌 Commission 요율 + 매수 부담률 | 계좌 Commission 요율 + 매도 부담률 | SEC 등 거래시 부담을 모두 포함한 유효 부담률 사실이 필요. 최소액·주식 수 기반 비용을 비율로 확정할 수 없으면 Unknown |

계좌 요율은 토스 `/commissions`의 소수 비율이다. 세율 사실은 적용 시장·종목 분류·날짜에 맞는 세율표 조회 결과다. R-11의 2026년 코스피 0.05%+0.15%, 코스닥 0.20%, 미국 SEC 0.00206%는 고정된 현재 세율로 코드에 박지 않는다. 면제도 명시적인 0 사실이 필요하다. 누락을 0으로 바꾸지 않는다. 양도소득세·배당세는 한 번 거래대금에 비례하는 비용이 아니므로 이 c에 넣지 않고 세금 원장 책임으로 남긴다. 미국은 이미 보유한 달러로 주문하므로 자동 환전 비용은 없다. 알려지지 않은 부대비용이 있으면 부담률 사실을 만들지 않는다.

D-32의 ConfirmedOrderFee는 계좌 CommissionRateFact와 주문 키·주문 금액에서만 만든다. 정확 곱셈 뒤 KRW는 1원, USD는 1센트로 올린다. 문서의 실제 절사·면제와 달라도 사전 추정이 사용자의 비용을 과소 표시하지 않도록 한 사용자 지시다. 세금은 예상 수수료 필드에 섞지 않는다. 실제 체결 비용은 거래내역으로 교체한다.

## 사용자 확인과 미해결

- 일반 여유분의 범위·위험 성향별 수치는 문서에 없다. 보수적 초안으로 5~25%p, 보수 20·중립 15·공격 10%p로 정한다. 10%p 예시는 설정 입력으로 재현한다. E-92와 사용자 확인 대상이며 확정 설정 화면은 추가하지 않는다.
- 사실 생성자는 외부 응답의 진위를 인증하지 않는다. 적용 날짜·계좌·종목 세율 분류와 미국 최소액·면제·SEC 이외 부담의 완전성은 broker 어댑터가 책임진다. 호출 위치 구조 강제는 후속 하네스 과제다.
- D-21 반년 기본 H=126과 예 표 H=120은 구분한다. 예 표 검증은 H=120의 반올림 전 수치를 사용한다.
- 프로젝트 신뢰와 훅 정의 신뢰가 현재 런타임에서 적용됐다는 증거는 제공되지 않았다. Git 훅 설치와 명시적 전체 검사 결과를 별도 확인한다.

## 경계와 검증 계약

비용 거부는 나눗셈으로 반올림한 Δ와 0.05를 비교하지 않고 c×20과 T+S를 비교한다. 유효한 D-21 과제는 S≤0.9, T≈2S로 합이 2.7 이하이며 CostRate는 각 항이 [0,1]이다. 경계 부근 c×20≤2.7에서는 28자리 십진 계수가 정확히 표현되고, 경계에서 멀리 떨어진 곱의 표현 반올림은 판정을 바꾸지 않는다. 분모 0·수치 범위 초과는 NumericalDomain이다. 계산된 Δ는 여전히 근사 타입 안에만 둔다.

임계값은 생성에 사용한 CalibratedProbability 전체를 보존한다. 같은 모델·기간이어도 판정 수·확률·보수 운용 변형이 달라지면 CalibrationMismatch로 비교를 거부하고 새 임계값을 계산해야 한다. 30건 상태에서 낮은 설정으로 만든 매수 임계값을 29건 상태의 확률과 비교하는 우회를 막는다. 과제 H와 보정 결과의 Horizon 대응도 대조한다. 실제 모델·기간 선택의 정확성과 판정 사실 출처는 application·D-23 책임이다.

독립 기준 검사는 임계값의 십진 계수와 정수 유리수의 교차 곱 잔차를 비교한다. 수수료 검사는 통화 최소 단위 정수의 올림과 대조한다. 각각 Config::with_cases(4096)를 쓰며, 29/30건에서 설정 독립 강제도 4096회 검사한다. 고정 회귀에는 예 표 네 행, 정확히 5%p, 나눗셈 표현 정밀도보다 작은 비용 초과, 5% 매도 하한, 미확인 비용·시장, 서로 다른 시장·기간·보정 결과, 정확 곱의 PrecisionLoss, 통화별 올림을 포함한다. 자동 cargo-mutants는 실행하지 않는다. 손 변형·최종 전체 검사 결과는 구현자 보고에 남긴다.

새 의존성, 검사 끄기, 기존 테스트 변경은 없다. D-21의 기존 crate 내부 접근자를 재사용하므로 기존 과제·확률 파일도 수정하지 않는다. 비용을 모르면 TradeCost::from_facts가 닫힌 TradeCostError::UnknownComponent를 반환하므로 Thresholds 생성에 도달하지 않는다. 이 오류와 NoThresholds는 모두 과제 없음으로 application이 처리한다.

손 변형 23개는 각각 컴파일 후 nextest 종료 100의 실제 테스트 실패로 검출됐다. 범위·비용 미상·시장·기간·보정 결과·보수 운용·과다 비용의 분기 제거 17개, 5%p 경계의 초과→이상, 매도 하한 제거, 매수 여유분 부호 반전, 매수·매도 세금 항의 부호 반전, 수수료 올림→내림을 포함한다. 각 실행 뒤 새 모듈 원본을 복구했다.
