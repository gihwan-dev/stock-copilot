# 대시보드 위젯에 FlexLayout을 사용한다

위젯을 탭으로 묶고 떼어 내는 동작과 분할선 드래그는 `flexlayout-react` 0.11.2가 처리한다. 사용자는 탭을 원하는 위치로 끌거나 라이브러리의 창 조작 버튼을 쓴다. 앱은 위젯의 내용과 이름, 추가·초기화 동작, 기존 테마와 화면 모양 설정을 제공한다.

도킹 라이브러리를 비교할 때 큰 계좌 표를 열고 분할선을 움직였다. Dockview의 기본 분할선은 포인터가 움직일 때마다 표 너비를 바꿨다. FlexLayout의 `realtimeResize={false}`는 드래그 중에 표시선만 옮기고 놓을 때 실제 크기를 적용한다. 독립 프레임은 같은 앱 창 안에 띄운다.

화면 너비 구간별로 배치를 저장한다. 이전 버전에서 사용자가 구성한 탭, 분할 비율, 독립 프레임, 제거한 위젯을 새 모델로 옮긴다. 앱에 저장하는 정보는 배치를 재구성하는 데 필요한 항목으로 제한한다. 보유 금액과 보고서 본문은 위젯이 기존 조회 경로에서 읽는다.

라이브러리의 상호작용과 키보드 지원은 [FlexLayout 문서](https://github.com/caplin/FlexLayout)에 있다. 기존 대시보드의 위젯 구성과 도입 배경은 [ADR 0199](0199-dashboard-docking.md)에 있다.
