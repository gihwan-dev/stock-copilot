# fin-measure 묶음 결정 기록

실측 묶음(AI-12, AI-15, G-09, DS-16, S-13·S-17, U-30)에서 문서가 정하지 않아 구현 담당이 정한 것.

| 작업 | 정한 것 | 다른 선택지 |
|---|---|---|
| 공통 | 실측 기록은 `docs/measurements/<작업>-*.md`에 둔다. `docs/open-issues.md`는 보호 파일이라 고치지 않는다 | open-issues 4.3 표에 직접 결과 적기(보호 파일), progress.md에 적기(묶음 규칙 금지) |
| 공통 | 측정 도구(Swift, 셸)는 `docs/measurements/`에 둔다. `scripts/`는 보호 경로라 쓰지 않는다 | `scripts/measure/`(보호 경로 경고), 저장소 밖 임시 폴더(재현 불가) |
| AI-12 | 세션 훅이 `claude` 실행을 거부해 우회하지 않고, 사용자가 돌릴 점검 스크립트만 둔다 | 스크립트로 감싸 훅 우회(하네스 8장 위반) |
| AI-15 | 실측 없이 ADR 0178로 "수집 실행은 WebSearch 결과만"(현재 코드 유지)을 확정하고, 사용자 실측 결과로 다시 볼 조건을 적음 | 실측 전까지 ADR 보류, 앱 가져오기 도구 추가 |
