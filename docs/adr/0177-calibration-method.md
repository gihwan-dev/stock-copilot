# ADR 0177: E-91 보정 방법(기본 매개변수)

- 상태: 확정 (2026-11-25, 묶음 fin-e). **E-90 자료로 재조정 필요**
- 근거: tasks E-91·D-23, design 6.2·6.6, ADR 0027·0041
- 사용자 지시: E-90 실측 자료가 없으므로 표본이 적을 때 기준 확률 쪽으로 당기는 방식을 기본 매개변수로 정한다. 기존 테스트 변경은 승인된 것으로 본다

## 결정

모델·기간 조합의 판정 수가 30건 이상일 때만(D-23 그대로) AI 확률 p를 다음과 같이 보정한다. 30건 미만은 지금처럼 원래 p로 보수 운용한다.

1. **조합 전체 표본으로 선형 재보정**: 그 조합에서 선택된 판정(D-23의 겹치지 않는 추정) n건의 예측 pᵢ와 결과 oᵢ(적중 1, 실패 0)로 최소제곱 직선을 맞춘다. 기울기 b = Σ(pᵢ−p̄)(oᵢ−ō) / Σ(pᵢ−p̄)², 예측이 모두 같으면 b = 0. 적합값 f(p) = ō + b·(p − p̄)를 [0, 1]로 자른다.
2. **기준 확률 쪽으로 축소(베타 사전과 같은 가중 평균)**: 보정값 = (n·f(p) + k·p₀) / (n + k). p₀는 그 추정 과제의 기준 확률(D-21), k는 사전 강도이며 **기본 k = 30**이다. 표본이 적으면 p₀에 가깝고(1건이면 p₀ 쪽 가중 30/31), 표본이 많을수록 관측 쪽으로 간다.
3. 결과는 [0, 1]로 자른 뒤 소수 6자리(짝수 반올림)로 고정해 저장·복원에서 같은 값이 되게 한다. 계산은 `domain::calibration_arithmetic`(Decimal checked 연산 허용 목록)에서만 한다.
4. 구간별 적중률(D-23 구간 표)은 표시용으로만 두고 보정 함수에 쓰지 않는다(ADR 0041).
5. 보정 결과(`EligibleCalibration`)의 근거에는 보정한 확률(`probability`)과 원래 AI 확률(`original_probability`)을 함께 남긴다. 임계값 비교·표시는 보정한 확률을 쓴다. 변형 이름 `EligibleBeforeE91`와 저장 문자열 `eligible_before_e91`은 저장된 신호와의 호환을 위해 바꾸지 않는다.
6. **Brier 점수 기록**: 판정(A-15 `ResolveEstimates`)마다 그 판정을 더하기 *전* 보정표로 그 추정을 보정해 (원래 p − o)²와 (보정 p − o)²를 계산한다(앞선 자료만 쓰는 순차 평가라 표본 안 과적합이 없다). 결과는 `ResolutionStatus::Resolved.brier`로 내고, 예약 판정 작업(J-12)의 집계 `ResolutionTally.brier`(`BrierTally`: 건수, 보정 전·후 평균)에 모은다.

## 기본 매개변수를 이렇게 정한 이유

- k = 30은 D-23의 최소 표본 30건과 맞춘 값이다. 보정이 처음 켜지는 30건에서 자료와 기준 확률을 반씩 믿고, 300건에서 자료 쪽 가중이 약 91%가 된다.
- 선형 재보정은 LLM 확률의 과신(기울기 < 1)을 직접 줄인다(design 10장 위험 표, R-12 2.1). 구간 방식보다 표본을 덜 나눠 30건대에서도 안정적이다.
- 과거 판정에는 기준 확률이 저장되어 있지 않아(보정표 저장 형식 변경 없이) 축소 목표를 과거 표본에 다시 적용할 수 없다. 그래서 Brier는 판정 시점에 순차로 기록한다.

## 버린 대안

| 대안 | 버린 이유 |
|---|---|
| 구간별 적중률을 기준 확률 쪽으로 축소 | ADR 0041·design 6.2가 구간별 적중을 표시용으로만 쓰게 함 |
| 로지스틱(Platt) 재보정 | 반복 최적화와 지수·로그가 필요하고 30건대에서 불안정. 정확 십진 산술 원칙(ACC-2)과 맞추기 어려움 |
| 등위 회귀(isotonic) | 표본이 적을 때 계단이 거칠고 기준 확률 쪽 축소를 따로 얹어야 함 |
| 판정에 기준 확률을 저장해 표본 안 Brier 계산 | 보정표 저장 형식과 복원 계약(D-56) 변경이 필요. E-90 이후 재조정 때 함께 검토 |

## E-90 자료로 재조정할 것

- 사전 강도 k(현재 30)와 선형 재보정 자체의 적합성. 순차 Brier에서 보정 후 평균이 보정 전보다 나쁘면 k를 키우거나 재보정을 끈다.
- 조합별 표본이 충분해진 뒤의 구간 수·경계(ADR 0041 미해결 표)와 성적표 신뢰도 도표.
- 판정마다 계산한 Brier 쌍의 영속 보관 위치(현재는 판정 보고와 예약 작업 집계까지). 성적표(D-17) 저장과 함께 정한다.

## 바뀐 기존 테스트 (사용자 승인)

- `domain::calibration` 30건 경계 테스트: 30건에서 보정값 0.685((30·1 + 30·0.37)/60)를 기대하도록 바꾸고 원래 확률 보존을 확인
- `domain::thresholds`의 `calibrated_at` 고정 자료: 30건 이상에서 보정 결과가 원래 p와 같아지도록(적중 비율 = p, 100건) 바꿈
- `domain::signal_restore`의 고정 보정표: 1~99% 각 100건의 잘 맞는 표로 바꿈
- `domain::signal_decision` 독립 기준: 30건 이상은 보정한 확률로 비교하고 표시 문구 검사는 30건 미만에서만
- `scheduler::code_jobs_tests`, `store-sqlite::estimates_tests`: `ResolutionTally.brier`, `Resolved.brier` 필드 반영
